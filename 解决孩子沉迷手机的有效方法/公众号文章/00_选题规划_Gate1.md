## 三、分篇规划（8 篇，篇号连续）

### 第1篇 · 总纲《孩子放不下手机，先别怪手机：三个成因，我对号入座了》
- 备选：①手机不是罪魁祸首：三个成因里，我家全中 ②砸手机那天我才明白，问题从来不在那块屏幕上
- **痛点场景**：又一次因为手机吵完，我站在他关上的房门外，手里攥着刚没收来的手机
- **核心观点**：手机不是原因，是结果。同样环境下有孩子管得住自己，差的不是运气而是家庭——而家庭是我唯一能掌控的
- **金句小标题**：·社会我改不了，家里的灯我能点亮 ·三个成因，我对号入座 ·别搞叶子，先搞根
- **选用例子**：直播里那位现场提问"社会这么乱我能怎么办"的爸爸；我家高一开学后的手机拉锯
- **我后来试着做的几件小事**：①先不砸手机，拿张纸写下"我家属于哪一种" ②把"你怎么又玩"换成"我们看看卡在哪"
- **发布时机**：开学季手机冲突高发期，本周内（工作日晚 20:00–22:00）

### 第2篇《孩子幼儿园就刷短视频，那条路是我亲手铺的》
- 备选：①他两秒刷一条视频的样子，像极了饭桌上的我们 ②我家手机有个固定"养鸡场"，孩子的瘾才慢慢淡了
- **痛点场景**：亲戚婚礼上，三四个幼儿园到二年级的孩子挤在一起刷短视频，两秒一条，一小时不抬头
- **核心观点**：孩子放不下手机的更大原因，是父母放不下手机。环境是父母亲手营造的，也能亲手换掉
- **金句小标题**：·那条路是我铺的 ·手机是工具，不是玩具 ·低龄还有"商量—计时—提示"三步
- **选用例子**：婚礼上那群孩子；舟山旅游退房时孩子躲回房间看动画片；理发店带书等位
- **我后来试着做的几件小事**：①设了个固定"养鸡场"放手机，走过去两分钟处理完就离开 ②晚上九点半后手机不进卧室 ③能开电脑就不摸手机
- **发布时机**：暑假 / 节假日亲子冲突高发期

### 第3篇 · 核心《孩子不是爱手机，是学习上没台阶下了》
- 备选：①我天天盯着他放下手机，却忘了他卡在哪道题上 ②那个成绩很好的孩子突然不去上学，我身边就有
- **痛点场景**：深夜十一点，他对着同一道题坐到半夜，第二天被老师批评——恶性循环就这么开始了
- **核心观点**：手机常常只是"第三者"。孩子逃避的不是学习，是在学习里找不到成就感的自己
- **金句小标题**：·他不是爱上手机，是没台阶下 ·越是被批评的孩子越容易逃 ·先扫学习的障碍，再谈手机
- **选用例子**：小学名列前茅 → 初中实验班 → 熬夜卡题 → 逃避 → 父母只盯手机 的完整链条（脱敏）
- **我后来试着做的几件小事**：①先把他卡住的那科陪他补了一个月 ②把"你又玩手机"改成"哪道题卡住了"
- **发布时机**：期中考试前后

### 第4篇《孩子说"压力好大"，我一开口就把他推远了》
- 备选：①"你要更用功""我早说过了"——这两句我说过无数遍 ②他来找我求助，我却顺手补了一刀
- **痛点场景**：晚饭后他低声说"最近作业有点吃力"，我脱口而出"那你要更用功啊，不懂去问老师"
- **核心观点**：他需要的是信任和支持，不是批评，更不是证明"我早就对"。要在根部施肥，不在叶子上使劲
- **金句小标题**：·我脱口而出的那句话 ·"我早说过了"是最凉的一句话 ·化情四步：识别→同理→探讨→相信
- **选用例子**：原文两句父母典型错话；化情大法四步拆解 + 一段可直接照念的父亲台词
- **我后来试着做的几件小事**：①把"你要更用功"换成"我听到你最近很吃力" ②问了半句就闭嘴，让他把话说完
- **发布时机**：家长会后 / 月考出分周

### 第5篇《同样上网课，一个近视一个掉队，差在哪儿》
- 备选：①"网课学困生"不是新病，是三年前留下的旧账 ②帮孩子找到目标那天，手机忽然没那么香了
- **痛点场景**：投屏里老师在讲课，屏幕角落弹出游戏公告，他的笔停了三分钟没动过
- **核心观点**：网课只是对自律性和过去管理水平的检验。它不是问题本身，是一面照出问题的镜子
- **金句小标题**：·屏幕前那三分钟的停笔 ·网课是照妖镜，不是元凶 ·把目标还给他，注意力才有地方去
- **选用例子**：网课四因拆解；"网课学困生"现象；长中短期目标带来的转变（脱敏）
- **我后来试着做的几件小事**：①和他一起把"想考哪所高中"拆成三个月的小目标 ②不自作主张装摄像头，先聊一次
- **发布时机**：开学 / 线上教学密集期

### 第6篇 · 实战《我没收儿子手机那晚，把老师请来一起谈》
- 备选：①我请老师先夸了他三件事，他才肯听"手机"两个字 ②把他请到桌前第一句，我先说：这不是批评会
- **痛点场景**：手机冷战第三天，我坐在他对面，老师也来了——他靠在椅背上，全身写着防御
- **核心观点**：规矩不能一个人压，要请他自己立。先卸防御、再给价值感、最后才谈手机
- **金句小标题**：·第一句我先摘掉他头上的帽子 ·请老师先夸他三件事 ·爸爸认的错是冷战，不是管手机
- **选用例子**（交叉素材 · 三方面谈八步）：摘帽子 → 老师当众表扬三件事 → 请他先说 → 听他说（管住嘴）→ 爸爸道歉交权 → 亮"共管→放松→自控"路径 → 一起定约定 → 三方签字
- **我后来试着做的几件小事**：①谈前先给老师发了条微信，只请她做三件事 ②他抱怨时我忍着没辩解，只接一句"这话我听到了"
- **发布时机**：手机冲突僵持期

### 第7篇《一张纸管住了我们家的手机，也管住了我》
- 备选：①"我先做到，才有资格跟你谈规矩"——这句他认了 ②我把"高一结束彻底放开"写进约定，他才签了字
- **痛点场景**：他拿起笔，盯着纸上"每连续做到一个月，每天加半小时"，看了很久才写下自己的名字
- **核心观点**：把管控一步步换成他的自控——他控 → 内化 → 同化 → 自控。要给终点，也要给对等条款
- **金句小标题**：·只要不碰底线，他的方案就答应 ·宁要他的 60 分，不要我的 100 分 ·这份约定也管我
- **选用例子**（交叉素材 · 可打印签字约定）：松绑阶梯（每连续做到一个月 +0.5 小时）；夜间 22:00–7:00 锁屏不动；"高一结束彻底放开"的终点；**家长对等条款**——我违约也要被罚
- **我后来试着做的几件小事**：①把约定贴在冰箱上，谁违约谁认 ②守住"不冷战"，再谈不拢也只用说的
- **发布时机**：谈判成功后的复盘期

### 第8篇 · 收尾《我陪他踢了一场球，他那天没提手机》
- 备选：①我算了算，他还能让我陪的日子其实只剩三年 ②孩子放下手机，是因为现实里有人等他
- **痛点场景**：周末下午球场上，他回头喊了一声"爸，快点"，我忽然想起自己多久没这样跑过了
- **核心观点**：孩子沉迷的深层原因是家里太无聊、太孤独。现实里有人陪，虚拟世界的吸引力自然下降
- **金句小标题**：·家里无聊，手机才好玩 ·陪伴是有时效性的 ·四种陪伴，从一起读书开始
- **选用例子**：四种陪伴方式（一起读书 · 一起做游戏 · 一起运动 · 分享收获）；"你和孩子存款"的比喻；陪伴时效性（大学后基本没机会，高中仅剩寒暑假）
- **我后来试着做的几件小事**：①周末半天把手机放进抽屉 ②晚饭后不再说教，只问他"今天有什么有意思的事"
- **发布时机**：期末 / 寒暑假开始前
