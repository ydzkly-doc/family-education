一个爸爸的真实复盘 · 那两年我盯错了地方

孩子不是爱手机

是学习上没台阶下了

第 3 篇 · 共 8 篇 ｜ 手机沉迷：三因与干预

晚上十一点二十。

我起夜路过他房间，门缝里还有光。推门一看，他趴在桌上睡着了，脸压着一本摊开的练习册，笔掉在地上。台灯还亮着。

我第一反应不是心疼，是火：怎么又拖到这个点。

把他叫起来的那几十秒，他整个人都是懵的，揉着眼说"我还有两道题"。我说别写了，睡觉。

第二天早上，他没写完的作业交不上去。中午老师给我发了条消息。

我以为我看到了全部

接下来那两周，我看到的场景是这样的：他作业越拖越晚，白天上课昏昏沉沉，被老师点名批评；回家更不想写，写不完第二天又挨批。

而我盯住的是什么呢？

我盯住的是他手机玩得越来越多。

于是我做的事，就是每天盯着"手机"这两个字。我提醒他少玩，我唠叨他不用功，我语气一天比一天不稳、越来越不耐烦。我心里认定了一件事：是手机害了他。

结果很讽刺——我管得越多，他玩得越凶。

那个"突然不上学"的孩子

转折是我在一次线下课上听到的一个例子。讲的是别人家的孩子，我却听得头皮发麻。

那孩子小学在班里名列前茅，初中开学分班考也考得不错，三百多人里进了年级前二十，进了实验班。

但小学六年，他是被父母盯出来的——作业要督，写得慢，好习惯没真正长在身上。

到了初中就不一样了。任务重、节奏快、工作量大，还是实验班。有一次他做作业被一道题卡住，坐到十一点还没做完，人困得不行，想眯一会儿养养神，结果睡死了过去。半夜一点醒过来，他一直是个好学生，又爬起来写，写到很晚也没写完。

第二天，作业没完成，人也没精神，到学校被老师批评了一顿。

然后就是那个让人喘不过气的循环：睡不好 → 上课听不进 → 作业又完不成 → 又被批评 → 更睡不好。

最开始他只是偶尔想逃避，别人上课的时候，他到学校别的地方晃一晃，其实就想喘口气、解解压。慢慢就变成不想进教室，不想看见老师。

而父母那时候注意到的是什么？是"他最近明显比以前更多地拿起手机了"。

父母为此生气：学习都跟不上了，还老玩手机——就更要多看书。提醒、唠叨、语气越来越不耐烦、批评越来越多。

后面的事我不忍细说。孩子跟父母的争吵越来越多，到后来只要父母一开口，他就把门砰地关上。

我坐在下面，心里冒出一个念头：这不就是我吗？我天天盯着手机，可他到底卡在哪儿，我其实一直不知道。

"手机游戏只是孩子跟学习之间的第三者。很多时候，孩子是在学习上遇到困难了，只能用手机来排解那份压抑。"

那句话落下来，我才明白我做错了什么——孩子逃避的不是学习，是在学习里找不到成就感的自己。

手机里有什么？打游戏，成就马上看得见；队友都尊重你；看小说，主角都是一路逆袭的。在学校被人看不起的地方，他在那里被当成一个"厉害的人"。

我当时做的事，是把他最后那点喘气的地方也堵上。

我做了一件以前从没做过的事

那天回家，我没提手机。

我把他的练习册翻开了。一页一页往前翻，翻到最近这两周。我看见物理那一章，好几页上都只有题号和一片空白，页边有几处铅笔擦过的痕迹——写了又擦、擦了又写那种。

他站在门口看我翻，一句话没说。

我说："这章是不是没听懂。"

他愣了两秒，说了句"嗯，受力分析不会"，然后转身回房了。

就是这么一句。没有拥抱，没有痛哭流涕。但那天晚上，我第一次不是站在他房门外，而是站在了他的问题面前。

我后来试着做的几件小事

第一件：先扫台阶，再谈手机。我找了个物理老师，一周一次，只补受力分析那一块。补了三周，他自己把那一章后面的题做了。他做出来的那天没说话，但把本子放到我桌上就走了——那个动作我懂。

第二件：把"你怎么又玩手机"换成一个具体的问题。换成"这周哪一科最难"。第一次问，他不理我；隔了三天再问，他说"数学也一般"。这句话比"物理"往下走了一步。

第三件：让他在学校重新有点"值钱"的感觉。我跟老师沟通过一次，请老师在他某次做对的地方点了他一次名。这件事对孩子来说比我夸一百句都有用。

第四件：也留了一道口子。我不再要求他"放下手机"，我要求的是"作业写完前手机在客厅"。就这一条。说多了等于没说。

必须说实话：那两个月他的手机并没有少玩多少。真正开始有变化的，是他开始愿意跟我说话，也开始在物理课上举手了。

我后来想明白一个顺序：先帮孩子把学习上那道坎迈过去，他在学校里越有价值感，就越有勇气面对现实。手机自然就退到后面去了。

一个越早成绩就不太好的孩子，反而没那么容易逃避——因为他早就无所谓了。真正容易"突然不去学校"的，往往是那些原本成绩不错、一直紧绷着的孩子。这件事我是到那一年才明白的。

孩子玩手机的时候，他逃避的往往不是学习，

是那个在学习里找不到成就感的自己。

下一篇，我想说说那句我说了无数遍的话。他明明来找我求助，我却一句话把他推远了——而且我当时以为自己说得挺对。

愿你不只盯着那块屏幕，也能看见屏幕后面卡住他的那一步。

我也是个还在重启的爸爸，不是专家，只是比昨天多懂了一点。咱们一步步来，门一直开着。
