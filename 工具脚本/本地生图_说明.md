# 本地生图 —— `工具脚本/本地生图_生成.py`

> **一句话**：把一段描述变成一张图，**全程在本机**。不用账号、不联网、不消耗积分、不加 AI 水印。
> 形态和 ffmpeg 一样：仓库外一个独立程序 + 一个模型文件，本仓库只放一层调用封装。

---

## 为什么要有这个

公众号内容生产里真正需要"生成"的图只有两处：

| 产物 | 需要生图吗 |
|---|---|
| 正文 HTML | ❌ SOP 规定零位图（全用 `<section>` + 内联样式画） |
| 干货卡片 | ❌ 700px 扁平 HTML，代码渲染 |
| **长文封面** | ✅ 唯一的位图 |
| **卡片文章底图** | ✅ 每篇只需 2 张（封面卡 + 收尾卡） |

原本这两处依赖云端生图（耗积分、要账号、常带 AI 水印角标）。本地化之后：

- **零积分** → SOP 里「生成前必须告知用户消耗积分」这条自动失效
- **无水印** → SOP 里「出图后必须用脚本去掉 AI 水印」这步可以省掉
- **离线** → 不受网络与服务可用性影响
- **规格自带** → `cover` / `card` 预设直接满足 SOP 的 2.35:1 与 3:4 规范

## 用法

```bash
python 工具脚本/本地生图_生成.py --prompt "英文提示词" --preset cover --out "封面.jpg"
```

| preset | 产出 | 体积上限 | 后处理 |
|---|---|---|---|
| `cover` | 1200×511（2.35:1） | ≤200 KB | 中央方形安全区 + 两侧模糊背景 |
| `card` | 900×1200（3:4） | ≤100 KB | cover 裁切 + 柔化 + 压暗 |
| `raw` | 512×512 原图 | — | 无 |

常用参数：`--batch 3`（出 3 张挑一张）、`--seed`（复现）、`--json`（结构化输出便于解析）。
默认 `--steps 6 --cfg 1.0`（LCM 模型的正确配方，**不要加大步数**，只会慢不会更好）。

**必须用带 Pillow 的 Python**。DSH 自带的那个已含 Pillow 12.3：

```
C:\Users\ZhuanZ\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe
```

## ⛔ 三个坑（踩过，排错先看这里）

1. **中文路径不能直接喂给 `sd-cli.exe`。**
   参数经 UTF-16 → GBK 双重编码会坏：轻则文件写成乱码名（`鍗＄墖...`），重则报
   `failed to create directory ... Access is denied`（其实是路径坏掉，不是权限问题）。
   **封装已把原图先写到纯 ASCII 的 TEMP 再转存，所以不要绕过封装直接调 `sd-cli`。**

2. **不要往 TEMP 的子目录写。**
   沙箱只授权 TEMP 根目录本身；`tempfile.mkdtemp()` 建的子目录反而被拒。

3. **`sd-cli.exe` 写不进工作区目录，也写不进仓库外目录。**
   前者是中文路径问题，后者是沙箱限制。成品落盘一律交给 Python —— Python 处理中文路径没问题。

**结论：整条链路在受限模式下即可完成，不需要提权。**
如果报 `Permission denied`，先确认没有绕过封装自己调 `sd-cli`。

## 能力边界（别过度承诺）

| 题材 | 本地效果 |
|---|---|
| 静物、门、窗、光影、氛围、抽象意象 | ✅ **可用**，主战场 |
| 插画感、简约图形 | 🟡 基本可用，可能要试几张 |
| 写实人物、人脸、手、复杂建筑 | ❌ **别用**，改用外部生图服务 |

分辨率是 512×512 原生：`cover` 预设的中央方形正好用足 511 高、**无放大**，所以清晰；
`card` 预设会放大到 900×1200，**靠柔化掩盖**（SOP 本来就要求柔化，不违和）。

## 出图不理想时

1. **写具体**：场景 + 光线 + 情绪，比抽象词有效。
2. **`--batch 3`** 一次出几张挑一张（约 2.5 分钟）。
3. **末尾固定加** `no text, no letters, no watermark`。
4. **调低 `--size`**（如 384）应对显存不足——日志里出现 `vae decode compute failed` 就是显存不够。
