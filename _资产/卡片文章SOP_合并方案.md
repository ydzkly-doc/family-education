## 二、⭐ 核心问题：存量 vs 新生成（**你问的第 3 点**）

### 2.1 设计原则：**一条主链，两个入口，同一套规则**

> **核心不变式**：**无论哪种入口，长文都是卡片文章的唯一素材源，且卡片文章都在长文完成后做。**

```
                    ┌─────────────────────────┐
                    │   长文（唯一素材源）      │
                    └───────────┬─────────────┘
                                │
              ┌─────────────────┴─────────────────┐
              │                                   │
      【入口 A】存量补做                  【入口 B】全新生成
      已有长文（含已发布）                新系列 / 新篇
              │                                   │
              │                          长文走原 SOP 0–9 步
              │                                   │
              └─────────────────┬─────────────────┘
                                │
                    ┌───────────▼─────────────┐
                    │  第 9.5 步 · 卡片文章     │
                    │  （同一套流程、同一套规则）  │
                    └─────────────────────────┘
```

### 2.2 两个入口的差异（**只有 3 处，其余全同**）

| 维度 | 入口 A · 存量补做 | 入口 B · 全新生成 |
|---|---|---|
| **起点** | 直接从卡片 SOP 第 0 步「读长文」开始 | 长文走完原 SOP 0–9 步 → 再进第 0 步 |
| **长文状态** | **已完成、可能已发布** → **⛔ 只读，绝不回改** | 刚完成，可自由引用 |
| **可用的图片素材** | 既有长文封面已在包内，**但卡片需另生成新底图** | 同左 |
| **其他（规格/张数/文案规则/关卡/自检）** | **完全一致** | **完全一致** |

### 2.3 ⚠️ 存量补做的三条额外纪律（**必须有，否则会破坏已发布内容**）

| # | 纪律 | 原因 |
|---|---|---|
| **1** | **⛔ 只读长文，绝不回改** | 长文可能已发布，改动会造成线上线下不一致 |
| **2** | **⛔ 不改长文标题去迁就卡片** | 卡片标题可另起，**不得反向修改长文** |
| **3** | **可回溯对照以"已定稿长文"为准** | 防止补做时顺手"优化"长文内容导致引用错位 |

### 2.4 ⭐ 批量存量补做的排序建议（**建议项**）

若要对某个系列**批量补做**，建议按此顺序：

| 优先级 | 条件 | 理由 |
|---|---|---|
| 1 | **数据表现好的篇目** | 已被验证的内容，卡片版更容易拿到推荐 |
| 2 | **主题大众向、痛点明确** | 与推荐流人群匹配度高 |
| 3 | **总纲 / 导航型篇目** | 分享与涨粉效率最高（本项目数据支持） |
| 4 | 其余篇目按系列顺序 | — |

### 2.5 合并后的完整流程图（**最终形态**）

```
【全新生成入口】
 第 0 步  消化材料
 第 1 步  选题规划 ────── Gate 1
 第 2 步  写正文
 第 3 步  干货卡片
 第 4 步  正文 HTML
 第 6 步  配套手册
 第 7 步  组装发布包 ──── Gate 2（样板）/ Gate 3（封面）
 第 8 步  沉淀与命名
 第 9 步  全套自检
 第 9.5 步 ★ 卡片文章 ── Gate A（拆卡）/ Gate B（封面卡）      ← 新增
 第 10 步 维护巡检清理
 第 11 步 真实素材池
 第 12 步 数据复盘闭环
            ↑ 卡片文章的数据也并入此处回收（用"推荐量/曝光"口径，不与长文互比）
```

```
【存量补做入口】
 任选一篇已定稿长文 ──► 直接进第 9.5 步 ── Gate A / Gate B ──► 交付
                        （⛔ 长文只读不改）
```
