## 四、考古层处理

1. **沿革叙述删除或转写**：凡"旧 X 已作废，见 SOP变更日志"——主文件只留**现行规则一句**，沿革不写。
   典型：第 33、100-101、119、125、130、299-306、375、870、1192、1220、1372 等。
2. **被删的沿革集中进 `references/SOP变更日志.md`**：把项目 `_资产/SOP变更日志.md` 复制进包内，
   本次新作废的口径（80%、4.6字秒、7段模板、咬合六条等）若日志里缺，追加补登，带日期。
3. **历史编号案例（03/05/06 实测故事）**：保留在 ref02/ref04 的对应条目下作为"为什么有这条"的佐证，
   但删掉重复叙述、压成一两句——它们在按需文件里不占常驻上下文。
4. **重复段直接删**：注意事项里"杠杆是被转发"那段的第二次出现删掉。

## 五、主文件里的引用指针写法（统一格式）

主文件需要细则处，用一行引用块，例如：

```markdown
> 📖 写法细则（7 个口语手法 / 人称 / 断行 / 标点 / 三张书面腔对照表 / 上屏句长）
> 见 `references/02-口播写法.md` 的 3.2 / 3.3 / 3.16 / 3.18 / 3.19。**动到哪条查哪条，不必全读。**
```

## 六、不动的东西（安全边界）

- ⛔ **一条规则都不删除语义**，只做"搬家＋去重＋压缩连接词"。
- ⛔ 固定配置表的值、所有 Gate、脚本命令、数字口径（÷4.3、88/80号、150秒配额、840上限等）原样保留。
- ⛔ frontmatter（name/description/maxTurns）、plugin.json **不改**（md 外置不影响插件声明，无需注册新文件）。
- 改 cache 源 → 跑 `expert_pack_sync.py video-script-studio` → 四处 md5 一致。
- 重构后**逐条 grep 校验**：主文件里每个 `references/xx.md#锚点` 都真实可达、无悬空。
- 项目 `_资产/SOP变更日志.md` 原件不动，包内是副本（包要自洽）。
