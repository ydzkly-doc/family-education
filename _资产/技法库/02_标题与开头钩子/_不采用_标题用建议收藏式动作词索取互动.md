## 2. 为什么有效（先承认它有效）

- **降低决策成本**：读者还没读就被告知"这篇值得占用你的收藏夹"——**等于替读者做了一个决定**。
- **触发平台行为**：收藏是**强信号行为**（比点赞更能影响推荐），在算法上通常有正收益。
- **提供"以后会用"的心理许可**：家长面对教育类内容常有"现在没时间细看、但不该错过"的焦虑，**"建议收藏"正好接住了这个焦虑**。

## 3. 为什么本账号不采用

**⛔ 判定：`❌ 不适用`。三条理由：**

### ① 它是一句"动作指令"，只是位置挪到了标题

SOP 已有明确规则：
> 正文与文末卡片**不写"点在看/点赞/转发/求关注/分享给"等动作指令**，这类直白祈使句在治愈/共情类话题里很刻意、削弱信任。

**"建议收藏"与"点个在看"在性质上完全一致**——都是**向读者索取一个动作**。
→ **SOP 只规定了"正文与文末卡片"，没有规定标题 → 这是规则空白。**
→ **按同一条规则的精神，标题同样不应出现动作词。**

### ② 它把"内容价值"换成了"操作提示"

本账号的替代做法早写在 SOP 里：
> 把传播交给读者的自发触动。
> **正文用一句"祝愿式/共鸣式"收口**……文末卡片只表达陪伴定位。

→ 逻辑是：**内容值得收藏，读者自然会收藏；提醒一句，反而暴露了不确定。**
一个真正好的清单不需要说"建议收藏"——**这句话本身就是对内容自信度的一个打折**。

### ③ 与"不承诺"的调性同源

"建议收藏"常与"**少走10年弯路**""**看完你会更懂孩子**"连用——**这些是结果承诺**。
本账号要求"不绝对化承诺"。虽然"建议收藏"本身不含承诺，但**它出现在承诺句扎堆的标题生态里，读者会把它们归为一类**（"又是一篇让我收藏的鸡汤"）。

## 4. 反例与边界（怎么替代）

**✅ 替代方案：把"提示读者收藏"换成"让内容本身值得收藏"。**

| | 写法 | 效果 |
|---|---|---|
| ❌ 原版 | 有远见的父母都该明白的10条法则，建议收藏 | 乞求动作 |
| ⚠️ 半改造 | 有远见的父母都该明白的10条法则 | 干净，但仍无主体 |
| ✅ 全改造 | 我用了三年才明白的10件事，写下来给自己存档 | **"存档"说的是我自己，不是要求读者** |

**要点**：
1. **若要表达"这份内容值得留下来"，让主语是"我"** ——"我写下来留个底""怕忘，记在这儿"。
2. **不要在标题里出现任何动词祈使**：收藏 / 转发 / 看看 / 记得 / 一定要读。
3. **标题只承担两件事：说清内容 + 制造点击欲。** 引导互动交还给内容质量。
