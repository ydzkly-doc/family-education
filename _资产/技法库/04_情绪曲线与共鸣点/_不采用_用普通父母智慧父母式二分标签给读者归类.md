## 1. 原始出处

- **文章**：你和智慧型父母之间，只隔着这9张图片
- **账号**：无单一作者，多平台改写转载
- **原始范例**（每一卡的固定首拍，照抄）：

> **普通父母：**眼里的缺点永远＞优点
> **智慧父母：**缺点、优点，都是特点
>
> **普通父母：**控制型，我的想法都是对的
> **智慧父母：**合作型，我们有共同的观点

## 2. 为什么有效（先承认它有效）

**它传播上确实有效**，机制是：

1. **左栏写读者真做过的事**（"我是为你好"、拿别人家孩子比）——读者被迫承认"我就是这样"；
2. **右栏给一个更好的做法**——读者自然想要那个更好的自己；
3. **作者全程没有指责一句**——没有"你不该…""你必须…"，所有判断都是读者自己下的。

**它的狠处在于：把羞耻的施动者从作者转移给了读者自己。**
读者一边点头一边自我否定，**而作者是不担责任的**——因为作者只是"描述了两类父母"，没有评价读者。

## 3. 为什么本账号不采用

**⛔ 判定：`❌ 不适用`。三条理由：**

### ① 它是"制造羞耻"，且是隐性羞耻

`普通父母` 这个标签的运作方式，是**让读者给自己贴上"我很普通、我做错了"的标签**。
作者不说，读者自说——**羞耻的强度不因作者没说而降低，反而因为"是我自己想出来的"而更难反驳**。

### ② 与账号锚点直接冲突

- 账号锚点之一是 **"减少羞耻"**；
- 调性要求是 **"家长是被理解、被松绑的一方，绝不让读者觉得'你在说我做错了'"**。
- 而"普通父母"这一栏，功能就是**给读者归类、并暗示他属于较差的那一类**。

### ③ 它是已入库 ❌ 卡的"斯文版本"

本库 2026-09-14 已入库一张 ❌ 卡：《用"全看父母的嘴"式绝对化归因制造羞耻》。
本卡与它是**同一性质，只是包装更斯文**：

| | 已入库的 ❌ 卡 | 本卡 |
|---|---|---|
| 方式 | 明着归因（"全看父母的嘴"） | 给一面镜子，让读者自己照 |
| 读者感受 | 被指责 | 被理解着指责自己 |
| 羞耻强度 | 高、显性 | **中、隐性、更难防** |
| 本质 | 制造羞耻驱动行动 | **同上** |

> **结论**：**方式更温和 ≠ 性质不同。** 它比明着骂更难识别，也因此**更需要在库里留一条记录**。

## 4. 反例与边界（怎么替代）

**✅ 替代方案：把"对照人"改成"对照行为或对照场景"。**

| | 写法 | 效果 |
|---|---|---|
| ❌ 原版 | `普通父母：控制型` / `智慧父母：合作型` | 给读者归类 + 制造羞耻 |
| ⚠️ 半改造 | `以前我：控制型` / `现在我试着：合作型` | 标签从读者身上移到了"过去的我"身上 |
| ✅ 全改造 | `我原来只会说：你必须…` / `我现在试着说：你打算几点…` | **纯行为对照，不含对人的归类** |

**要点**：
1. **对照的两端都应该是"我"**（过去的我 / 现在的我），**不出现"某类父母"这种对人的分类**。
2. **如果一定要分两类，那两类的差别必须是行为，不是身份**。
3. **不要用"智慧/高明/合格"这类形容词修饰父母**——这些词的反面就是"不智慧/不合格"，仍然在归类。

**保留它什么**：**对照结构本身是好的**（一张卡解决一个具体差异，读者 3 秒看懂）——本库已有 ✅ 卡《卡内四拍》和《卡片式并列》吸收了这个结构。**本卡否掉的只是"对照的两端是人还是行为"。**

## 5. 与本账号既有规则的关系

- **冲突**：与账号锚点 **"减少羞耻"**、调性要求 **"家长是被松绑的一方"**、既有硬规则 **"并列式分论点不得同质"** 之外的 **正文禁例第 1 条（绝对化归因 + 制造羞耻）** 相冲突。
- **与"区分孩子和行为"锚点的关系**：本技术是**反向操作**——"区分孩子和行为"要求把评价落在行为上、不落在人身上；而本技术**把评价落在"父母"这个身份上**，并分类。方向相反。
- **补充说明**：本卡与已入库的《用"全看父母的嘴"式绝对化归因制造羞耻》**并列为同一类问题的两个变体**，后续遇到类似写法，可对照这两条判定。
