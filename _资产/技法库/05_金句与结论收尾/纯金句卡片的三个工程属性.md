## 2. 为什么有效

**三个工程属性，缺一个就失效**：

| 属性 | 具体做法 | 作用 |
|---|---|---|
| ① **一句一条** | 一条 = 一个编号 + 一句话 + 一张配图 | **读者每次只需处理一件事**，认知负荷趋零 |
| ② **极短** | 单条 15–60 字，最多不超过 3 句 | 扫一眼就能判断"认同 / 不认同"，**决定成本低** |
| ③ **独立可截图** | 每条都需能脱离上下文成立 | **天然适配收藏与转发**（截图即可传播） |

**配图不是装饰，是节奏工具**：
10 句纯文字连排会变成"金句墙"（视觉疲劳）；**插图把文字切开，强制制造停顿**，且图本身也是独立可保存的传播资产。（"点击查看原图"这一交互印证了图是独立资产）

**机制（推测）**：它放弃"结构牵引"（悬念、递进、冲突），改用 **"认同率累积"**——
不追求读者从头读到尾，只追求**在 10 次机会里中 3 次**。
→ **这是它与叙事文最根本的区别**：叙事文赌"一次打透"，金句卡片赌"十次轻触"。

**它为什么没有结尾**：**清单不需要收尾。**
因为整篇从头到尾**没有给读者施加任何压力**，所以也不需要"收场"。
（对照本库卡《结尾三步：抬升 → 松绑 → 给台阶》——那条卡的前提是"给完压力要负责收场"，本篇是**反例印证**：没压力就不需要收场。）

## 3. 改造示例（本账号用法）

**⚠️ 关键改造：本账号不能用"无主语的格言"，每条必须能回答"这是谁说的"。**

**❌ 无主语（不能用）**：
> 请不要掩饰你对孩子的爱意，请直接告诉孩子，你有多爱他。
（这是**谁**在说？读者无法知道，也无法核验，且与账号"同路人非导师"的根本定位冲突）

**✅ 三种合格写法（每句都有主体）**：

**① 我做过的事（主语 = 我）**：
> 有一次他考砸了，我没提成绩，只说了句"饭在锅里"。他愣了一下，去厨房吃了两碗。

**② 我观察到的事（主语 = 我在现场）**：
> 家长会那天，老师说"孩子最近状态不好"。全场二十几个家长，抬头的只有三个。

**③ 从书里／课里读到的（主语 = 出处）**：
> 《最温柔的教养》里有句话我记了很久：比起父母的初心，孩子更容易记住父母最后做了什么。

**要点**：
1. **单条 15–60 字**（与原版同量级），超了说明一卡塞了两件事，拆开。
2. **一条只讲一件事**。判据：**把这条单独截图发出去，别人看得懂吗？** 看不懂就是依赖了上下文。
3. **本账号每句必须落在"我做过 / 我看见 / 我在书上读到"三者之一** —— 这是与无主语格言的分界线。
4. **条数 5–9 条为宜**。

## 4. 反例与边界

- **⚠️ 最大的坑：无主语 + 无出处 = 格言 = 无可核验**
  原版 10 句全是无主语的祈使句/断言句（"请不要…""父母应…""合格的家长要…"），
  **这正是它可以被抹掉出处、任意冠名"法则"的原因——因为它本身没有归属。**
  → **本账号的硬约束**：**任何一句金句，都要能回答"这是谁说的、在哪说的"。** 做不到就换成"我的观察"。
- **什么时候用会翻车**：
  - **不要用它替代机制与方法**。金句卡片是**形式**，不是内容。如果一篇只能给 10 句结论、给不出一个机制解释，那这篇对本账号**没有价值**（SOP 五层完整性的要求不因形式改变）。
  - **不要用"法则/真相/铁律"这类词包装**。"法则"暗示无条件成立，而本账号要求"经验归纳写常见的几种情况，不写必然导致"。
  - **不要用它索取互动**（见本库 ❌ 卡《标题用"建议收藏"式动作词索取互动》）。
- **与本账号调性的冲突点**：
  - **它天然是"信息驱动"**（情绪:信息 = 0:10，本库已拆样本中最极端），与本账号"父亲叙事化"的默认写法距离最远。
  - → **建议定位**：**偶发使用**（如系列间歇期的轻量篇、或作为长文之外的补充形式），**不作常规形式**。

## 5. 与本账号既有规则的关系

- **冲突（部分）**：SOP 要求"**金句也要从具体情境里长出来**，不要像板书/标题"。本篇 10 句**全部是板书式的**——没有一句长自场景。
  → **但两者目标不同，可共存**。建议区分两类金句：
  | | 内生金句（现有规则） | 外置金句（本卡） |
  |---|---|---|
  | 从哪来 | 从本篇场景里长出来 | 自足结论 |
  | 作用 | 提炼本篇（**结果**） | 独立存在（**主体**） |
  | 适用 | 叙事文 | 句卡式轻量篇 |
  | 硬约束 | — | **必须有主语或出处** |
- **冲突（部分）**：与"父亲叙事化"（"多写我也吼过、吼完也后悔"）距离最远——**本账号用它时必须保留"我"**，不能真做成"作者隐身"。
- **强化**：与"结尾不索取互动""不绝对化承诺""核不到来源不写"三条同向（改造后）。
