## 1. 选题与角度

- **切口**：从一个家长的具体困境（花心思开了未成年人模式，却被孩子轻易解除）切入，追问**"限制在哪一环失效"**。
- **覆盖人群**：青春期孩子的家长，尤其是正在管手机、管游戏的那一批。
- **痛点深度**：表层是"孩子钻空子"，深层是**"我做了努力却无效"的挫败** + **"这事我一个人解决不了"的孤立**。
- **角度差异**（本次最值得记的一点）：
  - 亲子号写同一题材的通行角度是**指向家长**——「你怎么管孩子的」「你的方法错了」「要理解孩子」。
  - 本篇的角度是**指向系统**——平台审核宽松、实名认证形同虚设、灰色产业专门做破解生意。
  - **责任从家庭单点被移开**，这是它对本账号最有价值的地方。

**原句摘录**（选题的呈现方式）：

## 2. 标题与开头钩子

### 标题

- **标题原文**：谁解除了孩子的未成年人模式？
- **类型判定**：疑问悬念型（**但是一种特殊的设问**）
- **结构拆解**：疑问词「谁」 + 动作「解除」 + 对象「孩子的未成年人模式」
- **⭐ 钩子机制（本次核心发现）**：**这个问号的箭头指向外部，不指向读者。**
  - 「谁」是一个**待查明的责任方**（平台？灰色产业？制度？）——读者是**跟着一起查的人**。
  - 对比亲子号常见的设问「你是不是也这样管孩子？」——箭头指向读者，读者一进门就被审问。
  - **同一个问号，指向不同，读者的位置就从"被审"变成"同盟"。**

### 开头

- **前 3 行原文**：

> "孩子今年读初二，我特意在多个手机应用上开启未成年人模式。但没过几天，孩子就找到了'窍门'：卸载软件后，用家里老人的身份信息重新注册，或者干脆和同学在别处租用成年人账号……"

> 山西太原市读者侯婷近日来信表示，有关部门出台了规章制度，家长花心思设置未成年人模式，为什么还能被孩子轻易解除？

- **开头类型**：第三方来信（个案）+ 场景细节 + 设问收束
- **留人机制**：
  1. **细节可信**——"读初二""家里老人的身份信息""在别处租用成年人账号"，都是具体动作，不是"孩子会想办法绕开"这种概括。
  2. **设问挂住疑问**——"为什么还能被解除？"让读者想跟着看下去。
- **用了多久进正题**：第 2 段交代制度背景（国家网信办 4 月发布未成年人模式），第 3 段进入记者调查。**个案 → 背景 → 调查，三段内完成**。

- **骨架类型**：**个案（读者来信）→ 核查（记者调查）→ 责任分配（专家访谈）**

- **小标题的组织逻辑**：**问题范围逐步扩大**——从"平台自身的门槛低"，到"外部灰色产业成链"，到"所以这不是单方能解决的"。**是范围扩展的进程，不是并列分论点**。
- **段落节奏**：个案段短（2–3 行）→ 核查段中（交代多平台证据）→ 结论段短（引专家）。**整体是"短—长—短"的呼吸感**。

## 4. 情绪曲线与共鸣点

- **情绪走向**：

```
我也试过但没用（认同）
   → 原来这不是我一家的问题（正常化）
   → 有些环节确实不是家庭能补的（松绑）
   → 那我能做什么（落到实处）
```

- **共鸣位置**：第 1 段读者来信那句设问。

> 家长花心思设置未成年人模式，为什么还能被孩子轻易解除？

- **共鸣机制**：**把"我无能"重构成"这一环确实有洞"**。同一件事，前者归因于人（我），后者归因于系统（它）——**后者不给读者羞耻感**。
- **痛点放大手法**：**它没有放大痛点，而是扩散责任。** 这是它与爆款亲子文最本质的差异——爆款文把痛感层层做深、压在家长身上；这篇把痛点**拆成几块分给不同主体**（平台 / 灰色产业 / 政府 / 学校 / 家庭）。
- **共情句式**：无典型共情句。它靠**事实排列**建立共鸣，不靠"我知道你很难"这类安抚句。
- **情绪句与信息句的比例**：**信息句占绝对主体**（约 9:1）。全篇几乎没有抒情。
