# 技法库 · 索引与使用规则

> 公众号学习工坊（wechat-learning-studio）的沉淀层。
> 这里存的不是"好文章摘抄"，而是**从好文章里逆向工程出来的、可迁移的写作技法**。

---

## 一、这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 从外部好文章提炼的可复用写法 | 文章收藏夹（不收原文全文） |
| 每条都注明适用条件与边界 | 万能公式清单（不写"用了必爆"） |
| 写作时可直接翻查的参考读物 | 自动生效的规则（要经确认才进 SOP） |
| 诚实标注"未验证爆款" | 假装自己知道阅读量 |

**核心立场**：我们拿不到公众号真实阅读量。所以本库**不宣称任何技法是"爆款密码"**，
只回答一个问题：**这一招，能不能搬到我自己的文章里？怎么搬？**

## 二、目录结构

```
_资产/技法库/
├── README.md                  ← 本文件（索引 + 规则）
├── 00_技法总览.md              ← 所有技法的一页速查表（滚动更新）
├── 01_选题与角度/              ← 选什么题、从什么角度切
├── 02_标题与开头钩子/          ← 标题类型、打开率诱因、前3行留人
├── 03_结构与节奏/              ← 骨架类型、段落长短、信息密度、转场
├── 04_情绪曲线与共鸣点/        ← 共情位置、痛点放大、情绪句式
├── 05_金句与结论收尾/          ← 金句造法、结尾收法、转发冲动
└── _拆解报告/
    ├── _模板_拆解报告.md
    └── YYYY-MM-DD_<短标题>.md  ← 每篇原文一份完整拆解
```

**双层结构**：
- **拆解报告**（`_拆解报告/`）= 单篇文章的完整逆向工程，留痕用，看出"这篇整体怎么运作的"
- **技法卡**（五个维度目录）= 从报告里抽出来的**独立可复用单元**，写作时按需翻查

一份报告可能产出 0–5 张技法卡。**只有真正可迁移的才立卡**，凑数的和不立。

## 三、技法卡规范（立卡前必读）

每张技法卡必须包含以下 6 项，缺项不得立卡：

| 字段 | 要求 |
|---|---|
| **技法名** | 一句话说清是什么招，不用抽象词（✗"情感张力" ✓"用具体时间点开头代替抽象感慨"） |
| **原始出处** | 哪篇文章、哪个账号、哪句话是原始范例（附原句） |
| **为什么有效** | 机制解释。若只是猜测，必须写"推测" |
| **可迁移度** | `✅ 可直接用` / `⚠️ 需改造` / `❌ 不适用`（判定标准见下） |
| **改造示例** | 若是"需改造"，示范怎么搬到家庭教育题材；"可直接用"也要给一个本账号的例句 |
| **反例与边界** | 什么时候用会翻车（如：与本账号"克制、不煽动"调性冲突的写法） |

### 可迁移度判定标准

| 等级 | 含义 |
|---|---|
| `✅ 可直接用` | 与账号定位、人设（一个也在重启的爸爸）、读者群（青春期家长）不冲突，拿来即用 |
| `⚠️ 需改造` | 技法本身有效，但依赖特定条件（大号背书、虚构案例、强情绪煽动、特定领域黑话），搬来需替换内核 |
| `❌ 不适用` | 与本账号 P0 红线冲突（如：编造经历冒充真实、绝对化承诺、操纵情绪），**记录但永不采用** |

> ⚠️ **"❌ 不适用"同样要立卡**——它解释了"为什么这个爆款套路我们不用"，
> 防止以后重复研究同一件事。但卡片顶部必须标红：**本技法不采用**。

## 四、选题与筛选纪律

### 值得拆的（替代信号，因拿不到真实阅读量）

1. 被多个平台转载（转载本身就是市场投票）
2. 被专业拆解号拆解过（有人已经验证过它的传播力）
3. 来源为头部账号（洞见父母、凯叔讲故事、女儿派、武志红等）
4. 用户手动指定（用户偏好优先级最高）
5. 同一主题下被反复引用的"代表作"

**筛选记录必须如实标注证据等级**：

| 标注 | 含义 |
|---|---|
| `证据：多平台转载（N处）` | 较强信号 |
| `证据：专业拆解号拆过` | 较强信号 |
| `证据：仅头部账号，无转载数据` | 弱信号，仅"可能值得拆" |
| `证据：用户指定` | 不适用爆款标准，用户偏好优先 |
| `证据：未验证` | 诚实标注，不得当作爆款对待 |

> ⛔ **严禁**：编造"阅读量10万+"、"爆款"等未经核实的表述。核不到就写"未验证"。

### 不值得拆的

- 只有情绪、没有技法的（读完只会说"写得真感人"但说不出怎么写出来的）
- 与本账号题材无关的（如纯财经、纯职场，除非技法本身高度通用）
- 已经在技法库里研究过的同类写法（先去 `00_技法总览.md` 查重）

## 五、反哺工坊的纪律（P0 红线）

**技法库 → 工坊 SOP 的通道必须经过用户确认，不得自动写入。**

```
技法卡入库 → 累积到一定量 → 给用户一份"候选反哺清单" → 用户逐条确认 → 才改 SOP
```

- ❌ 禁止：拆完一篇就自动改 `wechat-article-studio` 的任何文件
- ❌ 禁止：把技法库里的经验直接当规则在写作时应用
- ✅ 正确：拆解→入库存档→**定期汇总候选**→用户点头→走专家包三处同步流程

**候选反哺清单的格式**（累积到 5–8 张新卡或用户要求时生成）：

| 候选技法 | 拟写入 SOP 位置 | 与现有规则的关系 | 建议 |
|---|---|---|---|
| （技法名） | （如 `02-writing.md` 第2步） | 新增 / 冲突需替换 / 已有只作强化 | 采纳 / 观察 / 驳回 |

## 六、维护

- 每拆完一篇，同步更新 `00_技法总览.md`（一页速查表）
- 定期回看：标注 `⚠️ 需改造` 的技法，若已在实践中改造成功，升级为 `✅ 可直接用`
- 与 `_资产/发布数据复盘.md` 交叉验证：本账号发布后，某技法是否真的见效
- **技法库不做清理**——它是知识资产，不设保留期（区别于过程文件）
