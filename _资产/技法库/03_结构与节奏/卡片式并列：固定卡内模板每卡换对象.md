## 1. 原始出处

- **文章**：你和智慧型父母之间，只隔着这9张图片
- **账号**：无单一作者，多平台改写转载（搜狐号 / 成都泡桐树小学官网 / 贤爸馆 / 峰哥说教育）
- **原始范例**（九个小标题，一字不改）：

> 01 关于孩子的特质 → 02 关于沟通 → 03 关于比较 → 04 关于视角 → 05 关于提问
> → 06 关于时间分配 → 07 关于学习 → 08 关于立场 → 09 关于生活角色

对照：**已入库的同质并列反例**（女儿派《懂得"闭嘴"》）——
"当孩子专注时，请闭嘴 / 想尝试时，请闭嘴 / 犯错时，请闭嘴 / 想倾诉时，请闭嘴"。

## 2. 为什么有效

**这条卡的真正价值：它说清了"并列式分论点同质"是怎么发生的、怎么防。**

把两个样本放在一起看，分野非常清楚：

| | 女儿派（反例·同质） | 本篇（正例·不同质） |
|---|---|---|
| 小标题的差异在 | **场景**在变（专注 / 尝试 / 犯错 / 倾诉） | **对象**在变（特质 / 沟通 / 比较 / 视角 / 提问 / 时间 / 学习 / 立场 / 自我） |
| 核心动作 | 四条全部相同：**减少父母的语言输出** | 各不相同：重框认知 / 改沟通姿态 / 换评价基准 / 换时间视野 / 改回应方式 / 改生活结构 / 改学习观 / 改教育手段 / 安置自我 |
| 读者的收获 | "说得很顺"，但**说不出四条的区别** | 能**各记一条**具体差别 |

> **成因判定**：**同质的成因 = 换场景而不换对象。**
> 换场景是最省力的"假装换角度"——因为场景唾手可得（专注时、犯错时、倾诉时），而对象需要真的想清楚这篇文章能管几件事。

**机制（推测）**：固定卡内模板让读者无需重新理解结构，**降低每一卡的进入成本**；而"每卡换一个对象"保证**内容不重叠**——于是形成"读起来很顺，但每张都有新东西"的效果。
**这是卡片式既有统一感、又不注水的根本原因：它的整齐是形式上的整齐，不是内容上的重叠。**

## 3. 改造示例（本账号用法）

**❌ 同质写法（换场景不换对象）**：
> 他写作业的时候，我把嘴闭上了 / 他玩手机的时候，我把嘴闭上了 / 他考砸的时候，我把嘴闭上了

**✅ 卡片式并列（固定模板 + 每卡换对象）**：
> **关于他的房间** —— 我只收拾公共区域，那扇门后面归他
> **关于他的手机** —— 我谈的是"几点交"，不谈"你为什么老想玩"
> **关于他的成绩** —— 我问"这次哪里最卡"，不问"你怎么又退步"
> **关于他的朋友** —— 我说"我不太放心这件事"，不说"你别跟那种人来往"
> **关于我自己的情绪** —— 我要走开的时候，就明说"我需要十分钟"

**要点**：
1. **先定对象清单，再动笔**——对象是"这篇能管的几件事"，不是"几个场景"。**列不出 5 个不同对象，就说明这篇撑不起并列式，改用递进式。**
2. **卡内模板固定**（统一句式/统一分栏/统一字数），**卡与卡之间对象必须不同**。
3. **自检方法**（沿用 SOP 既有的"核心动作提取"）：写完把每卡的核心动作写成一句话，**若两卡相同，合并或换对象**。
4. **对象数量 5–9 个为宜**：少于 5 撑不起"清单感"，多于 9 读者记不住、且必然出现同质凑数。

## 4. 反例与边界

- **什么时候用会翻车**：
  - **叙事文不要用**——它天然是"信息驱动"（情绪句:信息句约 2:8），用它会毁掉一条完整的心理进程线。
  - **对象必须真的不同**：硬凑到 9 个（比如把"关于学习"和"关于成绩"拆成两卡）就退化成同质。
  - **对象之间要有覆盖面**：本篇 9 个对象横跨"看孩子的方式 / 和孩子说话的方式 / 我自己的位置"三层，**有内在秩序**；若全是同一层的不同说法，仍是同质。
- **与本账号调性的冲突点**：**无**。它本身是中性结构。但**配套的"对照标签"必须改造**（见本库 ❌ 卡《用"普通父母/智慧父母"式二分标签给读者归类》）。

## 5. 与本账号既有规则的关系

- **强化 + 补全「并列式分论点不得同质」**（`02-writing.md` 硬检查）：既有规则给了**判定法**（核心动作提取），本卡补上了**成因**（换场景不换对象）与**解法**（固定模板 + 强制换对象）。二者不冲突，是同一个规则的两半。
- **强化「六种结构轮换」第 4 种**（清单/工具型：以可执行的步骤、对照表、排查清单为主体）：原文只给了方向，本卡给了可操作手段。
- **与本项目既有实践互通**：「父母做到这点孩子会有惊人改变」五篇卡片文章已用近似结构（含"对照卡"卡型），**本卡可用于回看那五篇是否符合"每卡换对象"**。
