# BGM 曲库

把音乐文件（`mp3` / `m4a` / `wav` / `flac` / `ogg`）放在**本目录**下，并在下面的表里标注风格。
管道按风格筛曲子时读这张表 —— 没有这张表也能用，但只能拿文件名当关键词猜，准确度低。

> ⛔ 本工具**不联网下载音乐**（版权风险）—— 曲子需要你自己准备。
> 合规来源举例：剪映曲库导出、平台自带免费音乐库、自购版权音乐。
> ⛔ 不要用来源不明的"热门歌曲"当 BGM —— 视频号会做版权识别，可能限流或下架。

## 怎么用

**① 只给风格，让管道自己筛**（推荐，多篇复用）

在文案 MD 的「上屏方案」里加一节：

```markdown
### 背景音乐
- 风格：安静的钢琴
- 位置：头尾
- 音量：比口播低约 22dB
```

**② 直接点名某个文件**

```markdown
### 背景音乐
- 曲目：钢琴_安静_60s.mp3
- 位置：全程
- 压低：10
```

**③ 查曲库里有什么 / 试一次筛选**

```bash
python <技能目录>/scripts/video_bgm.py --list
python <技能目录>/scripts/video_bgm.py --pick "安静的钢琴"
```

**④ 临时覆盖**（不改 MD）

```bash
--bgm-file 某首.mp3      --bgm-style "安静的钢琴"
--bgm-placement 头尾      --bgm-placement 全程
--bgm-gain -24           --bgm-duck 12
```

---

## 位置参数说明（`位置:`）

| 值 | 效果 | 什么时候用 |
|---|---|---|
| **头尾**（默认） | **只垫没有口播的地方** —— 开头到第一句话之间、最后一句话到片尾 | 口播为主、不想被音乐干扰；也最省事 |
| **全程** | 整片垫底，**人声一出现就自动压低**（ducking） | 想要"有音乐感"、节奏更满 |

> 头尾段**短于 1.2 秒**时不垫（一响就被切掉，反而突兀）——这种情况管道会**直接报错停下**并提示改用「全程」。

## 音量参考

| 参数 | 默认 | 说明 |
|---|---|---|
| `音量 / --bgm-gain` | **-24 dB** | 相对口播。当"氛围垫"而非"音乐"；-18 就已相当明显 |
| `压低 / --bgm-duck` | **12 dB** | 仅「全程」用：人声段再压这么多 |
| `斜坡` / `--duck-ramp` | **0** | 仅「全程」用：压低区间做渐变（秒）。**0 ＝ 硬台阶** |

> ⚠️ **默认值别照抄**（2026-10-01 实测教训）：
> · **`-24 dB` 可能根本听不见**——曲子本身轻（本曲 −18.8 LUFS）＋ 素材停顿处底噪高（−28~−32 dB）时，
>   音乐会被底噪整个盖住。**本系列实测用 `-12 dB`**。
> · **`斜坡` 不写＝硬台阶**，听感不是"压低"而是**背景音忽大忽小**。**「全程」一律配 `斜坡：0.35 秒`**。

> ⚠️ **BGM 会拉高峰值-响度比（PLR）**：含背景音乐的视频实测 17~19 dB，
> 而同时满足 `-14 LUFS` + `≤-1.5 dBTP` 要求 PLR ≤ 12.5 dB。
> 所以 BGM 音量给太大时，成片响度可能到不了 -14 LUFS —— **这不是 bug，是物理约束**。

## 本项目的配套工具（都在 `工具脚本/`）

| 工具 | 干什么 |
|---|---|
| `bgm_pick_even_segment.py` | 量一首曲子的逐秒电平 → 挑**最平的一段** → 做**无缝循环** ＋ 核验循环缝 |
| `bgm_build_library.py` | ⭐ **批量建库**：一批曲子 → 每首挑 1~n 段最平的 → 无缝循环 → **响度统一拉齐** → 出候选清单＋试听 |
| `bgm_timbre_probe.py` | 量**声学特征**（谱质心／谱平坦度／起音对比度），用于「像不像钢琴」的**相对**判断（⛔ 不能识别乐器） |
| `video_add_bgm.py` | 给**已出成片**补 BGM（画面 `-c:v copy`，不动定稿）；`--duck-ramp`、`--bgm-only-out` |
| `video_bgm_audibility_check.py` | 核验 BGM 垫没垫上、有没有漏进人声段、电平常态 |
| `video_timecode_offset.py` | 核对成片与 `timings.json` 的时间码偏移（成片若前置过封面卡，整体要平移） |

**重做循环版**（换曲子时照这个走）：

```bash
# ① 看电平曲线、挑最平段并出循环文件
python 工具脚本/bgm_pick_even_segment.py "BGM/某曲.mp3" --length 90 --xfade 2.5 \
    --out "_资产/bgm/某曲_等电平循环90s.wav"
# ② 把新文件登记到本文件的风格表
# ③ 文案 MD 里写：曲目 / 位置：全程 / 音量 / 压低 / 斜坡：0.35 秒
```
