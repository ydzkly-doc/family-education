# 第2篇 · 一键发布操作指南（个人订阅号 · 手动粘贴版）

> 公众号：**归途有光和孩子一起重启**
> 本篇正文**不含 `<img>` 外链图**——金句框、干货卡片全部是 table+内联样式画的，
> 粘贴进公众号后台会**自动保留色块和排版**，无需上传任何正文图。

---

## 🚀 5 步发布（约 2 分钟）

### 第 1 步：打开正文 HTML
- 打开成果文件夹里的 **`正文_第2篇_30秒速览.html`**（本文件夹内，双击用 Chrome/Edge 打开）。
- 页面任意处点一下 → **Ctrl+A 全选** → **Ctrl+C 复制**。

### 第 2 步：进后台新建图文
- 登录 https://mp.weixin.qq.com →「草稿箱」→「新的创作」→「图文消息」。
- 正文编辑区点一下 → **Ctrl+V 粘贴**。
- ✅ 检查：主题色标题竖条、金句框、内嵌卡片、“今晚3件事”色块都应完整保留。

### 第 3 步：填标题/作者/摘要
- 打开 **`01_标题作者摘要.txt`** 逐项复制：标题、作者（归途有光）、摘要。

### 第 4 步：设置封面（唯一需要“图”的地方）
- 封面**必填**（正文可不图，封面不能空）。比例 2.35:1（约 900×500），暖色、与正文主题色统一，画面不带文字。
- 用本发布包里的**封面候选图**（`封面候选*.png`，选一张）；上传后建议关闭“正文显示封面”。

### 第 5 步：预览 → 存草稿 / 发布
- 「预览」扫码发自己微信，**手机通读一遍**：重点看卡片有无横向溢出、金句换行是否自然（无孤字）。
- 无误 →「保存」进草稿箱；「群发」可定时（建议工作日晚 20:30–21:30）。

## ✅ 发布前自查清单

- [ ] 标题无错别字、戳痛点但不夸大失实
- [ ] 手机端：卡片、金句框完整，无横向溢出、无孤字换行、无白底断裂
- [ ] 作者、摘要已填
- [ ] 封面已上传（暖色、风格统一、画面无文字）
- [ ] 文末**来源声明在位**（读书笔记整理自威林厄姆《为什么学生不喜欢上学》，版权归原作者/出版方）
- [ ] **不声明原创**（读书笔记/学习心得，避免与原著版权冲突）
- [ ] 结尾是祝愿式收口，**无“点在看/转发/关注”等动作指令**
- [ ] 无绝对化表述、无口语残留（对吧/啊/那么）
