## 四、逐篇展开

### 第1篇｜重复犯错，不只是孩子的事

- **主标题**：孩子又犯同样的错，我也吼出了同一句话
- **备选**：我催儿子长记性，却忘了自己也在重复犯错
- **场景（改编）**：周日晚准备返校，儿子又落了一样用品；爸爸脱口而出“我说多少遍了”，突然想起上周自己也说过同一句。
- **转折**：提醒过不等于练会；允许反复，仍然可以要求把事情补好。
- **故事推进**：追着问为什么 → 儿子沉默 → 爸爸收回“你就是不长记性” → 先确认缺了什么、这次如何处理 → 留到平静时再找原因。变化只是儿子愿意参与补救，不写成从此不忘事。
- **核心台词**：“这件事确实要处理。先看看现在能怎么办，回头我们再找总漏掉它的原因。”
- **实用卡**：失误以后先分清三件事：发生了什么／眼下要补什么／下次要练什么。
- **我后来试的小事**：不加“总是”；一次只处理一件事；让孩子参与补救，不替他包办。
- **拟定金句**：他需要学会的，不只是认错，还有认错以后怎么办。
- **封面意象**：玄关边半开的书包与一件落下的用品，暖光。
- **下一篇**：那些随口说出的标签，怎样变成孩子对自己的判断。

### 第2篇｜把评价换成看得见的帮助

- **主标题**：我说儿子“总是粗心”，他回我“我就这样”
- **备选**：那道题又漏了，我这次没再说“你怎么这么粗心”
- **场景（改编）**：儿子订正一道漏答的小问，爸爸看见红笔就想说“这么简单也能漏”，儿子先回“我本来就粗心”。
- **转折**：先看漏在哪里，才能找到改什么；泛泛的骂和泛泛的夸都替代不了这个步骤。
- **故事推进**：给人下结论 → 两人不再讨论题目 → 爸爸改问“这题有几个要求” → 儿子圈出第二小问 → 爸爸只肯定这次实际做出的动作。
- **核心台词**：“这次第二小问没答。你愿意先圈出题目里的要求，再看是哪一步漏了吗？”
- **实用卡**：标签句／事实句／行动句三列对照，覆盖漏题、忘物和拖延。
- **我后来试的小事**：说具体位置；询问卡点；只表扬真实变化，如“这次你自己发现了漏的小问”。
- **拟定金句**：把“你是什么样的人”，换成“这一步可以怎么做”。
- **封面意象**：练习纸、圈出的第二小问与一支红笔；画面不要求生成可读文字。
- **下一篇**：不等出错才开始谈。

### 第3篇｜提前聊，是练判断

- **主标题**：出事前那十分钟，我终于没拿来讲道理
- **备选**：我不再用别人的错，给儿子上课
- **场景（改编）**：回家路上聊到一个“未经允许把别人东西借走”的日常情境，爸爸差点接上“你以后可别这样”，这次换成询问儿子怎么看。
- **转折**：提前讨论不是预先训话，也不需要拿可怕的结局吓孩子；把选择、对方感受和可能后果摊开说。
- **故事推进**：以前讲到最后总在影射儿子 → 这次明确只是讨论假设 → 儿子提出不同看法 → 爸爸听到自己漏想的一点 → 两人形成一个可记住的判断问题。
- **核心台词**：“如果东西是你的，你希望别人先问你什么？如果是你想借，又可以怎么开口？”
- **实用卡**：假设场景三问：还有什么选择／会影响谁／拿不准时向谁问。
- **我后来试的小事**：选普通小情境；不借题翻旧账；允许孩子不同意，不把聊天变考试。
- **拟定金句**：有些判断，可以在不用付出代价的时候，先练一遍。
- **封面意象**：并排的两杯水与一本摊开的书，桌面近景。
- **与第4篇边界**：本篇练一般判断；下一篇才针对即将到来的具体事情商量做法。

### 第4篇｜具体约定，早一点说清

- **主标题**：周日又赶作业，我把谈话挪到了周五晚上
- **备选**：我以为说过就算约定，儿子却不是这样理解的
- **场景（改编）**：周日晚又在找作业、赶进度，爸爸脱口而出“早跟你说了”；下一个周五，两人先把返校前要做的事排在纸上。
- **转折**：“早点做完”没有说清什么时间、哪些事情、做不完如何调整；约定要让孩子参与，家长能提供什么帮助也要讲清。
- **故事推进**：爸爸先想排满时间 → 儿子提出运动与休息 → 双方选定必要节点 → 约好中途检查，而非拖到周日晚追责。
- **核心台词**：“周末你想先安排什么？这些作业打算放在哪段时间？如果卡住，准备什么时候调整或找我帮忙？”
- **实用卡**：周末约定四格：要做什么／何时开始／怎么检查／卡住怎么办。
- **我后来试的小事**：让孩子先排；留出余量；家长说清能帮和不能帮的部分。
- **拟定金句**：约定要在事情开始前说清，不能等出错了才拿出来证明我早说过。
- **封面意象**：周末安排纸、铅笔与计时器，纸面不呈现可读文字。
- **下一篇**：有约定仍可能犯错，现场怎么办。

### 第5篇｜保留尊严，也留下责任

- **主标题**：儿子当众犯了错，我把那句批评留到了门外
- **备选**：我把儿子叫到一边，他才肯听我把话说完
- **场景（改编）**：做客时儿子没征求同意就使用别人桌上的物品，爸爸当着亲戚想数落一长串。这次先让行为停下来，再找不围观的位置说明。
- **转折**：需要制止的行为先制止，简短说明事实和补救；保护尊严不等于替孩子遮掩影响。
- **故事推进**：爸爸也有怕别人觉得“没教好”的难堪 → 把自己的面子和孩子的责任分开 → 单独重申约定 → 儿子归还物品、说明情况并完成适当补救。
- **核心台词**：“先把东西放回去，我们出去说两句。刚才没有征求同意，这件事需要你说明一下，看看有没有造成影响。”
- **实用卡**：现场四个动作：先停下／移开围观／说清这一件事／完成补救。
- **我后来试的小事**：不翻旧账；提醒保持简短；不逼当众检讨、不用羞辱交换认错。
- **拟定金句**：我可以认真处理他的错误，也可以认真保护他的尊严。
- **封面意象**：半开的门与两把靠近的空椅，物件构图。
- **补充边界**：涉及即时危险或持续伤害，先制止和保护相关人，不能为了“到门外说”延误处理；本文以普通日常失误为例。

### 第6篇｜让复盘落到下一次

- **主标题**：“下次注意”说过太多回，这次我们换了个办法
- **备选**：孩子说“我知道错了”，那场谈话才刚开始
- **场景（改编）**：同一种漏带又发生，儿子习惯性说“下次注意”；爸爸这次不要求再保证，而是与他回看装包时哪一步被打断。
- **转折**：复盘不是重播批评；它应当产出一个由孩子参与决定、下次可以观察的小调整。
- **故事推进**：想追问“你到底记没记住” → 改问发生顺序 → 发现只凭临出门想起 → 选一个固定放置或检查动作 → 下一次有改善，也可能仍有遗漏，再调整。
- **核心台词**：“先把那天怎么收拾的说一遍。你觉得哪一步最容易漏？下次只改一件事，你想先改哪件？”
- **实用卡**：三问一试：当时怎么发生／影响了谁和什么／下次换哪一步／试一次再看。
- **我后来试的小事**：等双方平静再聊；父亲也复盘自己的提醒方式；用实际结果判断办法，不要求“保证永远不犯”。
- **拟定金句**：复盘结束时，留下一个新办法，比留下一句保证更有用。
- **封面意象**：书包边一个固定收纳盘，用品集中放好。
- **收官**：回收四步方法图——平时提前聊，事前说清楚，现场处理好，事后试着改。首篇“又落一样东西”的故事在此回应，但每篇仍可独立阅读。
