# 第 3 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第3篇_批评表扬.html`**。全篇 table+内联样式，**零 `<img>`**，粘贴即图文完整。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第3篇_批评表扬.html` → `Ctrl+A` 全选 → `Ctrl+C`。
2. **新建图文**：公众号后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要，标题与正文大标题逐字一致。
4. **传封面**：上传本文件夹 **`封面_第3篇_批评表扬.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：重点看三明治卡、放礼花三栏卡、3 天打卡表是否横向溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：三栏"放礼花"卡不挤、三明治三段卡完整、3 天打卡不溢出
- [ ] 无"点在看/转发/求关注"等动作指令；无绝对化承诺

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 家长会回来，我占着理把儿子骂了一顿，他梗着脖子回我"我就这样"。
> 那晚我没睡好——我明明没错，为什么一说就把他推到对立面？
> 后来我学会：批评要像块三明治，两片软和的话，中间才夹那块真问题；
> 夸人要像放礼花，有对比、有观众、夸到他骨子里的品质。
> 一张能直接照念的填空卡，写在这篇里了。
