## 三、底图后处理（`_bg_prep.py`）

| 步骤 | 参数 | 说明 |
|---|---|---|
| ① 去水印 | 顶锚裁到 3:4 高（1024×1365） | 平台水印固定在 y>1425，裁切线 1365 之下自然出框 |
| ② 统一 3:4 | 横向居中裁 | 只裁不放 |
| ③ 缩放 | 1.213x → 1242×1656 | 放大倍数上限 1.30（超限即重生） |
| ④ 保护性暗化 | 封面 veil 0.20 / 收尾 0.14，色 `#241c14` | 保证浅色字可读 |
| ④b 轻微柔化 | `GaussianBlur(1.1)` | 减高频噪点，**JPEG 压缩率大幅提升**（关键：让 3:4 大图压进 100KB） |
| ⑤ 顶部压字区 | 封面 `strength=0.52` / 收尾 `0.30`，覆盖 60% 高 | 顶部渐变暗化，大字专用 |

**⚠️ 踩坑记录**：底图不做柔化时，封面卡压到 q=40 仍 102.7KB（超限）。
柔化后 **q=50 即 98.9KB 通过**。柔化只作用于底图，**文字是后画的，清晰度不受影响**。

## 四、文字排版（`_card_render.py`）

### 规格

| 项 | 值 |
|---|---|
| 尺寸 | 1242 × 1656（精确 3:4） |
| 安全边距 | 96px |
| 字体 | 微软雅黑（`msyh.ttc`）/ 加粗 `msyhbd.ttc` |
| 单张体积 | ≤100KB（q 自适应，从 92 递减） |

### 三季配色（第三季 · 给信心 · 暖金棕）

| 用途 | 色值 |
|---|---|
| 主色 | `#c0924f` |
| 深 | `#a47a3a` |
| 底带 | `#ecdfc6` |
| 页面底 | `#fdf6ef` |
| 正文墨 | `#33302b` |
| 深棕 | `#5c3a1e` |
| 暗底主字 | `#f5ecdc` |

### 排版引擎四条纪律（**防"两行重叠"坑**）

1. **只用一种绘制方式**：所有文字经统一出口，不混用"逐字绘制"与"整行绘制"；
2. **先算后画**：元素列表先算总高 → 整体垂直居中 → 再逐块绘制，**绝不用绝对 y 硬写**；
3. **行首禁则**：`NO_HEAD = 。，、；：！？）》”’%…·` 不出现在行首；
4. **渲染后自检**：越界 + 重叠断言（容器框只查越界，不参与重叠比较）。
