# 第 1 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第1篇_总纲.html`**（一份，不另存副本）。全篇用 table+内联样式绘制，**零 `<img>`**，粘贴即图文完整，无需上传任何正文图。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：用浏览器打开本文件夹 `正文_第1篇_总纲.html` → 页面里 `Ctrl+A` 全选 → `Ctrl+C`。
2. **新建图文**：登录公众号后台 mp.weixin.qq.com → 内容与互动 → 草稿箱 → 新的创作 → 图文消息 → 在正文区 `Ctrl+V` 粘贴。排版、卡片、打卡表会一起带过来。
3. **填字段**：照 `01_标题作者摘要.txt` 填【标题】【作者】【摘要】；标题与正文顶部大标题保持逐字一致。
4. **传封面**：上传本文件夹 **`封面_第1篇_总纲.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：点"预览"扫码在手机上看一遍 → 确认卡片不横向溢出 → 存草稿 / 定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字，且与正文大标题**逐字一致**
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位（扶鹰教育·王金海《青春期三十讲》）
- [ ] 手机端：12 站进度地图、7 天打卡表无横向滚动、字不挤
- [ ] 全篇无"点在看 / 转发 / 求关注 / 分享给"等动作指令
- [ ] 无绝对化承诺（"一定""彻底改变"等）
