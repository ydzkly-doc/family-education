# 视频卡片文章 v2 · 总体方案

> 版本：v2（覆盖 v1）
> 起草日期：2026-10-26（**二次修订**：用户明确"正文不超 800 字，扩写靠卡片"，本版为最终口径）
> 触发原因：v1 直接拿视频号口播稿当正文，内容单薄。v2 从根源解决——**卡片承载更多实质内容，正文适度扩写但不超长**。

---

## 一、核心定位（二次修订后）

| 维度 | v1 | v2（最终口径） |
|---|---|---|
| **正文字数** | 300–500 字 | **不超 800 字**（贴图短文仍是贴图短文） |
| **卡片承载** | 单卡 4–6 块、每块 30–50 字 | **单卡 5–7 块、每块 50–80 字**（卡片更"厚"） |
| **张数方案** | 3 张×5 篇 + 4 张×28 篇 = 117 张 | **沿用 v1 张数方案**（不变） |
| **扩写策略** | 几乎没扩 | **卡片加厚度＋正文适度加深**（论述/案例/细节放在卡片里） |
| **目录** | `视频卡片文章/` | **沿用同名**（v1 三篇已归档 `_归档/视频卡片文章_v1/`） |

---

## 二、扩写的"分寸"在哪

**不是把文章写长，而是把内容写"厚"**：

| 部位 | v1 现状 | v2 改法 |
|---|---|---|
| **卡片每块文字** | 30–50 字（一句话） | **50–80 字**（两句话：动作+细节／观点+原因） |
| **卡片块数** | 4–6 块 | **5–7 块**（多 1–2 块用来放机制解释或案例细节） |
| **正文** | 视频口播稿轻改 | **基于口播稿适度加深**：补一句机制解释／补一个具体细节／补一段边界提醒；**总长不超 800** |
| **金句/论点** | 沿用视频 | **不变**（金句原句、论点不动摇） |

**结果**：读者看卡能学到方法，看正文能把整篇串起来。**整体信息量翻倍，但单篇阅读时长仍控制在 2–3 分钟**。

- **辅材 A**：公众号长文 14 篇发布包 → 抽机制、方法步骤、案例细节、边界提醒（重新组织，不照搬整段）
- **辅材 C**：联网开放资料（**可选，最后补充**）→ 只查 DSM-5 等开放学术概念；核不到来源就不写

## 四、正文标准结构（≤800 字）

```
[开篇 100–150 字]
  一个具体场景/现象 → 引出核心点（视频封面大字）

[是什么+为什么 200–300 字]
  把视频一句话扩开：定义、机制、常见误解
  从长文/课程抽一两句支撑（标"书中提出/课程认为"）

[怎么办 250–350 字]
  方法步骤（2–3 步，每步配细节）
  关键细节放卡片，正文只点到

[边界 80–120 字]
  什么情况不适用、可能的反弹

[收尾 30–50 字]
  金句收束（视频原句）
```

## 五、卡片新规格（**这是 v2 真正的扩容点**）

### 单块文字量提升

| 元素 | v1 | v2 |
|---|---|---|
| **topic**（卡主题） | 12–18 字 | 12–18 字（不变） |
| **head**（卡头条） | 20–30 字 | 20–30 字（不变） |
| **单块 title** | 6–10 字 | 6–10 字（不变） |
| **单块 body** | 30–50 字 | **50–80 字**（**翻倍**） |
| **每卡块数** | 4–6 | **5–7**（**加 1–2 块**） |
| **footer**（卡底金句/提醒） | 12–20 字 | 20–30 字（**加一句**） |

### 张数沿用 v1（不变）
- **3 张**：03／04／06／08／10
- **4 张**：其余 28 篇
- **总计**：117 张

### 渲染参数调整
- **密度上限**放宽：0.42–0.78 → **0.42–0.85**（让卡片真能装下更多字）
- **正文字号**：44px → **42px**（每块多 30 字，字号微降 2px 保排版稳定）
- **行高**：54–62 → **52–60**（微调匹配）
- **块内垂直居中**：保留（v1 已修）
