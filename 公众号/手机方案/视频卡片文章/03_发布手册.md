# 03_发布手册（视频卡片文章 v2）

## 这是什么

33 篇「贴图短文」发布包，与视频号 00–32 共 33 条一一配套。每篇一包四件：

| 文件 | 用途 |
|------|------|
| `01_标题作者摘要.txt` | 标题／作者／正文字数／卡片张数依据／朋友圈转发文案／发布前检查清单 |
| `02_文章正文.md` | 完整正文（400–800 字，含来源声明＋话题标签） |
| `03_卡片贴图正文.txt` | 贴图短文版（320–460 字，可贴后台纯文） |
| `04_卡片JPG/` | 封面×1 ＋ 内容×3–4 ＋ 收尾×1（3:4 竖版，全部 <100KB，可直接传后台） |

## v2 与 v1 的区别

- 正文仍是贴图短文（≤800 字），但论述完整度提高：机制／边界／ tonight 最小一步，四段式齐。
- 卡片加厚：单卡 4–5 块（v1 是 2–3 块），每块 30–60 字；密度上限放宽到 0.92，目标密度 0.82。
- v1 三篇样板归档在 `公众号/手机方案/_归档/视频卡片文章_v1/`。

## 发布操作

1. 后台「图片/文字」模式 → 选「贴图」。
2. 按 `01_标题作者摘要.txt` 的「发布前检查」逐项过一遍：封面字与视频封面一致／阶段徽标／金句原句未改／来源声明／话题标签 4 个。
3. 上传 `04_卡片JPG/` 全部图（顺序即文件名序号），贴 `03_卡片贴图正文.txt`。
4. 需要长文版时用 `02_文章正文.md`。

- **辅材 C**：联网开放资料（只查开放式学术概念，核不到来源不写）——仅 26 篇启用（DSM-5／ICD-11 游戏障碍诊断要点，已核实：DSM-5 为 2013 年列入「待进一步研究」、9 条标准 12 个月内符合 5 条以上；ICD-11 于 2019 年正式纳入）
