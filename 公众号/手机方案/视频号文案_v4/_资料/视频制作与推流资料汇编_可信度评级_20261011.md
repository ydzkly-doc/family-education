# 视频号「制作 + 推流」资料汇编（含可信度评级）

> 检索日期：2026-10-11
> 目的：为《孩子与手机》33 条及后续系列的**拍摄、出片、上传、分发**沉淀一份可直接引用的参考；
> 每条都标注可信度，明确哪些能直接进 SOP、哪些只能当假设小范围验证。
> 范围：仅微信视频号（含视频号助手 / 公众号联动 / 微信生态），不含抖音、快手、小红书运营。

## 〇、可信度分级标准（先读这个）

| 级别 | 定义 | 能不能用 |
|---|---|---|
| **S 官方一手** | 微信/视频号官方帮助中心、视频号助手后台、"微信珊瑚安全""微信公开课"官方账号原文 | **可直接写进 SOP** |
| **A 官方转述（高可信）** | 新榜、见实、亿邦、腾讯新闻等对官方发布会/公告的转述，措辞克制、未夹带私货 | 可用，**关键数字仍以官方原文为准** |
| **B 行业报告 / 数据机构** | 三个皮匠、发现报告收录的白皮书，克劳锐/卡思等，含估算成分 | 看**趋势与方向**，不引用具体阈值 |
| **C 自媒体经验（待验证）** | 营销号、MCN、代运营文章，口径互相打架 | **只当假设**，小批量 A/B，不进 SOP |
| **D 明显编造 / 营销伪科学** | 精确到"点赞触达20%好友""完播45%进万人池"却无任何官方出处 | **一律不采信** |

> 总判断：**凡是带精确百分比阈值、又找不到官方出处的"算法规则"，一律按 D 处理。**
> 微信官方对算法的公开，只到"社交好友推荐 + 可自主调节"这一层，**从未公布过流量池阈值、百分比、计分公式**。

## 一、可直接进 SOP 的（S 级官方一手）

### 1. 封面比例：竖视频后台封面 = **3:4（1080×1440）** ✅已落地
- **官方原文**（视频号帮助中心 findeross.weixin.qq.com）：
  > "视频号封面的显示比例是 **3:4**，非该比例的图片用作封面会被裁切；竖视频只能设置一个封面。"
- 推论（我方已实测确认）：
  - 后台上传封面用 **3:4**，传 9:16 会按宽适配、居中裁掉上下，丢顶部色条/角标/编号。
  - **片头 2 秒封面卡仍用 9:16（1080×1920）满屏**（正片是 9:16，塞 3:4 会上下黑边）。
  - **朋友圈分享 1:1（1080×1080）主标 only**。
- 状态：**三载体 SOP 已固化，无需改动。**

### 2. 上传技术规格（视频号助手 channels.weixin.qq.com 后台口径）
- 容器/格式：**MP4、MOV**；编码 **H.264 + AAC** 兼容性最稳。
- 大小：**≤ 2GB**；时长：**≤ 60 分钟**（短视频后台通用上限；部分老文章写 30 分钟，以后台实际提示为准）。
- 定时发布：**可预约未来 7 天内**。
- 建议：**用电脑端"视频号助手"网页上传**，比手机端/微信传输压缩更少；
  **不要用"微信发给自己/好友"的方式传原片**（微信会先压一道，再被平台转码，二次劣化）。
- 平台**一定二次转码**，本地导出码率再高也会被重压——目标是"喂给平台一个高质量、规格标准的母版"，而非追求上传文件不被压。

### 3. 算法官方口径（2025-04-02 "微信珊瑚安全"《视频号算法推荐原理》，腾讯新闻 news.qq.com/rain/a/20250402A04KXF00）
官方**只公开了这些**，没有别的：
1. **主要靠社交好友关系推荐**；有独立"朋友 ❤️"标签。
2. **较多朋友推荐的内容，提升曝光排序**，并有"朋友今天都在看""多位好友推荐"提示。
3. 用户可在 **"设置—个性化推荐"** 自主增/减推荐类目，可对内容做**"不感兴趣"负反馈**，可**关闭个性化推荐**（关闭后只按热度 + 关注 + 朋友页展示）。
- **对我们的直接含义（可进 SOP 的运营原则）**：
  - 视频号的第一推手是**"值得被朋友转发/点赞"**，不是"卡算法阈值"。
  - 内容要做**"可社交传播"**（父母愿意转给配偶/家长群），而非单纯"求完播"。
  - 私域（自己公众号粉丝、家长群、好友）的**真实转发与点赞**是正经的、官方机制内的启动方式——但应是自然/口碑驱动，不是刷量。

### 4. 创作者权益与原创（support.weixin.qq.com 官方帮助 / 创作者权益指南）
- 支持**原创声明**、**合集（专辑）**、内容加热等；**搬运/抄袭会被降权或取消原创**。
- 有面向不同粉丝量级创作者的权益体系（"零粉"也有基础权益，随粉丝/活跃度解锁）。
- **对我们**：坚持原创声明、把系列（如"第一次月考 5 讲""孩子与手机 33 讲"）建成**合集**，利于连看与沉淀——可直接执行。

## 二、方向可信、可参考但别迷信数字（A/B 级）

### 5. 2025 微信公开课传递的平台导向（A 级，新榜等转述）
- 平台**鼓励原创、真人出镜、真实经验**；对**新作者有流量倾斜/扶持**。
- 官方看的是**正反馈与负反馈的综合**，不是单看播放/点赞绝对值；
  **"常读/常看的铁粉"比单纯粉丝量更有价值**。
- **对我们高度吻合**：真人爸爸出镜 + 真实家庭场景 + 垂类（家庭教育），正是平台鼓励方向；
  坚持垂直、持续更新、服务好"愿意追更的核心家长"，比追单条爆款更对路。

### 6. 本地导出码率建议（B 级，行业经验综合，非官方）
各家口径不一，取**交集的稳妥区间**：
- 1080p 竖版 H.264：**目标 8–12 Mbps**（复杂画面/中长视频可到 10–12M，简单口播 6–8M 也够）。
- 帧率 **30fps** 为主；若做 60fps 需相应提高码率。
- 音频 AAC，**≥128 kbps，48kHz**。
- 关键帧（GOP）按 2–4 秒、关键帧闭合，利于平台切片转码。
- **我们的做法**：现有 ffmpeg 管道沿用输入探测码率（实测 9.3–10M），已落在稳妥区间，**无需改**；
  以后若主动设码率，1080p 竖版用 **CRF 18–20 或 8–10M** 即可，别堆到 20M+（徒增体积，平台照样压）。

### 7. 发布时段（B/C 级，多源，结论方向一致、具体点位不一）
- **高度一致的方向**：晚高峰 **18:00–22:00** 是全天最高，早高峰 **8:00–10:00** 次之；
  多个来源提到**周五晚 / 周末**更活跃。
- 白皮书口径：晚高峰 18–22、早高峰 10–13；营销号口径：视频号 18–19 点、16–19 点等，**互相矛盾**。
- **对我们（家庭教育受众=家长）**：优先在**工作日晚 20:00–22:00（孩子睡后家长刷手机）**试，
  配合**周日晚**这类"为下周育儿做心理准备"的场景；
  **正确姿势是自己记录每条发布时间 × 24h/7d 数据，跑 2–4 周找自己受众的峰值**，不要照搬任何一张"通用时间表"。

### 8. 内容长度（B 级，行业报告 + 平台导向）
- 多个报告：**1–3 分钟短视频最受欢迎、消费最稳**；平台也在给中长/深度内容加权（知识/教育类）。
- **对我们**：与已定策略一致——**视频号短快、一条一个点、≤3:30、不设下限**；
  12 号这种需要讲透的可做 4–6 分钟长条，靠合集与铁粉承接，不必为"短"牺牲连贯。

## 三、只当假设、需自测，不进 SOP（C 级）

以下在营销号里流传极广，但**无官方出处、且彼此数字打架**，只能作为"可做小实验的运营动作"，**不能写成规则**：

- "发布后 **30 分钟/黄金 1 小时**冲互动决定后续推荐" —— 方向上**初始表现重要**合理（官方也认社交启动），
  但"30分钟定生死"是简化说法；另有"**7 天长效赛马**"一说，说明平台并非只看头几小时。
  → 可做：发布后在自己的家长群/朋友圈**自然分享一次**，观察即可；不刷数据。
- "**前 3 秒钩子**最重要" —— 作为**创作经验成立**（开头抓人对任何短视频都对），可继续坚持；
  但"前3秒跳出率必须<45%"这类阈值是编的。
- "完播率/点赞率/评论率到 X% 进下一级流量池" —— 阈值版本极多（45%、40%、完播35%…），**全部无出处**。
- 私域→公域逐级流量池、"L1 200–1000 播放 / L6 大推"这类层级与数字 —— 均为自媒体推测。
- "引导留言关键词领资料"等促互动套路 —— 与我们"不制造羞耻、真诚"的内容调性冲突，**不采用**。

**唯一被官方证实的"私域启动"，就是第一条第 3 点的社交好友推荐机制本身**；
具体怎么撬动，靠**内容值得转发**，而非任何阈值技巧。

## 四、明确判定为伪 / 不采信（D 级）

| 流传说法 | 判定 | 原因 |
|---|---|---|
| "点赞会曝光给点赞者 **20%** 微信好友" | ❌ 编造 | 无官方出处；微信绝不可能公开"按好友百分比曝光"，企鹅号转载文，系营销伪科学 |
| "转发触达 **50%** 直接好友 + **30%** 间接好友" | ❌ 编造 | 同上，精确百分比无来源 |
| "完播率突破 **45%** 自动进万人流量池" | ❌ 编造 | 无官方/权威信源，阈值是拍脑袋 |
| "停留 ≥**72 秒**、互动率 ≥**8%** 进 L1" | ❌ 编造 | 数字具体到秒和百分比，纯自媒体杜撰 |
| "点赞后看 5 秒才算有效、评论≥8字才计分、4K 初始推荐 +30%" | ❌ 编造 | 平台从未公布此类计分细则 |
| "社交推荐权重 55% / 算法 45%" | ⚠️ 存疑 | 各报告互相引用、源头不清，**只当"社交推荐很重要"的定性参考，不引用 55/45 这个数** |

> 提醒：上面很多出自**腾讯云开发者社区（企鹅号转载）**这类看似"腾讯系"的页面——
> **域名带 tencent/qq 不等于官方**，那是 UGC 转载渠道。我们这次专门核到的官方一手只有"微信珊瑚安全"与帮助中心。

## 五、对后续 SOP / 运营的"可用清单"（结论）

### 可以立刻做（官方/高可信支撑）
1. **封面三载体继续执行**：3:4 后台上传 / 9:16 片头卡 / 1:1 朋友圈（已落地，保持）。
2. **成片母版规格固定**：MP4(H.264) + AAC、1080×1920、30fps、码率 8–12M、≤2GB、≤60min；
   **一律走电脑端视频号助手上传**，不用微信传原片。
3. **每条做原创声明**；系列建**合集**（手机 33 讲 / 月考 5 讲）。
4. 运营主轴对齐官方算法：**做"家长愿意转发给家人/家长群"的内容**，靠真实社交启动；
   发布后在自有私域**自然分享一次**，不刷量、不玩领资料套路。
5. 坚持**真人出镜 + 真实经验 + 垂直家庭教育 + 持续更新**（平台明确鼓励原创真人、扶持新作者、重铁粉）。

### 列为"小实验"，用自己数据验证（先不写死）
6. **发布时段**：先固定工作日 20:00–22:00 + 周日晚，记录每条发布时间 × 24h/7d 的播放/完播/转发/关注，
   跑 2–4 周后用自己的数据定"我们受众的黄金时段"。
7. **建一张《发布数据表》**：编号 / 标题 / 发布时间 / 时长 / 24h播放·完播·点赞·评论·转发·收藏 / 7天数据 / 是否进合集 / 备注。
   用真实数据替代营销号阈值。
8. 前 3 秒钩子、一条一个点、时长 1–3 分钟为主——作为**创作经验继续**，但不当成"算法要求"。

### 明确不做
9. 不追任何"X% 阈值/流量池层级/点赞触达好友比例"的伪规则，不据此改稿或改排期。
10. 不做"评论扣关键词领资料""诱导点赞"这类与内容调性冲突、且可能触发平台负反馈的动作。
