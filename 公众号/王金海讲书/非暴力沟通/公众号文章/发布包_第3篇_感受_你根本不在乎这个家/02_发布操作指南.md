# 第 3 篇 发布操作指南

> 本篇为《非暴力沟通》系列**第 3 篇（非暴力沟通第二步·感受）**，共 7 篇。
> 正文文件：`正文_第3篇_我觉得你根本不在乎这个家这不是感受是指责.html`

## 五步发布（约 2 分钟）

1. **复制正文**：用浏览器打开本文件夹的正文 HTML → 页面里 `Ctrl+A` 全选 → `Ctrl+C` 复制。
2. **粘贴到后台**：登录微信公众号后台 → 新建图文 → 在正文编辑区 `Ctrl+V` 粘贴。排版、卡片、配色一并保留（全表格样式，无需上传任何正文图片）。
3. **填字段**：照本文件夹 `01_标题作者摘要.txt` 填写【标题】【作者】【摘要】；标题必须与正文顶部大标题逐字一致。
4. **传封面**：上传本文件夹封面图（2.35:1）。封面是本篇唯一需要上传的图片。
5. **手机预览** → 确认无误后存草稿 / 定时发布 / 发布。

## 发布前自查清单

- [ ] 标题与正文大标题、字段表【标题】三处逐字一致
- [ ] 本文为**读书笔记**，后台**不声明原创**（文末已有来源声明）
- [ ] 文末来源声明在位（扶鹰教育-王金海读书《非暴力沟通》）
- [ ] 手机端预览：卡片无横向溢出、左右不贴边、行距舒适
- [ ] 全文无"点在看 / 点赞 / 转发 / 求关注 / 分享给"等动作指令
- [ ] 无绝对化承诺

## 朋友圈 / 家长群转发文案（一屏内）

> "你根本不在乎这个家"——听起来是指责，剥开全是孤单。非暴力沟通第二步"感受"：把"我觉得你……"改成"我感到……"，说脆弱反而换来在乎。7篇读书笔记第3篇，附"想法→感受"对照卡。👇
