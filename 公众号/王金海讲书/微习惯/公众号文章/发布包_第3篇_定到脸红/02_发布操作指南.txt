发布操作指南 · 第 3 篇
================================

本篇主题：微习惯到底怎么定才立得住——缩到脸红、最坏一天测试、连问为什么、别拉高期望
主标题：把目标定到"说出来都脸红"，反而更容易做到

【5 步发布 · 约 2 分钟】

1. 复制正文：打开本文件夹的「正文_第3篇_定到脸红.html」（双击用浏览器打开）
   → 页面里 Ctrl+A 全选 → Ctrl+C 复制。
2. 后台粘贴：登录 mp.weixin.qq.com → 新建图文 → 在正文区点一下 → Ctrl+V 粘贴。
   排版、色块、卡片会一起带过去（正文无任何图片，无需上传正文图）。
3. 填字段：照「01_标题作者摘要.txt」填【标题】【作者】【摘要】；标题逐字复制，别手打。
4. 传封面：上传「封面_第3篇_定到脸红.jpg」；公众号封面必填，比例 2.35:1。
5. 预览发布：点"预览"用自己手机扫一眼 → 确认卡片无横向溢出、金句换行正常 → 存草稿或定时群发。

【发布前自查清单】

[ ] 标题与正文顶部大标题逐字一致（含引号、标点）。
[ ] 标题 ≤ 64 字，钩子在前 20 字。
[ ] 文末来源声明在位（扶鹰教育·王金海读书《微习惯》，原著 [美]斯蒂芬·盖斯）。
[ ] 本文为读书笔记/学习心得，不声明原创。
[ ] 全文无"点在看/点赞/转发/求关注/分享给"等动作指令。
[ ] 无绝对化承诺（"一定/必然/保证"等）。
[ ] 手机端预览：各卡片不超出屏幕、金句居中块换行正常、正文左对齐。
[ ] 作者名写作"斯蒂芬·盖斯"（非"盖茨"）。
