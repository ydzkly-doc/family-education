# 发布操作指南 · 第 2 篇

> 本篇主题：忙碌奔波型——为什么目标实现了也不快乐
> 主标题："等孩子考上大学就好了"，这句话骗了我们半辈子

## 5 步发布（约 2 分钟）

1. **复制正文**：打开 `正文_第2篇_等孩子考上大学就好了.html`（浏览器打开）→ `Ctrl+A` 全选 → `Ctrl+C`。
2. **后台粘贴**：mp.weixin.qq.com → 新建图文 → 正文区 `Ctrl+V`（无图片，排版随粘贴带入）。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要，标题逐字复制。
4. **传封面**：上传 `封面_第2篇_等孩子考上大学就好了.jpg`。
5. **预览发布**：手机预览 → 查卡片不溢出、金句换行正常 → 存草稿/定时群发。

## 发布前自查清单

- [ ] 标题与正文顶部大标题逐字一致（含引号、逗号）。
- [ ] 标题 ≤ 64 字，钩子在前 20 字。
- [ ] 文末来源声明在位（扶鹰教育·王金海讲书《幸福的方法》，原著 [美]泰勒·本-沙哈尔）。
- [ ] 读书笔记/学习心得，**不声明原创**。
- [ ] 无"点在看/点赞/转发/求关注/分享给"等动作指令；无绝对化承诺。
- [ ] 手机端：卡片不超屏、金句居中、正文左对齐。
- [ ] "我家孩子"为 15 岁男孩，人设一致。
