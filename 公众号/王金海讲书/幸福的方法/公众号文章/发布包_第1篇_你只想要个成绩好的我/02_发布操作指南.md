# 发布操作指南 · 第 1 篇

> 本篇主题：我们为什么弄丢了幸福（系列总纲）
> 主标题：儿子摔门："你根本不爱我，你只想要个成绩好的我"

## 5 步发布（约 2 分钟）

1. **复制正文**：打开本文件夹的 `正文_第1篇_你只想要个成绩好的我.html`（双击用浏览器打开）→ 页面里 `Ctrl+A` 全选 → `Ctrl+C` 复制。
2. **后台粘贴**：登录 mp.weixin.qq.com → 新建图文 → 在正文区点一下 → `Ctrl+V` 粘贴。排版、色块、卡片会一起带过去（正文无任何图片，无需上传正文图）。
3. **填字段**：照 `01_标题作者摘要.txt` 填【标题】【作者】【摘要】；标题逐字复制，别手打。
4. **传封面**：上传 `封面_第1篇_你只想要个成绩好的我.jpg`；公众号封面必填，比例 2.35:1。
5. **预览发布**：点"预览"用自己手机扫一眼 → 确认卡片无横向溢出、金句换行正常 → 存草稿或定时群发。

## 发布前自查清单

- [ ] 标题与正文顶部大标题**逐字一致**（含引号、标点）。
- [ ] 标题 ≤ 64 字，钩子在前 20 字。
- [ ] 文末**来源声明在位**（扶鹰教育·王金海讲书《幸福的方法》，原著 [美]泰勒·本-沙哈尔）。
- [ ] 本文为**读书笔记/学习心得，不声明原创**。
- [ ] 全文无"点在看/点赞/转发/求关注/分享给"等动作指令。
- [ ] 无绝对化承诺（"一定/必然/保证"等）。
- [ ] 手机端预览：各卡片不超出屏幕、金句居中块换行正常、正文左对齐。
- [ ] "我家孩子"为 15 岁男孩，与人设一致。
