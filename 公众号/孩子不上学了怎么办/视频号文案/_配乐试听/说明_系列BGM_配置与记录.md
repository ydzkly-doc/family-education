## 五、怎么复现（换条 / 重做时照抄）

**写法 A ⭐ 还没出片时用这个（推荐，05 起改用）**——把 BGM 写进 MD 的 `### 背景音乐` 节（放在「四、上屏方案」里），
**管道一次出片就带 BGM**，不用二次处理：

```markdown
### 背景音乐
- 曲目：传递的温柔_等电平循环90s.wav      ← 必须写全名（见「曲库.md」的告诫：别用「风格」筛）
- 位置：全程
- 音量：-12dB
- 压低：8
- 斜坡：0.35 秒
```
> 核验：`--dump-params` 的摘要行要出现 **「背景音乐 1」**；日志 `【BGM】` 段应显示
> `−12.0 dB｜全程垫底，压低 8 dB（N 段包络，0.35s 斜坡）`，
> 以及 ⭐ **「BGM 预补偿 +X dB（素材 … → 目标 …），有效 gain …」**——
> **写法 A 的 `音量` 值不用手算**：管道会先测「素材＋前置链」的响度，把 loudnorm 的抬升量自动扣掉
> （否则 BGM 会被整体响度补偿一起抬，比写法 B 的高 ≈11 dB，见经验第 9 条）。

**写法 B 已经出片了才补**（01~04 是这么做的，画面 `-c:v copy` 不动定稿）：

```bash
cd 公众号/孩子不上学了怎么办/视频号文案
python ../../../工具脚本/video_add_bgm.py \
  --video "0N_xxx/_成品/成片_0N.mp4" \
  --bgm "D:/个人资料/家庭教育/_资产/bgm/传递的温柔_等电平循环90s.wav" \
  --placement 全程 --gain -12 --duck 8 --duck-ramp 0.35 \
  --timings "0N_xxx/_成品/_过程文件/timings.json" --offset 2.0 \
  --out "0N_xxx/_成品/成片_0N_带BGM.mp4"
```

**核验（两种写法都要）**：

```bash
python ../../../工具脚本/video_bgm_series_check.py .        # 片长 / 压低占比 / 人声范围 / Δ
```
> ⛔ **写法 A 没有"无 BGM 原片"，Δ 那一列算不出来**（05 就是这样）→ 改用**逐秒 RMS 横向比**
> （与 01/04 比 中位/P10/P90，差 ≤1 dB 即同档），并确认**没有"数字静音"窗口**。

> ⚠️ **`--offset 2.0` 不能省**：四条成片都**前置了 2 秒封面卡**，`timings.json` 要整体后移。
> 三条独立证据一致：① 开头静音 2.33~2.39s；② 末句 +2.0 后片尾余量仅 0.10~0.24s；③ 抽帧看到静止封面卡。

## 六、经验（已写进专家包 SOP 与技能硬坑，这里只列一句话）

1. **别吃默认的 `-24dB`** — 曲子轻（−18.8 LUFS）＋ 停顿底噪高（−28~−32 dB）→ 音乐被底噪盖住，像"没垫上"。→ 音量实测定。
2. **「全程」必须配「斜坡」** — 不写斜坡时压低是**硬台阶**，听感是"背景音忽大忽小"（用户原话：「开头背景强，人物开始说话就变小了」）。
3. **别拿整首歌直接垫底** — 曲子自己的起落会被带进成片（本曲逐秒 RMS 极差 **79.8 dB**）。→ 取最平的一段做无缝循环（本系列取原曲 **95~185 秒**，极差降到 **8.3 dB**）。
4. **中段循环顺手解决"开头没音乐"** — 管道从曲子 **0 秒**起放，原曲开头约 2 秒是静音前奏 → 直接垫整曲时封面卡那几秒一点音乐都没有。
5. **`头尾` 模式在本系列不可用** — 见第二节。
6. **已定稿的不回改 MD** — BGM 由出片后补加（不动定稿、不重跑管道）；**还没出片的，就把 BGM 写进 MD**
   （写法 A，**05 是第一次这么做**：管道一次出片，少一道工序、也少一次音轨重编码）。
7. ⛔ **"合成时就带 BGM"时，日志那条 PLR 警告是虚警**（2026-10-02 05 实测）：
   日志报 `PLR 26.74 dB｜超标 14.24｜预计只能到 −28.2 LUFS`，但**成片实测 −14.6 LUFS / −2.4 dBTP**（PLR 12.2）
   —— 那条分析测的是混音中间件 `_bgm_mix.wav`（float wav 有 **+1.1 dBTP** 过冲），
   **最终 loudnorm ＋ alimiter 已经把它拉到位**。→ **判据只看成片实测**，别因此重跑。
8. ⛔ **抽帧自查要认"有没有前置封面卡"**：`video_check_frames.py` 不给 `--offset` 时
   **默认按 +2 秒**（它以为已加封面卡）→ **管道刚出片时要用 `--offset 0`**，
   否则抽到空档、会误判"**字幕根本没烧上**"（本次白排查一轮）。
   稳的判据：**读 `subs.ass` 的行区间、取中点抽帧**。
9. ⛔ **写法 A 与写法 B 对同一个 `音量` 值，结果差 ≈11 dB**（2026-10-02 用户听出「第五条明显比前四条高」）：
   · **A（合成时带）**：BGM 在 loudnorm **之前**混入 → 素材被判"偏轻"时，**loudnorm 的整体增益会把 BGM 一起抬**
     （本次素材 −25.7 → 目标 −14 = **+11 dB**）→ BGM 实际 ≈ −19.3 LUFS，明显盖过 01~04。
   · **B（事后补加）**：输入是**已归一化的成片** → loudnorm 增益 ≈0 → BGM 停在 −30.3 LUFS。
   → ✅ **已修**：管道加了**预补偿**（混音前测素材响度，把 gain 预扣掉抬升量；本次有效 gain −23.6）。
   **两条路径的「BGM 相对口播」现在只差 0.15 dB**（−16.1 vs −16.25）。→ 硬坑 **hk54**。
   📌 **核验口径**：别再单看"最安静窗口"（会被素材底噪掩蔽），**用「BGM 相对口播」这个差值**。

> ℹ️ 细则：专家包 SOP「BGM 六条」｜技能 `SKILL.md` 硬坑 **hk51**（硬台阶→忽大忽小）、**hk52**（整曲垫底→取平段循环）。
