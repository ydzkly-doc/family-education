# 《智慧父母实践课》公众号系列选题规划（Gate 1）

日期：2026-09-28。状态：待用户确认选题；尚未写正文、制作发布包或生成封面。

## 一、这次不再多讲一遍道理

内容类型：课程学习心得与家庭实践方法文，不是作者家庭纪实，也不是课程宣传。

系列主线：把“我知道应该这样”变成一件能商量、能试做、能复盘的小事。每篇只解决一个家庭现场，不要求父母一次改变全部，也不承诺孩子必然变好。

核心读者：家有学龄孩子、尤其是青春期孩子的父母。已经学过尊重、鼓励和边界，仍在具体执行时卡住：道歉说不出口、会议变训话、家务总接手、约定一再落空。低龄课程例子进入青春期文章时，明确标为原则迁移，不照搬幼儿语气和任务。

建议 8 篇：资料涉及爱的表达、情绪、自我价值、家庭会议、责任、自律、感恩和成长支持，压成三五篇容易重新变成大而全的清单。按“修复对话 → 看见进步 → 一起商量 → 交还责任 → 复盘约定 → 看见付出 → 保留支持 → 发现能力”推进，不机械对应课次。

正文预计每篇约 1600–2200 字，以案例、判断和小实践写足，不为凑字数增加故事。每篇提供一段可参考的对话及一次小试验，但不统一套成“三点方法＋三件事＋祝愿”的模板。

## 三、8 篇具体选题

### 1｜冤枉孩子以后，别用“我也是为你好”收场

- 备选标题：父母说错了，怎样道歉才不变成另一场说教？
- 痛点：以为孩子没写作业，事实查清后，父母仍想保住面子。
- 核心：先为自己的判断和说法负责，再处理尚未解决的事情；道歉不撤销合理规则。
- 来源：1–4 原文 P74–86，尤其 P80–82 的作业误会；12 原文 P2–4 的支持与责任。P 为 Word 正文段落序号，详见素材索引。
- 类型与结构：对话拆解文；误会现场 → 两种无效收场 → 道歉句里的责任 → 情绪平复后处理事情。
- 案例：作业误会保留为课程第三人称，不改成“那晚我走进儿子房间”。不复述完整情绪四步法。
- 示例说法：改编——“刚才我没查清就说你偷懒，这句话不公平。对不起。你愿意告诉我刚才是什么情况吗？”
- 小实践：选一次判断错误，只道歉，不接“但是你也……”；记录自己是否听完了孩子的回应。
- 边界：孩子不必立即原谅、拥抱或解释；持续暴力、欺凌和自伤风险不靠一次对话处理。
- 衔接：关系修复后，下一篇讨论怎样让孩子知道自己具体做对了什么。

### 2｜把“你真棒”说具体，孩子才知道哪里做对了

- 备选标题：孩子做成了一件事，除了夸聪明，还能说什么？
- 痛点：鼓励很多，孩子却觉得敷衍，或只在意大人的评价。
- 核心：描述事实、指出有效策略，再听孩子自己的感受；不是把“聪明”机械替换成“努力”。
- 来源：5–8 原文 P1–20，尤其 P14–19；12 原文 P16–18，尤其 P17 的足球表现反馈。
- 类型与结构：反馈方法文；足球例子 → 泛泛夸奖与具体反馈对照 → 做不成时怎样回应 → 留给孩子的自评问题。
- 案例：课程里进球后只被指出一次失误的孩子；不声称有作者亲历或成绩提升数据。
- 示例说法：改编——“这次你先列了要做的事情，漏项比上次少了。你觉得哪一步最有帮助？”
- 小实践：记下一件可观察的变化；说事实而不贴人格标签，听孩子是否认可这项变化。
- 边界：不宣布“真棒”不能说；肯定不等于忽视错误，也不变成“夸完马上提更高要求”。
- 衔接：从大人的评价转到全家共同表达和商量。

### 3｜家庭会议怎么开，才不会又变成批评大会

- 备选标题：全家坐下来谈一次，只解决一件小事
- 痛点：一说开会，孩子就知道又要听训；父母准备了答案才让大家发言。
- 核心：真正讨论的是可以共同决定的事情；每个人能提出意见，最后形成有限、可调整的试行约定。
- 来源：5–8 原文 P21–49，尤其 P35 的冰箱留言、P41–47 的角色与流程。
- 类型与结构：过程叙事＋工具；孩子留言想谈 → 大人怎样回应 → 一场短会议的推进 → 没谈拢怎么办。
- 案例：课程中孩子留言“很生气、想谈”的例子；会议示范另标改编，不虚构后续和解。
- 示例说法：改编——“今天只谈饭后怎么收拾。先听大家的办法，再选一个试一周，不顺再改。”
- 小实践：由家庭共同选一个小议题；首次约 15 分钟是本系列的试行建议，不是课程硬标准。轮流说、写下一个约定，约定复盘时间。
- 边界：不逼孩子当众忏悔；基本照护、安全底线不能投票取消；孩子可暂不发言，成人承担最终照护责任。
- 衔接：会议中谈定分工后，下一篇处理大人最难做到的“不接手”。

### 4｜家务交给孩子以后，最难的是大人不接手

- 备选标题：想让孩子有责任心，先把一件家里的事交给他
- 痛点：嫌慢、嫌做得不好，父母一边包办，一边埋怨孩子不负责。
- 核心：任务需要可选择、标准清楚、技能教过、允许练习；交还责任不是撤走支持。
- 来源：9–11 原文 P15–29；5–8 原文 P112–116 只作主题承接，不重复当新课。
- 类型与结构：机制＋生活流程；包办循环 → 选任务和教技能 → 何时帮、何时等 → 一周复盘。
- 案例：课程中的端菜、做饭、打扫等分工；实际示范改用低风险的饭后收拾或整理书包，注明改编。
- 示例说法：改编——“这周你愿意负责收桌子还是整理玄关？我们先一起做一次，看看完成标准。”
- 小实践：孩子从两个合适任务中选一个；成人演示一次，约定支持方式，复盘时谈困难而非给人格打分。
- 边界：年龄、能力和安全优先；不假装生病迫使照顾，不把成人经济压力交给孩子，不把基本照护当奖惩。
- 衔接：分工有了，如何处理没有完成的约定？

### 5｜约定总是做不到，先别急着说孩子不自律

- 备选标题：说好半小时，最后用了一个小时：先复盘哪里估错了
- 痛点：双方都答应了，却因为时间估计、任务不清或临时变化再次争执。
- 核心：把人格批评换成执行复盘：约定是否具体、能力是否足够、环境是否支持、大人是否也守约。
- 来源：9–11 原文 P64–77，尤其 P70–75；结合家庭会议的试行思路，标为本系列综合应用。
- 类型与结构：问题诊断文；约定落空 → 看事实而非猜动机 → 改一个条件 → 下一次复盘。
- 案例：课程关于守时、兑现承诺的讨论；具体“整理用时”对话为改编，不重新写手机管理教程。
- 示例说法：改编——“我们预计半小时，实际花了一小时。是开始晚了、步骤没算全，还是中间有别的事？下次改哪一项？”
- 小实践：选一件小任务，由孩子估时、完成后对照，再调整一个条件；不要求立即精准。
- 边界：不以延迟食物、睡眠或就医训练自律；长期执行困难不简单归为懒惰；不以一次试验预言未来。
- 衔接：家庭秩序不仅是执行，还包括彼此的付出被看见。

### 6｜想让孩子懂得感恩，先让家里的付出被看见

- 备选标题：一句谢谢之外，孩子还能怎样回应别人的帮助？
- 痛点：父母忍不住算付出、讲苦难，希望孩子被感动，最后变成内疚和抵触。
- 核心：让具体帮助可见，让回应可以自主选择；感恩不是情感债务，更不是必须服从。
- 来源：9–11 原文 P94、P104–109；借用 P106 分享最后一块柚子的课程例子。
- 类型与结构：日常观察文；柚子小事 → 看见谁做了什么 → 把谢谢落到适合的行动 → 不强迫表态。
- 案例：柚子例子为课程转述，不把分享写成衡量孝顺的试题。
- 示例说法：改编——“今天奶奶帮我们准备了饭。你想怎么回应她？说一声谢谢，或者一起收拾，都可以。”
- 小实践：成人先具体感谢一次，不催孩子模仿；邀请孩子选择一项力所能及的回应，允许拒绝身体接触。
- 边界：不制造饥饿寒冷，不展示贫困者隐私，不以公益真假不重要为由传播未经核实项目。
- 衔接：看见别人的付出，也要让孩子知道支持不是靠表现换来的。

### 7｜孩子没做好时，怎样让他知道你仍然站在他这边

- 备选标题：有边界的支持，不是“随你怎样都可以”
- 痛点：父母想表达担心，却出口成了“再这样就别来找我”。
- 核心：关系支持、行为底线和孩子责任分开说；允许求助，不代替承担。
- 来源：1–4 原文 P33–38、P51–52；5–8 原文 P52–54；12 原文 P2–4。
- 类型与结构：概念辨析＋对照；条件式支持的语言 → 支持／责任／底线三个位置 → 一句有条件的话怎样改 → 何时提供帮助。
- 案例：不使用摔裙子后挨打的故事作为“爱”的示范；采用明确标记的未完成任务改编场景。
- 示例说法：改编——“这次没完成，我们还要一起看怎么补上。我不会因为这件事不爱你；需要帮助时可以说，但属于你的部分还要由你做。”
- 小实践：找一句带抛弃意味的口头禅，分别写清担心、底线与支持，不靠重复“相信你”施压。
- 边界：不推出幼年照护决定终身的宿命结论；支持也不意味着替孩子掩盖伤害他人的行为。
- 衔接：在有支持的关系中，让孩子有机会展示自己的能力。

### 8｜试着让孩子教你一次，不急着把他的兴趣变成成绩

- 备选标题：孩子热爱的那件事，你愿意先当一次学生吗？
- 痛点：父母一靠近孩子兴趣，就开始纠正、评估有没有用，孩子越来越不愿分享。
- 核心：短暂让出指导位置，具体理解孩子会什么、喜欢什么，再商量下一步；兴趣不是必须立刻变现的项目。
- 来源：12 原文 P10–24，尤其 P20 的搭积木例子，P37–39“做孩子学生”的课程任务。
- 类型与结构：场景递进文；低龄搭积木例子 → 明确年龄迁移 → 青春期兴趣示范 → 听完后不过度安排未来。
- 案例：搭积木是课程案例；青年兴趣对话为改编，可用绘画、运动、工具操作等，不捏造作者儿子的爱好。
- 示例说法：改编——“这个我不懂，你愿意教我最基础的一步吗？我先照你的办法试，不急着提建议。”
- 小实践：邀请孩子选一件愿意教的事，给一次不被打断的示范机会；结束问“哪个部分你最喜欢”，不马上报名或定目标。
- 边界：孩子可以不愿意教；有风险的活动需成人守住安全，不把照顾父母情绪、解决成人事务交给孩子。
- 收尾：回到系列主线——挑一个小实践继续，而不是给八篇方法全部打卡。
