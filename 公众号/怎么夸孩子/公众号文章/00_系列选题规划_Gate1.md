## 二、规划表（3 篇）

### 第 1 篇 · 共情 · 叙事型（2000–2800）

| 项 | 内容 |
|---|---|
| **标题（主）** | 我夸了他十年，他却越来越听不得一句重话 |
| **备选 1** | 孩子只能听好话？先说清：夸得太满也是压力 |
| **备选 2** | 不是孩子玻璃心，是他的"好话"被喂得太满 |
| 标题类型 | 主=情绪共鸣｜备1=问题解决｜备2=认知反差 |
| **痛点场景** | 考好了要夸，考砸了连一句"下次注意"都听不进；一句重话就崩、就急着辩解 |
| **核心观点** | 笼统、满额的夸奖，会让孩子把"被夸"当成必需品，**不再被夸时反而怀疑自己**（**课程认为**：反馈语言塑造孩子对"能力"的解释方式） |
| **金句小标题** | ①他不是玻璃心，是被夸得太满　②满分的夸奖，是另一种压力 |
| **选用例子** | 课程里"被夸能干、听不得半句玩笑的孩子"——**第三人称/课程案例**，开篇标注改编 |
| **今晚 3 件事** | ①今天挑一句夸，**减掉一半形容词，换成具体一件事**　②夸完不追加"但是……"　③数一数自己一天说了几次"你真棒" |
| **卡片建议** | 卡1「过度表扬的三个信号」（只接受夸／听不得批评／怕输） |
| **建议发布时机** | 开学季 或 月考后（家长最集中谈成绩的窗口） |
| **篇职能** | 共情 |
| **篇幅档** | 叙事型 2000–2800 |
| **开场设定** | **晚上 ／ 餐桌 ／ 他报喜那一下，我脱口而出的夸** |
| 篇间承接 | 系列开篇 |

### 第 2 篇 · 实操 · 方法型（1200–1800）

| 项 | 内容 |
|---|---|
| **标题（主）** | "你真棒"说腻了，试试这五句能照念的话 |
| **备选 1** | 夸孩子夸不到点上？五句现成的话，今天就能用 |
| **备选 2** | 夸事，别夸人——一句话的差别 |
| 标题类型 | 主=问题解决｜备1=问题解决｜备2=认知反差 |
| **痛点场景** | 道理都懂，可真到嘴边还是"你真棒""真聪明" |
| **核心观点** | 鼓励不是天赋，是可练的句式；**把"夸人"变成"夸事"，孩子能照着长** |
| **金句小标题** | ①夸事，别夸人　②夸他能重复的动作，不夸他改不了的天赋 |
| **内容（去重合并，标来源层级）** | · 三个鼓励句式（**书中提出**）："我看到……"／"你通过……所以……"／"在这件事上，只是因为……还需要加强而已"<br>· 表扬三要（**课程认为**）：要有对比（跟自己过去比）／要有观众（人前夸）／要有高度（夸到品质）<br>· 话术转换（**课程给出**）："你真棒"→"你找到了自己的方法" |
| **今晚 3 件事** | ①挑一句今天就用　②写一张鼓励贴　③把"你是怎么做到的？"问出去 |
| **卡片建议** | 卡2「能照念的夸人话·五句」（收藏型） |
| **建议发布时机** | 紧跟第 1 篇（一周内） |
| **篇职能** | 实操 |
| **篇幅档** | 方法型 1200–1800 |
| **开场设定** | **傍晚 ／ 书桌边 ／ 他刚做完一件事，我张了张嘴没说出来** |
| 篇间承接 | 承接第 1 篇"那到底该怎么夸" |
