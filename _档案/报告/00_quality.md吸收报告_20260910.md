其 `origin.md` 明确写着：**由用户提供的 `wechat-article-studio.zip` 迁移而来**，且"后续原专家包更新不会自动同步到此版"。

**结论：两者是同一套 SOP 的两个平台版本**，Codex 版把内容按职责拆成了 5 个专题文件，WorkBuddy 版是单文件 434 行的完整 SOP。所以处理原则是——**取增量、不照搬**。

## 二、用户拍板的两项决策

### 决策 1：字数区间 → 折中 **1600–2400** 可见字符

quality.md 两处建议 **1400–1800** 字符（1400–1800 普通稿 / 1800–2200 深度稿）。我先做了实测：

| 系列 | 可见字符（最小 / 中位 / 最大） |
|---|---|
| 解决孩子沉迷手机（8 篇） | 1833 / **2309** / 3256 |
| 父母做到这点（5 篇） | 1836 / **1859** / 2035 |
| 为什么学生不喜欢上学（8 篇） | 1069 / **2361** / 3049 |
| 青春期30讲（18 篇） | 1679 / **2309** / 3260 |

现有 39 篇中位 **2309**，而 SOP 旧值写着"2000–2500 字"——也已与实际脱节。

**最终定标（用户确认）**：

| 类型 | 区间（中文可见字符） |
|---|---|
| 普通完整稿 | **1600–2400** |
| ├ 偏轻的日常稿 | 1600–1900 |
| └ 核心方法 / 深度复盘 | 1900–2400 |
| 速览 / 短答 / 单张清单 | 900–1400 |

**理由**：既不推翻已发布的 106 篇，又给新稿比"2000–2500"更克制的护栏；1400–1800 会让现有绝大多数文章被判"过长"。

## 三、吸收进 SOP 的 6 条 + 2 处修正

| # | 条目 | 内容要点 | 写入位置 |
|---|---|---|---|
| 1 | **五层完整性** | 原"四要素"（场景·机制·方法·边界）**补入「父母心理/认知转折」为第二层**——缺了它，文章只剩对家长的评判与指令，共情断掉 | 第2步完整性红线 + 第9步7b + 输出规范 |
| 2 | **删改降幅 30% 复核线** | 改写前后各记一次字符数；**降幅 ≥30% 必须额外复核叙事张力 / 情绪承接 / 方法细度 / 阅读节奏**。30% 是**复核触发线，不是写作规律** | 第2步完整性红线 |
| 3 | **相邻篇语言指纹** | 判定单位是**"相邻"而非"全系列累计"**——相邻两篇不连续用同一转折词、同一收尾、同一标题结构 | 第2步句式节流后 |
| 4 | **不强制装配件** | 不要求每篇都有金句块 / "三件事" / 完整系列地图 / 下篇预告；系列地图只在首末篇 | 第2步 |
| 5 | **"结构稿" ≠ "可发布成稿"** | 未达厚度不得称可发布；补内容只能用已确认素材，禁重复金句/同义改写/无据结论/新编事件填篇幅 | 第2步 + 输出规范 |
| 6 | **备选标题同样要过证据关** | 1 主 2 备**每一个**都要正文兑现、事实站得住 | 第1步标题规范 |
| + | **字数标准修正** | 旧"2000–2500 字" → **1600–2400 可见字符** | 第2步 + 输出规范 |
| + | **巡检四类报告** | 明确缺陷 / 历史写法差异 / **质量优化（新增维度）** / 需要用户判断；并加"只读巡检只给建议，不自动改存量""技术合格 ≠ 内容合格" | 第10步巡检 |

## 四、工具增强

`工具脚本/模板感诊断_template_scan.py` 新增两个参数，把 SOP 里"人工记账"的两条要求变成可执行：

```bash
# ① 区间判定：逐篇报可见字符数 + 正常/偏薄/偏长
python 工具脚本/模板感诊断_template_scan.py --dir "<系列>/公众号文章" --count

# ② 30% 降幅复核：对比改前备份目录，自动算逐篇降幅、≥30% 标 ★
python 工具脚本/模板感诊断_template_scan.py --dir "<系列>/公众号文章" --count \
       --baseline "<系列>/_backup_SOP改造前_日期"
```

**实测结果**：

- 手机系列：正常 5 / 偏长 3（第6篇 3256 最长，是"真实经历"实战篇，内容确实厚）
- 青春期30讲第10篇：原 2535 → 2234，**降幅 12%**，未触发 30% 线
