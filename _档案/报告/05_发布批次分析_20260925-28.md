## 三、⚠️ 本批**不能回答**什么（否则必然误判）

2. ⛔ **跨期比较需极度谨慎**。本批 **09-25~09-28**，早期基线 **09-05~09-22**。卡片版阅读从早期中位 **98** 降到本批 **22–32**——
   ⚠️ 这**看似"腰斩"，实为既有结论的重现**：推荐红利期（09-09~12）之后给量已回落（见 `_资产/发布数据复盘.md` §五·补录 B）。**不是新增问题。**
3. ⛔ **评论为 0 不构成"内容变差"**。本批阅读基数 **16–32**；早期有 9–11 条评论的篇目阅读在 **178–193** 量级——**基数差 6–10 倍时不具可比性**。
4. ⛔ **完读率不可作为"下滑"证据**。4 篇为 36.8% / 38.5% / 41.7% / **62.5%**；对照早期基线（48.8% / 49.4% / 57.1% / 60.0%）→ 2 篇低于基线、1 篇创了新高。
