## 二、修复内容明细

### 1. B 类问题（文字颜色挂在 `<td>/<section>` 容器上）+ data-* 污染
- **影响系列**：8 个（见上表）
- **修法**：`工具脚本/微信HTML规范校验修复_wx_html_fix.py`
- **改动性质**：**语义等价**——颜色由容器下沉到包住文字的 `<span>`，渲染效果不变，可安全执行
- **备份**：各系列目录下 `_backup_规范修复_20260910/`

### 4. 预览页规范化（全部迁入独立 `_预览/` 子目录）
- 新建通用预览脚本模板：**自动扫描 `发布包_第N篇_*` 读取篇号**（无需手写清单），剥 `data-*`，输出到 `_预览/`，支持 `--fix`
- 统一覆盖/补建 **14 个系列**的 `_build_preview.py`，全部重建预览页
- 根目录旧预览页归档到各系列 `_backup_旧预览页_20260910/`；旧脚本备份为 `_backup_预览脚本_20260910.py`

**为什么必须放 `_预览/`**：预览面板会把渲染后的 DOM 写回被打开的那个 `.html`（注入数百个 `data-*`）。放独立副本目录后，源正文物理上不会被污染，随时重跑脚本即可复原。

## 三、工具改进（本轮沉淀）

`系列发布全套自检_selfcheck.py` 的判据经实测打磨，已可跨系列复用：

| 判据 | 改进 |
|---|---|
| ①篇号连续 | 自动读取，无需配置篇数 |
| ③标题比对 | `norm()` 去中英弯直引号/书名号/括号/分号；legacy 下额外容忍"分词位移"（正文分两行时标点位置不同） |
| ④来源声明 | legacy 下放宽：课程类认"扶鹰/非课程原文"，读书笔记类认"整理自《书名》/非原文摘录" |
| ⑤动作指令 | 只扫可见文字（剥 script/style），并加豁免表（"点赞越多我凉得越快""分享给你"等叙事句不算）；**豁免词须长词优先排序** |
| ⑧预览页 | 兼容单双引号 `class='art'`，只匹配正文容器不匹配导航标签 `arttag` |

**用法**
```bash
# 新系列（严格模式，交付门禁）
python 工具脚本/系列发布全套自检_selfcheck.py --dir "某某系列/公众号文章"

# 既有系列巡检（放行历史约定差异，只看真问题）
python 工具脚本/系列发布全套自检_selfcheck.py --dir "某某系列/公众号文章" --legacy --source "扶鹰教育-王金海"
```
