## 零、为什么"只保留官方检测工具"还不够（核心论点）

按你的思路，官方检测工具是**后置兜底**。但我把官方检测器源码读完后发现一个**决定性事实**：

> **官方文档写了规则，检测器不一定实现。**

实证：`font-family` 规则在官方文档第 3 章明文规定（"不建议设置任何字体族"），
源码里也有 `checkFontFamilyViolation()` 函数、也在 `propertyRules` 文案表里，
**但 `collect.ts` 只 import 了它，从未调用**（`grep` 确认：全仓仅 2 处出现，均为 import 与预筛正则）。

**后果**：我们全库 **91 篇**写了自定义 `font-family`，官方工具全部判 `isValid: True`——
**检测通过，但文档明确不建议**。iOS 17+ 部分版本会出现字号/字间距差异（官方给了对比图）。

**所以结论是**：
- **官方检测工具** = 后置兜底（能查的查）
- **生成阶段规则** = 前置防线（**必须按文档写，不能以"工具过了"为准**）

两者是**补充关系，不是替代关系**。这也正是你要的方向。

## 二、⭐ 通用生成规则（前置防线，建议写进 SOP 第 4 步）

以下两条是**从官方算法机理反推的"生成时写法"**——比事后修复治本。

### G1 · 块内不要"裸文本 + 内联元素"混排（治 line-height 告警）

**为什么**：官方按真实布局测量行框数。块内**裸文本与内联元素混排**时，
内联元素边界被算成额外 rect → `lineCount` 虚增 → `contentHeight/lineCount` 被除小 → 误判叠字。
⛔ 与 `font-size`/`line-height` 取值**无关**（已证伪）。

**生成时怎么写**（按优先级）：
```
✅ 首选：整段用「容器 + 全部文本节点包 span」——
   <p style="…"><span>前半句。</span><b>强调句。</b><span>后半句。</span></p>
   （块内无裸文本 → 官方测量稳定，且行高声明 1.9 完全合规）

✅ 次选：强调独立成段 ——
   <p style="…;font-weight:bold;color:#xxx">小标题</p>
   <p style="…">正文</p>

❌ 避免：<p style="…">裸文本<b>强调</b>裸文本</p>
   （视觉正常，但官方会报 line-height-overlapping）
```

**关键**：`<span>` **不带任何样式**（颜色仍写在自己的 `<b>`/`<span>` 上），
**视觉零变化**，只是让官方测量不再误判。

### G2 · 控制嵌套层级（治 nestNodes）

**官方 2.1 原文**：同 tagName + 同内联样式 + 仅单个子节点 的连续链 **≤10 层**。
**官方检测器 `nestNodes`** 口径更宽：**DOM `data-nest-level ≥ 15`** 即报（本项目 7 篇）。

**生成时怎么写**：
```
✅ 合并「无样式/同样式」的纯包裹 section ——
   ❌ <section style="width:100%"><section style="width:100%"><p>…</p></section></section>
   ✅ <section style="width:100%"><p>…</p></section>
✅ 需要多层是为了「背景 + padding + 圆角」叠加时，把多个属性合并到一个 section
✅ 单个 section 上不要重复写相同 style
❌ 避免连续 3+ 层「只为了包一层」的 section
```

## 三、生成阶段该写 / 不该写（速查表）

| 类别 | ✅ 该写 | ❌ 不该写 |
|---|---|---|
| 宽度 | `width:100%` / `max-width` 配 `box-sizing:border-box` | 固定 `width:500px`（≥200px） |
| 高度 | 由内容撑开（不写 height） | `height:0` / 固定小 `height` + `overflow:hidden` |
| 行高 | `line-height:1.9`（≥字号） | `line-height` < 字号 / `line-height:0` |
| 对齐 | `text-align:left/center/right` | `text-align:start/end` |
| 字体 | **不写 `font-family`** ← 新 | 任何自定义字体栈 ← 新 |
| 文本容器 | `<p>` / `<span>` / `<b>` / `<strong>` | `<div>` / `<h1-4>` / `<ul>/<li>` / `<pre>` |
| 背景 | 写在公共容器；纯色 | 渐变承载文字；逐段落重复写背景 |
| 定位 | 正常流式 | `position:absolute` / `transform` 破坏顺序 |
| 优先级 | 内联样式 | `!important` |
| 图片 | 正文零 `<img>`（卡片用 section 绘制） | 图片承载纯文本 |
| 块内结构 | 全部文本包 `<span>`（G1） | 裸文本 + 内联元素混排（G1） |
| 嵌套 | 合并同样式包裹层（G2） | 连续 >10 层同样式单子节点链（G2） |

## 三、⭐ 生成阶段标准写法模板（写正文时照抄）

这是本方案最可直接落地的一部分——**在生成时就写对，而不是事后修**。

### 模板 A · 普通正文段（**默认用这个**）

```html
<p style="margin:0 0 12px;font-size:16px;line-height:1.9;color:#3a322c">
  <span>前半句文字。</span><b style="color:#93553a">需要强调的一句。</b><span>后半句文字。</span>
</p>
```
> **要点**：块内**每段文字都用 `<span>` 包**（`<span>` 不带样式）→ 官方测量稳定。
> 这是 G1 的落地形态，**视觉与"裸文本 + `<b>`"完全一致**。

### 模板 B · 段内小标题 + 正文（强调独立成段，二选一）

```html
<!-- 写法 1：小标题独立成段（视觉上换行，最稳） -->
<p style="margin:0 0 6px;font-size:15px;line-height:1.9;font-weight:bold;color:#93553a">发生：</p>
<p style="margin:0 0 8px;font-size:14px;line-height:1.9;color:#46514f">周二晚上九点，物理作业卡住后打开短视频……</p>

<!-- 写法 2：同行但全部包 span（视觉不变，也稳） -->
<p style="margin:0 0 8px;font-size:14px;line-height:1.9;color:#46514f">
  <b style="color:#3f6f6a">发生：</b><span>周二晚上九点，物理作业卡住后打开短视频……</span>
</p>
```

### 模板 C · 加粗强调（**禁裸混排**）

```html
❌ 不要写：<p style="…;line-height:1.9">这是正文<b>这里是重点</b>继续正文。</p>
✅ 应该写：<p style="…;line-height:1.9"><span>这是正文</span><b>这里是重点</b><span>继续正文。</span></p>
```

### 模板 D · 卡片 / 色块（G2：合并同样式包裹层）

```html
<!-- ❌ 三层同样式包裹（易触发 nestNodes） -->
<section style="width:100%"><section style="width:100%"><section style="width:100%">
  <p style="…">内容</p>
</section></section></section>

<!-- ✅ 一层承载（背景 + padding + 圆角合并到一个 section） -->
<section style="box-sizing:border-box;width:100%;background:#faf3ec;border:1px solid #ecd9c6;border-radius:10px;padding:16px 20px;display:block">
  <p style="…">内容</p>
</section>
```

### 模板 E · 引文 / 金句块（背景写自己，属正常）

```html
<section style="box-sizing:border-box;width:100%;background:#f4f6f5;border-left:4px solid #3f6f6a;padding:12px 16px;display:block">
  <p style="margin:0;font-size:15px;line-height:1.9;color:#3f6f6a"><span>引文内容。</span></p>
</section>
```
> **注意**（对应官方 4.2.1）：若**相邻多个段落要共用同一背景**，应把它们放进**同一个外层 section**，
> 而不是给每段各写一份相同背景。

### ⛔ 完整禁用清单（生成阶段）

| 禁用 | 原因（官方条款） |
|---|---|
| `<p>` 内「裸文本 + 内联元素」混排 | line-height 误判（G1，实测） |
| 连续 >3 层同样式纯包裹 `<section>` | 嵌套层级（2.1 / nestNodes，G2） |
| **任何 `font-family`** | 字体使用规范第 3 章（**检测器不查，但文档明确不建议**） |
| `line-height` < 字号 / `line-height:0` | 1.3 |
| `text-align:start` / `end` | 1.6 |
| `<pre>` | 1.8 |
| `height:0`；固定高 + `overflow:hidden` + 含文字 | 1.5.1 / 1.5.2 |
| 固定 `width:≥200px`；大 `margin-left` | 1.4.1 / 1.4.2 / 1.4.3 |
| `position:absolute` / `transform` 破坏视觉顺序 | 4.2.2 |
| `!important` | 4.5.2 |
| 渐变背景承载文字；格子/条纹渐变背景 | 4.1.2（DM 下会转纯色 / 消失） |
| 图片承载纯文本 | 4.3.1 |
| `<div>` / `<h1-4>` / `<ul>` / `<li>` / `<table>` / `<img>` | 现行 SOP 已禁（微信粘贴清洗） |
