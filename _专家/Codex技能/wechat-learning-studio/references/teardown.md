# 文章拆解与报告

## 分析方法

先完整读文章、确认其主要命题及文章类型，再回读关键段落。标准拆解可从五维组织；用户只问某一维时不强迫填满五维：

1. 选题与角度：具体切口、目标读者、对常见写法的偏离；没有比较样本时，只说明本文角度，不声称“别人通常都……” 。
2. 标题与开头：标题向谁许诺什么、开头如何兑现或制造悬念、进入正题的速度；“可能吸引谁”标推测，不写“读者一定不会划走”。
3. 结构与节奏：论证／叙事骨架、分段与转场、信息密度和重复点。可用段落位置或小标题概括，不机械复制全部小标题。
4. 情绪表达：文本怎样呈现焦虑、理解或希望，有无羞辱、恐吓、绝对化归因；区分文本的情绪设计与读者真实反应，不编造情绪比例。
5. 结尾与可复用表达：论点如何收束、是否留下行动或思考空间；分析句法与功能，避免收集大段“金句”。

每项有价值的发现尽量给“文本位置／短引句 → 写法 → 作用机制（若为推测则标明）→ 对本账号的适用条件”。拆不出可迁移技法就明确说 0 项，不为凑卡而硬提炼。涉及事实、人物、科学研究或引用时，核实后再作内容质量判断。

## 正式报告

仅用户要求落盘时写入 `_资产/技法库/_拆解报告/YYYY-MM-DD_<短标题>.md`，参考现有 `_模板_拆解报告.md`。保留文章身份、来源和获取日期、证据缺口、主要结构、关键发现、适用边界、技法卡候选及与现行 `wechat-article-studio` 规则的关系。旧模板要求“前 3 行照抄”“所有小标题逐条列出”“转发冲动来源”等，不应机械执行：以必要短引、位置标记和有根据的推测替代，避免过量摘录及代读者下判断。

账号语境：读者为青春期孩子的家长，叙事者“一个也在重启的爸爸”是同路人而非导师。模拟改写须显式标注；不得补出未经用户确认的父子对话、家庭结果或第一人称经历。分析外部文章可以肯定其写法，同时指出它不适合本账号的部分。
