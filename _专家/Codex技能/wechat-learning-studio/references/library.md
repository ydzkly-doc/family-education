# 技法库与反哺

## 入库

只在用户要求建档或入库时写文件。以 `_资产/技法库/README.md`、`00_技法总览.md`、`_模板_技法卡.md` 和 `_拆解报告/_模板_拆解报告.md` 为现有资料，先检查是否已有同义技法卡。卡片保留六项核心信息：技法及具体写法、可追溯出处与短引、作用机制及推测标识、本账号模拟改写示例、边界／反例、与现有规则及验证状态的关系。

可迁移度用 `✅ 可直接用`、`⚠️ 需改造`、`❌ 不适用`。`✅` 只表示不明显违背账号定位，不表示已验证有效。明显违背真实性、来源标注或不羞辱家长等底线的写法，记入不采用区；若只是一次性问题，可在报告和总览中记录，不强求每条都建完整卡。建立 `❌` 卡时沿用 `_不采用_` 文件名前缀，防止误用。

实际技法库已有 `07_封面与视觉`、`08_数据复盘与指标口径`，不仅是旧 README／模板列出的五个写作维度。按现存目录及本次内容选择归属，不新建空目录或改写历史记录。正式新增、修改卡片后，同步总览中的条目、数量、日期和待确认清单；核对数字，不沿用旧统计。未经授权的快速分析不动总览。

## SOP 反哺

技法卡是研究材料，不自动成为 `wechat-article-studio` 的规则。提议反哺时列：技法、证据与局限、拟改位置、与现有规则的关系（新增／强化／冲突／重复）、建议采纳／观察／不采用。用户确认具体条目后，才另按公众号制作技能当前的维护规范修改其项目版和安装版；不能照搬 WorkBuddy 的 cache／marketplace／ZIP 三处同步步骤。用户只说“看看能否反哺”时只给建议，不改 SOP。

## 效果复盘

外部文章的写法观察不等于本账号效果证据。本账号复盘需注明文章、发布日期、渠道、题材、形式、指标定义和可比基线。不同文章的简单“有／无某技法”对比、不同发布时间或渠道的所谓 A/B，不支持单技法因果结论；小样本只标“观察”或“待验证”。
