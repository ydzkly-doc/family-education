# 公众号爆款工坊（WeChat Article Studio）

把读书笔记 / 逐字稿 / 脑图等原始材料，加工成一套**可直接发布的微信公众号内容**。

## 类型

Agent 型（单个 AI 专家）

## 每次使用请提供

1. **原始材料**：读书笔记、逐字稿、脑图，或文件路径（docx / xmind / md / txt 等）。
2. **来源声明口径**：文末来源/版权声明怎么写（公众号名、作者、书名、是否"读书笔记·非原文摘录"等）。

## 功能（默认交付一整套）

- **视角转换**：从"讲书/汇报"改为"读者痛点"视角，开头 3 行进场景。
- **系列化**：1 篇引流总纲 + N 篇单主题深耕 +（可选）1 篇 30 秒速览；篇号连续。
- **图文一体排版 HTML**：每篇一个自包含 HTML，卡片用 `<section>`+内联样式绘制（**禁用 `<table>` 布局**——微信安卓端会固化 table 宽度导致窄屏右裁），浏览器打开→全选复制→粘进公众号后台即带排版，无需手动插图。
- **干货卡片**：清单/节奏表/对照图，可单独截图转发朋友圈与社群。
- **卡片文章（贴图）**：每篇长文可**额外产出一个卡片版本**——微信官方"贴图"形态（俗称小绿书），**独立的新内容形态**，不是长文缩略版。含 **3–5 张**竖版卡片（封面 1 + 内容 1–3 + 收尾 1；**张数按长文内容厚度定，不固定 2+3** / 3:4 / 单张 <100KB / **文件名带篇号前缀**）+ **钩子型描述 540–660 字**（600 为中心 ±10%；**只写卡片没讲的**，不重复卡图内容；**末段自然引导原文**）+ **纯文本正文**（编辑框不支持富文本；**卡图不印声明**（2026-09-29 用户改定：来源类型改为逐卡内部回溯记录，卡图只留署名·篇号·卡序））+ 字段表；**卡片走算法推荐、优先推给非粉丝**，是突破粉丝上限的免费通道。**长文是唯一素材源**，存量补做与全新生成同一流程。
- **Word 版本**：含卡片原生表格的 .docx，供本地改稿、打印、存档。
- **配套手册**：系列选题规划、发布顺序与后台步骤、朋友圈/社群转发文案。
- 每篇文末**固定来源声明**（按用户口径）；事实硬伤在成稿中修正。

产物统一放在与原材料同目录的成果文件夹（如 `公众号文章/`）下。

## 使用示例

- 这是我的读书笔记和来源声明口径，请加工成一套可直接发布的公众号内容。
- 把这份读书会逐字稿改成公众号系列：读者痛点视角、金句小标题、落地动作清单，文末按我给的口径带来源声明。
- 产出系列成稿、图文一体排版 HTML、干货卡片、Word 文档和发布手册。
