# 选题与规划（第 0–1 步）

**第 0 步 · 消化材料**
- 读全部原始文件，列出核心观点、金句、最有画面感的例子、逻辑结构。
- 排查并标注原材料里的**事实硬伤/口误**（错别字、常识错误、张冠李戴），成稿一律修正，不原样搬运。
- **判定内容类型（决定叙事轴与"书名/课程在场密度"，必须在 Gate 1 规划表里先给出建议、由用户明确拍板）**：
  - **类型 A · 课程/逐字稿改写**（默认，如王金海课程逐字稿、直播录音、讲座纪要）：叙事以"我和孩子"的亲子冲突为主场景；课程/老师显性引用**每篇压到 1–2 处**、只在"我想通"处轻轻带入；书名/课程名**不做正文显著露出**（仅文末来源声明出现）。
  - **类型 B · 读书笔记**（用户明确说"读书笔记/读一本书/书摘改写"）：书是主角，**书名要在场**。
  - **判定规则（易踩坑）**：哪怕是"王金海讲书"——只要成品定位是**读书笔记**（来源声明写"读书笔记，原著某某书"），一律按**类型 B**处理；讲书人/课程只是"我怎么遇到这本书"的引荐路径。**类型由用户最终决定，Agent 只在 Gate 1 输出明确建议（A 还是 B、为什么），不自行默认。**
  - **类型 B（读书笔记）的两条特殊规则**：
    1. **书名引荐块（显著位置，硬性）**：每篇**开场叙事之后、进入观点之前**，插入一个显眼的「📖 书名引荐块」（暖底色卡片：书名加粗 17px + 作者/出处 + 一句"为什么值得读"+ 说明"这是我边读边在自己家试的笔记"）。第 1 篇写全书背景（作者、来头、我怎么遇到这本书、整个系列是什么）；第 2 篇起用轻量承接式（"读书笔记·《书名》第 X 篇"+本篇讲书中哪个概念），不重复堆砌背景。
    2. **原书观点/概念带入密度提高**：书/作者在正文中的提及**每篇约 6–10 处**（类型 A 是 1–2 处）；书里的模型、概念（如四象限模型、某个公式、三问法）用 **section 卡片**正经呈现。但**红线不变**：概念仍要贴着"我"的故事讲（在"我卡住/想通"处带出），**绝不退回观点灌输/板书式讲课**，父亲叙事、同路人口吻一律照旧。
- **【⛔ P0 · 事实核验与适用边界（发布前必过）】** 原材料里常混有书籍销量、译本数量、作者履历、名校演讲、研究结论、阶段划分等具体事实，以及"XX通常只有三种成因"这类容易被读成**完整结论**的表述。成稿前按**内容分级**处理：
  | 内容类型 | 写法要求 |
  |---|---|
  | 故事 / 个人体会 | 明确**真实**或**改编**（见"叙事真实性三分法"） |
  | 书中模型 / 概念 | 写明"**书中提出**""作者认为" |
  | 课程观点 | 写明"**课程认为**""课上讲" |
  | 研究 / 数字 / 人物履历 / 销量 / 名校演讲 | **发布前核验可靠来源**；核不到就不写，或改为不带数字的柔性表述 |
  | 经验性归纳 | 改成"**常见的三种情况**""**可以先从这三处排查**"，不写"只有三种""必然导致" |
  - **专业求助边界（敏感议题强制）**：涉及**厌学、自伤、饮食障碍、长期失眠、抑郁焦虑**等议题时，必须增加一句**求助边界**提示（如"如果情况持续或伴随情绪、身体上的明显异常，建议同时寻求学校心理老师或专业医疗帮助"），**绝不把普通沟通方法写成治疗方案**、不承诺"照做就能好"。
- **【2026-09-10 新增·系列规模与去重（防止"把课拆完"）】** 读者关心的是"**这一篇能不能解决我今晚的问题**"，不是"这门课被完整拆解"。因此：
  - **普通系列优先控制在 3–5 篇**（原 5–8 篇偏长）；只有材料确实厚、且主题之间边界清晰时才做 6 篇以上，并在 Gate 1 说明理由。
  - **每篇独立成立**，不依赖上一篇才能读懂（可互相引用，但不做成"连续剧"）。
  - **跨系列处理原则：主题主线区分、核心原则重复强化、表达与场景变化。** 选题前先扫一遍既有系列（青春期 / 手机 / 厌学 / 学习动力 / 沟通 / 犯错 等主题重叠较多），相似的核心问题先合并或换角度，不做“换标题但整篇仍讲同一件事”的第 N 个系列；但**不得把去重理解成禁止重要观点和方法复现**。像“先理解再纠正”“减少羞耻”“把目标拆小”“区分孩子和行为”等账号锚点，可以在多篇、多系列中持续强化，帮助读者形成稳定认知。每次复现必须服务于本篇的新机制、新场景和新动作，不能原段复制或用同一案例重复填充。Gate 1 的边界说明同时列出“本系列不再展开什么”和“本系列继续强化哪些核心原则”。
  - **长课程只挑最值得写的部分**，不必篇篇转化；宁可少写几篇写透，不要把原材料机械切块。
  - **用 1 篇"总导航 / 工具合集"承接全系列**，而不是让每篇都塞一份完整的课程地图（避免重复占篇幅）。
  - **⭐ 规划表里的"篇间承接关系"只用于排序与写作，不落成正文顶部导航（2026-09-21）**：规划阶段照常写清"第X篇承接第Y篇"，但**正文顶部不生成"上一站／下一站"视觉导航**——它粘贴到公众号后不可点击、且与合集重复。跨篇跳转由**公众号合集**承担，系列坐标由**眉题**承担。详见 `05-publish-kit.md` 正文 HTML 规格。

**第 1 步 · 定选题与结构**
> ⛔ **Gate 1（选题确认）**：本步产出规划表后**立即停手**，向用户明确请"修改/确认"。**未收到明确确认，禁止进入第 2 步写正文、禁止建发布包、禁止生图。**
- 输出系列规划表：每篇含 篇号、标题（1 主 2 备）、痛点场景、核心观点、金句小标题、选用例子、"今晚就能做的 3 件事"、配图/卡片建议、**建议发布时机**、**篇职能（共情／过招／实操）**、**篇幅档（叙事型／方法型）**、**开场设定（时段＋空间＋触发）**。
- **⭐ 规划期就要定"篇职能"与"开场设定"（2026-09-28 新增·跨篇去同质化的唯一低成本时机）**：**跨篇重复只能在规划期拦住**——写到第 5 篇时回头改第 1 篇的开场，成本等于重写。
  - **篇职能 + 篇幅档（一起定）**：给每篇标 **共情 / 过招 / 实操**，一个系列内**三档都要有**；零件装配按职能走（见 `02-writing.md`「按篇的职能分流装配」）。**篇幅档随职能推导**：**共情／过招 → 叙事型 2000–2800**；**实操 → 方法型 1200–1800**（区间与例外见 `02-writing.md` 篇幅条）。
    - **为什么要在规划期定**：篇幅是**素材预算**——定了档才知道每篇该配多少素材；写到一半才发现"撑不起 2000 字"或"只能塞到 1800"，都要推翻重来。
    - **⚠️ 同系列不要同档扎堆**：**一个系列全是方法型**（篇篇 1200–1800）会显得薄；**全是叙事型**（篇篇 2000+）会显得重。**看系列体量平衡**，不必强行五五开。
  - **开场设定**：给每篇记一行 **"时段 ＋ 空间 ＋ 触发"**（如"清晨／玄关／一句没头没尾的话"），**填表时逐行比对**——⛔ **同系列内不得有两篇用同一时段 ＋ 同一空间**（细则见 `02-writing.md`「跨篇开篇去同质化」）。
  - **为什么必须在规划期做**：这是**唯一能低成本发现重复的时点**。**判据：这一列填不出来，说明还没想清每篇"长什么样"就开工了。**
  - **⚠️ 本列是"设计值"，不是"成稿引文"**：正文写完后若开场有调整，**回填规划表**，保持两边一致（规划表是后续自检的比对基准）。
- 篇号必须**连续（第1篇、第2篇……）**，不允许出现"第0篇然后跳第2篇"这类断号。
- **标题（1 主 2 备）**：主标题保持温暖/知识调性；**2 个备选里至少 1 个走"具体场景+悬念/冲突"路线**（身份感+矛盾，如"孩子说'我不想上学'的那一刻，最不该做的就是讲道理"），供 A/B 选用。
- **【2026-09-10 标题组合去同质化（易踩坑）】** 横向统计约 100 个标题发现**极度集中在一种句式**：约 **46 个带"我"**、**67 个带"孩子/儿子/女儿"**、**41 个带引号**，大量是"孩子说了某句话，我突然明白……"的结构。**单看有效，数量一多就互相稀释**。因此：
  - **刻意在系列内轮换三类标题**（一个系列里不要全是同一类）：
    1. **情绪共鸣型**：保留父子冲突与关键对话（"他摔门喊'那你去当别人家的爸啊'"）——上限控制在系列内约 1/3。
    2. **问题解决型**：直接说明读者能解决什么（"孩子作业拖到十一点？先看他卡在哪一步"）。
    3. **认知反差型**：给一个反常识判断（"孩子不是爱手机，是学习上没台阶下了""越管越远：盯作业盯出的是对抗"）。
  - **坚决减少无依据的夸张表达**：不用"90%的父母都接错了话""一招管住""彻底改变""治好了""三天见效"这类**未经核验的比例数字与绝对承诺**（存量标题中仍有此类，新内容一律不用）。常识性描述（如"很多父母"）也尽量换成具体场景。
  - **备选标题同样要过证据关**：**1 主 2 备三个标题，每一个都必须是正文真正支撑得起、且事实站得住的**——不能出现"主标题合规、备选标题里塞了个'90%父母都错了'"的情况。**备选标题不是"随便多给两个选项"，用户可能会真的用它去发**，所以后台可用的标题 = 正文可兑现的标题。
- **标题长度与钩子位置（硬性，易踩坑）**：
  - **硬上限：标题 ≤ 64 个字符**（中英文、标点、空格全部计入），超了后台发不出去/被截断。
  - **信息流可见区只有前约 18–22 个字**：订阅号列表、转发卡片超出部分显示"…"。所以**最扎心的冲突/数字/悬念/那句台词，必须压在前 20 个字里**，别把"真相藏在…""答案是…"这类钩子放在 20 字之后。
  - **主推"短钩子版"正式标题（17–24 字最佳）**：前半句就是具体场景或冲突台词（如"孩子打游戏能专注，一写作业就喊累？""他摔门喊'那你去当别人家的爸啊'"），短而完整、在信息流里不被截断；偏书面/偏长的版本放备选做 A/B，不当主标题。
  - **标题三处必须一致**：正文 HTML 顶部大标题（h1 或标题色块）、字段表 `01_标题作者摘要.txt` 的【标题】行、发布手册里引用的标题，**逐字相同**。任何时候改了正文标题，必须同步字段表【标题】；被替换下来的旧标题降级收进【备选标题】，不丢弃。
- **踩情绪时间点（传播⑧）**：选题要对着家长情绪日历排——开学季、期中/期末考试前后、家长会当晚、寒暑假手机/作息冲突、中高考放榜等；在情绪最高的那一周发对应主题，打开率与转发率显著更高。规划表里"建议发布时机"一栏即为此服务。
