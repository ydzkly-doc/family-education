# 公众号学习工坊（WeChat Learning Studio）

把**外部好文章**逆向工程成**可迁移的写作技法**，沉淀进技法库，经确认后反哺「公众号爆款工坊」的写作规则。

## 类型

Agent 型（单个 AI 专家）

## 它解决什么问题

「公众号爆款工坊」（`wechat-article-studio`）管的是**把素材加工成文章**（生产端）。
但它的"什么算好文章"这套标准，全部来自编辑经验——SOP 自己写着"规则要能被数据推翻，20–30 篇后再定稿"。

**缺口在于：它只有"写出去"的闭环，没有"学进来"的通道。**

本工坊就是那条通道：**研发部**，负责把外部高手的写法拆开、验证、沉淀成规则。

```
好文章 → [本工坊：拆解] → 技法卡 → (用户确认) → 工坊 SOP → 更好的文章 → 发布数据回流
                ↑                                                          ↓
                └──────────────── 真实数据验证技法是否有效 ←────────────────┘
```

## 每次使用请提供

任选其一：
1. **候选文章**：链接、全文，或"帮我搜一批"。
2. **拆解范围**：全拆 / 只看某几个维度（如只要标题分析）。

## 功能

- **候选发现**：自动联网搜捕（含直接命中 `mp.weixin.qq.com` 原文）+ 接收投喂。
- **证据分级**：公众号阅读量**不公开**，故用替代信号分级——多平台转载 > 被专业拆解号拆过 > 头部账号 > 用户指定；**核不到就如实标"未验证"，绝不编造"10万+"**。
- **五维拆解**：选题与角度 / 标题与开头钩子 / 结构与节奏 / 情绪曲线与共鸣点 / 金句与结论收尾。每维都摘原句、给机制解释、判定可迁移性。
- **技法卡**：切成独立可复用单元，6 项必填，标 `✅ 可直接用 / ⚠️ 需改造 / ❌ 不适用`。**`❌` 的卡同样要立**——记录"为什么这个爆款套路我们不用"。
- **反哺清单**：累积到量后编制候选清单，**由用户逐条拍板**，绝不自动写入工坊。

## 三档优先级

| 档 | 内容 |
|---|---|
| **P0 红线** | 证据诚实 · 反哺须确认 · 不冒充原创 · 三道 Gate · 只读原始材料 |
| **P1 质量线** | 五维完整 · 六项齐备 · 可迁移度判定 · 报告留痕 · 来源可追溯 |
| **P2 偏好** | 报告详略 · 候选数量 · 是否定期自动搜捕 |

## 三道人工关卡

- **Gate A · 候选清单确认**：给清单就停手，等用户圈选。
- **Gate B · 首篇样板确认**：先只拆 1 篇，等用户确认深度/角度/格式。
- **Gate C · 反哺清单确认**：给候选清单就停手，等用户逐条拍板。

> **关卡不可跳过。** 用户说"你定就行/继续做"时，授权范围仅限当次点名的那一件事。

## 使用示例

- 帮我拆解几篇同题材的好文章，学它们的写作技巧，沉淀进技法库。
- 搜一批青春期亲子题材被广泛转载的文章，标注证据等级，给我候选清单让我挑。
- 盘点技法库，提出哪些发现可以写进写作工坊的 SOP，我逐条拍板。

| | 公众号爆款工坊 | 公众号学习工坊（本包） |
|---|---|---|
| 定位 | 生产线 | 研发部 |
