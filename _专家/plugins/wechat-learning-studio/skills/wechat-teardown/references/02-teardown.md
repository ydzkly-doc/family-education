# 第 2 步 · 五维深度拆解（核心细则）

> 目标：把一篇文章的写作机制**逐维拆开**，每一维都要落到"可迁移的判断"。产出拆解报告。
> **这是本工坊最核心的能力。拆得透不透，全看这一份细则。**

---

## 零、动笔前：先通读，再分维

**顺序纪律**：
1. **先完整读一遍**全文，不打断、不摘句，只为搞清楚"这篇在讲什么、想让读者干嘛"
2. **再读第二遍**，这次带着五维的追问清单逐维提取
3. **摘句时用原句**，不要复述。复述会丢掉语感，而语感正是要学的东西

⚠️ **常见错误**：一上来就逐段摘句编号，结果拆成一堆碎片，说不出"这篇整体的运作机制"。

---

## 一、选题与角度

### 追问清单
1. **切口是什么**：一句话概括它选了什么题（如"孩子玩手机"→ 具体切口可能是"为什么讲道理没用"）
2. **覆盖人群**：谁会觉得"这说的就是我家"？（越具体越好，不要写"家长"这种泛词）
3. **痛点深度**：戳的是**表层麻烦**（作业慢、玩手机）还是**深层焦虑**（我是个失败的家长 / 我的孩子要毁了）？
4. **角度差异**（最关键）：**同一主题下，大多数文章怎么写？这篇换了什么视角？**
   - 例：大家都在写"怎么让孩子放下手机"，这篇写"我为什么不让你玩手机"——从**父母立场**转向**对话姿态**
5. **时机因素**：是否踩了某个时间点（开学、考试、假期）？换时间还成立吗？
6. **可迁移判断**：这个选题方向对本账号适用吗？**若不适用，明说**

### 输出要求
- 必须**摘一句原句**展示它是怎么切入的（通常是开篇第一句或小标题）
- "角度差异"这一项**必须填**，填不出就写"这篇角度无明显差异，胜在执行"

---

## 二、标题与开头钩子

### 标题追问清单
1. **标题原文**（照抄，不改标点）
2. **类型判定**（单选或双选）：
   - **情绪共鸣型**：`孩子，我为什么不让你玩手机？`
   - **问题解决型**：`3个技巧，帮孩子搞定作文跑题`
   - **认知反差型**：`你越努力，孩子越清醒`
   - **疑问悬念型**：`为什么别人家的孩子阅读能力强？`
   - **数字清单型**：`这5个问题，一次性说清`
3. **结构还原**：用公式拆（如 `人群标签 + 情绪冲突 + 具体结果`、`疑问句 + 利益点`）
4. **钩子机制**：让人点开的**具体诱因**是什么？——注意：不是"引发好奇"这种空话，而是**它藏了什么信息、承诺了什么回报**

### 开头追问清单（重点在前 3 行）
1. **前 3 行照抄**
2. **开头类型**：场景切入 / 悬念抛出 / 反常识断言 / 数据冲击 / 对话开场 / 权威引用
3. **留人机制**：**为什么读者不会在这里划走？**（是画面感？是冲突？是一个悬着的问题？）
4. **进正题速度**：第几段开始讲核心论点？（算一下前摇有多长）
5. **与标题的呼应**：开头兑现了标题的承诺吗？有没有"标题党"嫌疑？

### 输出要求
- 标题和前 3 行**必须逐字照抄**，这是最有学习价值的部分
- "留人机制"若只是你的推测，**写"推测"**

---

## 三、结构与节奏

### 追问清单
1. **骨架类型**：
   - 总分总 / 并列式（N 个分论点）/ 递进式（层层深入）/ 故事线 / 问题-原因-方案 / 清单式 / 对话拆解
2. **小标题逐条列出**：**这一步不能省**——小标题是骨架的骨架
   ```
   01 ___
   02 ___
   03 ___
   ```
   **看它的组织逻辑**：是并列？是递进？是时间顺序？是视角切换？
3. **段落节奏**：用具体模式描述（如"3 短 1 长"、"每段 ≤3 行"、"长段后必跟一句独立短句"）
4. **信息密度曲线**：哪里密（概念/数据/论证集中）、哪里疏（故事/情绪喘息）、有没有给读者留呼吸空间
5. **转场手法**：段落之间怎么衔接（举 1 例原句），是否用了"过渡句"或"设问"来推
6. **篇幅**：全文大致多少字？各部分占比？（开头/展开/高潮/结尾）

### 输出要求
- **小标题必须完整列出**，不许写"有若干小标题"
- 节奏描述要**具体到可模仿**，写"段落长短交替"是无效分析

---

## 四、情绪曲线与共鸣点

### 追问清单
1. **情绪走向**：用箭头串起读者的心理路径
   - 例：`焦虑 → 被理解 → 释然 → 有力量`
   - 例：`自我怀疑 → 震惊 → 反思 → 行动`
2. **共鸣位置**：**第几段让读者觉得"这就是我家"？**那句话说是什么？
   - 这份共鸣通常伪装成"具体到不像是编的细节"（如"我躲在被子里哭"）
3. **痛点放大手法**：怎么把痛感一步步做深的？——**具体到句式**
   - 是"层层加码"（一个场景接一个场景）？
   - 是"从现象推到后果"（玩手机 → 成绩下降 → 未来毁掉）？
   - 是"直接命名情绪"（"你不是懒，你是害怕"）？
4. **共情句式**：可照抄的共情模板（如 `我知道你现在一定很难受，能跟我说说吗`）
5. **情绪句与信息句的比例**：大致感受（如"7 分情绪 3 分道理"）
6. **是否操纵情绪**（⛔ 关键判断）：
   - 它制造焦虑是为了**给出口**，还是**只制造焦虑不给出口**？
   - 有没有用"制造羞耻"来驱动行动？（如"再不管就晚了"）
   - **若存在情绪操纵，必须在报告中标注**，并在立卡时标 `❌ 不适用`

### 输出要求
- 情绪走向**必须画成链**，不要只写"情绪饱满"
- **必须指出是否含情绪操纵**——这是本账号最需要警惕的（调性克制、不煽动）

---

## 五、金句与结论收尾

### 追问清单
1. **可引用金句**：逐条列出，标注位置和造法
   | 金句 | 位置 | 造法 |
   |---|---|---|
   | | 开头/中段/结尾 | 对仗 / 比喻 / 反转 / 引用权威 / 排比 |
2. **结尾结构**：金句收束 / 呼吁行动 / 开放提问 / 呼应开头 / 升华主题 / 引用名言
3. **转发冲动来源**：读完**想转给谁**？为什么？
   - 是"转给老公看，让他也意识到"（指向他人）？
   - 是"发朋友圈暗示自己的处境"（自我表达）？
   - 是"存下来以后用"（工具价值）？
4. **来源声明处理**：这篇有没有署名/版权声明？怎么写的？（供本账号参考）
5. **结尾有没有"动作指令"**：如"点个在看""转发给需要的朋友"——**本账号不用这类指令**（调性克制），记录备查

### 输出要求
- 金句**照抄**，并分析造法——**学会造法比背下金句有用**
- "转发冲动来源"若判断不出，写"看不出明确指向"

---

## 六、与工坊 SOP 的对照（反哺的原料）

拆完五维后，**必须做这一步**：

| 本报告的发现 | 工坊 SOP 现状 | 关系 |
|---|---|---|
| （技法） | （如 `02-writing.md` 已有"六种结构轮换"） | 新增 / 强化 / 冲突 / 已验证 |

**四种关系的处理**：
- **新增**：工坊 SOP 里没有这个写法 → 潜在反哺候选
- **强化**：工坊已有类似规则，这篇印证了它 → 记录为"实证支持"，可增强该规则的说服力
- **冲突**：这篇的写法与工坊某条规则相悖 → **重点标记**，这是最需要用户拍板的情况
- **已验证**：工坊规则在本账号发布后已有数据支持 → 交叉引用

> **这一步不能省。** 不做对照，拆解就只是"读后感"，反哺无从谈起。

## 八、Gate B 停手纪律（样板篇）

**首次拆解（或新类型文章的第一篇）**：
- ✅ 拆完 1 篇 → 落盘 → **停手**，请用户确认：深度够不够？角度对不对？格式合不合意？
- ❌ **不要**接着拆第二篇
- ❌ **不要**同时立完所有技法卡再问（先让用户看拆解本身的质量）

**用户确认样板后**，才可继续拆其余候选。**批量拆解仍需逐篇落盘，只是不再逐篇停问。**
