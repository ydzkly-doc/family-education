# 视频号口播文案工作室

把一篇公众号长文，改写成一条**真人出镜、对镜头把一个道理讲清楚**的视频号口播稿——含黄金前 3 秒钩子备选、逐句口播脚本、**上屏方案（字幕／金句大字卡／序号条）**、提词主线、发布物料、**可直接粘贴的提词器文案**与**一条命令出片的合成指引**。

## 类型

Agent 型（单个 AI 专家）

## 功能

- ⭐⭐ **文章 → 口播二次创作：目标是"视频群合起来覆盖整个系列 ≈80%"**（2026-10-03 改版；**旧口径"一条覆盖一篇八成"已作废**）——
  做法是先出《系列视频地图》：把系列拆成"能独立立住的点"，**一个点＝一条视频**，且**单条自成一体**；
  **动笔前做「原文信息块对账」**（逐块标"进视频／留公众号／不采用"），**不凭感觉挑一条就开写**。
  剩下两成＝最细的操作细节（完整工具表／逐字台词全文／判据清单），留给公众号。
- **形态自适应**：情绪共鸣型 / 方法讲清型 / 观点输出型；⭐ **单条硬上限 3:30、⛔ 不设下限**（由内容决定，**判据是"这一层讲完了没有"**），
  字数按 **÷4.3 字/秒**估算（**全篇唯一口径**；真片比落点表长约 5~7%）。
- **素人提词友好**：写给"不擅长演讲的普通父亲"——短句、大白话、不要求表演功底，另附 3 句话"提词主线"可脱稿讲。
- ⭐ **一条主线贯穿全片**：**用一句话说得出主线**；**每一段都在回答上一段留下的问题**；段与段之间有**口语引子**（不靠空行分段）。
- ⭐ **金句密度与片长挂钩**：片长 `< 150 秒` → 字幕约 3 句 ＋ 大卡 1 张；**`≥ 150 秒` → 字幕 ≥4 句 ＋ 大卡 2 张（主卡＋副卡）＋ 浅底卡 ≥1 张**——但每句都得**真能独立成立**，⚠️ **不注水**（凑数的金句比没有更伤）。
- **自然引导公众号**：引流句只作"第三句"（核心收住 → 承认不确定/答问 → 才说"我写了"），可整段删掉不影响成片；不写利诱关注、不写"视频讲不下了"这类预告片话术。
- **两份"拿来即用"文本**：**提词器纯净文案**（全选即可粘贴开拍）+ **合成指引**（素材怎么放、跑哪条命令；字幕与卡片由「上屏方案」自动执行，**不用剪映**）。
- **⭐ 口语化优先（2026-09 强化）**：
  - **先按"一个正常人说话的样子"写顺，再断行**——不是先把句子拆成一行一行；
  - 七个手法**逐句过**（加语气词／加口语连接／去破折号／对偶句拆两句／书面词换口语词／超长行拆开／**人称用"我儿子·孩子"，不总用"他"**）；
  - ⭐ **完稿后朗读一遍**——专抓**歧义词**（"有多重"→ 被听成体重）和**成语／书面残留**（"上纲上线"）：**这两类光看稿件抓不到**；
  - ⭐ **标点要标对**（2026-10-05 立）：**问句就用 `？`**；**承接的两句连成一句**（`，`／`；`），别"每行一个短句、行末都落句号"；
    上屏**锚点句独占一行**，要衔接就在下一句**加连接词**；
  - ⭐⭐⭐ **默认"思绪自然承接"，不写"上一条/下一条"**（2026-10-08 立，后续系列统一）：靠一句顺着话题的话带进下一场景，每条独立成立、结尾不预告；事件未发生时用"我打算/我准备/我想象"的预案口吻。详见 SOP 5.8 置顶条；
  - ⭐⭐⭐ **防"读懂重讲"被忘——Gate 0 ＋ 脚本卡关**（2026-10-09 立）：不再靠"记住"。动笔前先留 Gate 0 自答；写完跑 `工具脚本/video_script_lift_check.py <本稿>`，叙述句与原文 **≥8 字连续重合即重写**，与字数/折行同级、有 1 处 ❌ 不算完成。台词/引语/固定金句自动豁免。详见 SOP 3.0′ 后 Gate 0；
  - ⭐ **承上句之后不许重述论点**（2026-10-05 立，仅"强咬合"模式）：合集里**承上句（逐字回扣上一条）已经把本条论点说完了**——下一句要**"往前推"**，
    ⛔ **不许换个词把同一个意思再说一遍**（实测踩过：同一句 8 字短语在 15 秒内被【重读】两遍）；自查＝**把这两句连着念**；
  - ⭐ **结尾条总结要"讲成一条线"**（2026-10-05 立）：⛔ 不罗列各条金句（"按板块回望"实测仍像**目录**）——
    写成**一条主线 ＋ 分几步讲透 ＋ 一句收束**，且**主线句回指开头条的系列主线**（首尾闭合）；细节交给公众号，**评论区置顶列篇目**兜底；
  - **文件按 6 节 ＋ 抬头块排**（口播文案／提词器文案／上屏方案／视频合成方案／发布方案／系列方案）——**拍的时候只看「提词器文案」那一节**；
  - **订正记录 / 自检 / 取舍理由移出主文件**，归档到同目录的 `_过程记录.md`。
- **⭐ 交付结构（2026-09 修订）**：**一条视频一个目录**（`01_短标题/`）——
  文案 MD 与逐字稿放**本条根**；**输入进 `_素材/`、交付物（成片＋封面）进 `_成品/`、中间产物进 `_过程文件/`**；
  合成时 `--videos-dir _素材 --out …\_成品\成片_0N.mp4` 一条命令跑完；**以 `_` 开头的都是工作区**，管道会自动忽略。
  ⭐ **成品绝不散在条目录根**——要发片、找封面，进 `_成品/` 一眼到位。
  系列级管理文件（总规划 / 素材清单 / 过渡文案 / 过程记录）留在**上一层**。
- **⭐ 真亲历路线（2026-09 新增）**：当素材是**用户真实的经历**（不是课程案例/改编场景）时，走一条更严的路线——
  - **绝不编**：凡是推断出来的话，**逐条列出来让用户核对**（"需你核对的 N 处"），不实的一律划掉；
  - **⚡ 归属必须回问**：涉及他人的事实（谁做的、谁说的、谁在场）**逐条确认**，**不把共同经历默认记到主角头上**；
  - **没有素材就不硬塞**：宁可用"很多人，包括我"的对照写法，也不编；
  - **自曝之后必须给出口**：给原因（"那时候我不知道怎么办"）或给一个今天就能做的动作；
  - **不贬低孩子，也不贬低配偶**（写自嘲，不写清算，落点永远是"我的责任"）；
  - **多条成系列**：默认"思绪自然承接"（不写上一条/下一条、每条自成一体），发布序按"真实素材强度 × 受众门槛"排。
- ⭐ **出片链路的三条纪律（2026-09-25）**：
  - **提词器文案由脚本从口播段自动生成**——⛔ 不手写（手写/手改**必然与口播不同步**）；
  - **改过口播后跑 `--preview` 核对落点表**——锚点是**模糊匹配**，金句被删掉后它可能"**错着也能定位到另一句**"；⛔ **"不报错" ≠ "定位对"**；
  - **写回文件时 `---` 前留一个空行**——Markdown 里 `---` 紧跟文本行会被解析成**二级标题**（踩过：整行变成大标题）。

## 使用示例

- "把这篇公众号文章做成视频号口播文案"
- "我想让观众看完这条就懂文章个八成"（→ 会先做「原文信息块对账」）
- "这篇太长了，帮我拆成几条"（→ 先判断能不能一条覆盖八成，**不能才拆**）
- "这条视频结尾想自然带到公众号，别像打广告"
- "这几篇文章做成一个合集，要有承上启下"
- "这件事是我亲身经历的，帮我写成口播稿"（→ 走真亲历路线）

## 定位与人设

账号「归途有光·和孩子一起重启」——一个**也在重启的普通爸爸**，家有 15 岁男孩，走过弯路、不擅表达、不说教、不端着。是"同路人"，不是"导师"，更不是"主播"。

**两条不可让步的原则**：
1. ⭐ **一条视频必须自成一体，而且要覆盖到文章八成**——观众光看这条就该学到东西；**只剩两成（最细的操作细节）留给公众号**——**视频给八成、公众号给两成**，不是反过来。
2. **先让内容值得被转，再谈引流**——视频号靠社交推荐分发。写稿时先问一句："这条，我会转给我朋友吗？"
   ⚠️ **口径提醒**：本项目后台那句"社交型新增关注是推荐型的 33 倍"是**公众号文章组之间**的渠道对比，
   只能说明**方向**（社交型渠道转化远高于推荐型），⛔ **不是视频号的实测效果证明**。
