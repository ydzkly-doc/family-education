## 安卓端公众号正文右侧裁切 bug（重要·跨系列通用）
- 现象：青春期30讲第1篇发公众号后，安卓（腾讯X5/TBS内核）朋友圈打开右侧内容被裁、显示不全；iOS（WebKit）正常。
- 根因：680px 主表同时写了 HTML 属性 `width="680"`（固定宽）+ CSS `width:100%;max-width:680px`。安卓 X5 更认 HTML 属性→死撑 680px，窄屏(360-410px)溢出裁切；iOS 听 CSS 的 width:100%→自适应正常。

- 第一次只改主表 width="680"→"100%" 无效，用户复测安卓仍右裁。

## 【重大标准变更】正文布局 table → section 流式（安卓裁切根治）
- 根因（微信官方《编辑器插件开发规范》确认）：微信安卓 X5 内核会把 `<table>` 宽度**固化**，窄屏(360-410px)整列右裁（右侧文字/卡片被屏幕切掉、显示不全）；iOS WebKit 二次缩放故正常。表现="安卓左右显示不全、苹果正常"。`width:100%`、剥 data-id、拖窄浏览器窗口复制都没用——根子是 table 布局本身。
- 解法：正文布局全部改 `<section style="box-sizing:border-box;width:100%;…">` 流式嵌套；卡片用 background/padding/border-radius/border-left；禁 `<table>/<tr>/<td>`、禁容器级固定宽(width/max-width:≥200px)、禁 align="center" 居中嵌套；多列网格(三季卡)→纵向堆叠满宽 section；竖条小标题→ border-left。
