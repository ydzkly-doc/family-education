## 一、内容红线（不可让步）

**1. 文章类型分轨**（细化见工坊 `02-writing.md`）：
- **方法文/概念文** → 场景 / 父母心理转折 / 机制 / 方法 / 边界**五层齐全**。
- **叙事文** → 允许缺机制与方法，但**必须有场景、心理转折、边界**，按三条替代标准验收：细节诚实度 / 情绪克制度 / 承认不确定。
- **⛔ "允许缺方法" ≠ "可以不写边界"**——厌学/自伤/抑郁等议题，专业求助边界照样必须写。

**2. 叙事真实性三分法（最高门槛）**：①用户确认真实经历→可写"我和儿子"；②课程案例/改编→**第一屏标注"场景改编"**；③他人案例→第三人称。**红线：绝不把讲师自述改写成"我"。**

**3. 事实核验**：书中模型写"书中提出"、课程观点写"课程认为"；**研究/数字/履历发布前核验来源，核不到不写**；不写"必然导致"。

**4. 人物连续性**：孩子固定 **15 岁 / 高一 / 儿子**；叙事者"一个也在重启的爸爸"；后台【作者】用账号名"归途有光·和孩子一起重启"。

**5. ⛔ 正文禁例三条**（外部爆款反面样例，传播有效但一律不写）：①绝对化归因+制造羞耻 ②密集引用不标出处 ③结尾居高临下给指令。三条均有替代写法（见 SOP）。

**6. 过稿捷径警惕**（2026-09-14）：写完 N 个并列分论点，必须做**"核心动作提取"**比对——同质即合并或换角度。同质并列读着顺、极易过稿，但只有"干货感"、无信息增量。

## 二、目录落位（强制）

**根目录只允许：内容系列目录 + `.git/` `.gitignore` `.workbuddy/` + 固定管理目录。**

| 产物 | 落位 |
|---|---|
| 文章/讲书系列 | 根目录平铺 |
| 工具脚本 | `工具脚本/`（**不改名**，被引用 29 处） |
| 专家包及派生物 | `_专家/` |
| 长期资产（素材池/数据复盘/SOP变更日志/技法库） | `_资产/` |
| 备份 | `_备份/<对象>/` |
| 一次性报告/临时小样 | `_档案/报告/` |

- `_` 前缀 = 管理类；**产物落位在动手前想好**；移动文件**必须同步改引用**。
- **过程目录不要挪**：`_过程文件/` `_封面候选/` `_预览/` `_归档/` 等**设计上留在系列内**，由 `工具脚本/过程文件过期扫描_scan_stale.py` 按保留期管理（预览 7天 / 备份 14天 / 素材 14天 / 档案资产不过期）。**只有 `_backup*/` 归口到 `_备份/<系列名>/`**。
- **⭐ `.gitignore` 必须用「前缀+`*`」，禁精确目录名**：过程目录**会带后缀变体**（`_封面候选_新SOP`、`_封面样板_Gate3`、`公众号文章_预览/`），精确名会漏掉（曾致 60MB 过程图误入库）。
  - **⚠️ 两处反例**：`_资产/技法库/_拆解报告/` 是**正式成果、不可忽略**；`_build_preview.py` / `_render_upgrade.py` 是**正式工具、不忽略**——别被 `_` 前缀误判。
  - 改 .gitignore **管不到已跟踪文件** → 需 `git rm --cached` 出库（磁盘保留）。
