## 一、内容红线

1. **文章类型分轨**（`02-writing.md`）：方法文/概念文 → 场景·心理转折·机制·方法·边界**五层齐全**；
   叙事文 → 可缺机制与方法，但**必须有场景·心理转折·边界**。**⛔"允许缺方法"≠"可不写边界"**。
2. **叙事真实性三分法（最高门槛）**：①确认真实经历→可写"我和儿子"；②课程案例/改编→**第一屏标"场景改编"**；③他人案例→第三人称。**红线：绝不把讲师自述改写成"我"。**
3. **事实核验**：书中模型写"书中提出"、课程观点写"课程认为"；**研究/数字/履历核不到不写**；不写"必然导致"。
4. **人物连续性**：孩子固定 **15 岁/高一/儿子**；叙事者"一个也在重启的爸爸"；后台【作者】用账号名"归途有光·和孩子一起重启"。
5. **⛔ 正文禁例三条**：①绝对化归因+制造羞耻 ②密集引用不标出处 ③结尾居高临下给指令。
6. **过稿捷径警惕**：并列分论点须做**"核心动作提取"**比对——同质即合并或换角度。
7. **卡片张数按内容厚度定**：**张数是"果"不是"因"**——先数长文**独立核心意思**，区间 **3–5 张**，**3 张常为正解**。**Gate A 须写明张数依据**。
