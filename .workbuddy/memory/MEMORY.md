## 一、内容质量总纲（最高优先级）

**0. ⭐ 完整性红线（先于一切节流指标）**：判断标准不是"有没有重复"，而是"删完以后各层是否仍然完整"。**五层——场景 / 父母心理转折 / 机制 / 方法 / 边界**。自查顺序：**先保该有的层齐全 → 再压重复句**；节流伤到层宁可不改；重复句优先"换说法"而非整段删。
- **⭐ 2026-09-14 起按文章类型分轨**：**方法文/概念解释文**（清单工具/概念解释/问题复盘）→ **五层齐全**；**叙事文**（现场故事/对话拆解/书信自问自答）→ **允许缺机制与方法**，但必须有场景/心理转折/边界，并按"叙事文三条替代标准"验收：①细节的诚实度（写"不体面的真实反应"而非"正确的情感"）②情绪的克制度（不给廉价出口）③不确定的承认（不给完满结局）。
- **⛔ 硬边界："允许缺方法" ≠ "可以不写边界"**——厌学/自伤/抑郁等议题，专业求助边界照样必须写。
- **脚本指标全绿 ≠ 文章完整**；补内容只能用已确认素材，禁重复金句/同义改写/无据结论凑篇幅。

**1. 叙事真实性三分法（最高门槛）**：①用户确认的真实经历→可写"我和儿子"；②课程案例/改编→**第一屏标注"场景改编"**；③他人案例→第三人称，**绝不转成作者本人**。红线：不把讲师自述改写成"我"。

**2. 人物连续性**：孩子固定 **15 岁 / 高一 / 儿子**；叙事者"一个也在重启的爸爸"；后台【作者】字段用账号名"归途有光·和孩子一起重启"。

**3. 打破模板感**：6 种结构轮换（现场故事/问题复盘/对话拆解/清单工具/读书概念解释/一封信·自问自答）。单篇"不是…而是…"≤2、"那一刻/忽然/慢慢/一点点"合计≤3、"愿你…"不每篇用。**相邻篇语言指纹**（判定单位是"相邻"）。"我后来试着做的几件小事"**只在方法文**用。
- **⭐ 并列式分论点不得同质（2026-09-14 新增硬检查）**：写完 N 个分论点必须做**"核心动作提取"**——把每点核心动作写成一句话比对，同质即合并或换角度（同质并列读着顺、极易过稿，但只有"干货感"）。
- **小标题拟法**：**进程式**（2–4 字动词/状态词，连起来构成心理进程线，如"拉扯→停学→解除烙印"）/ **场景锚定式**（"当孩子…时"，须去命令感）。
- **开头可轮换"旁观者视角"**：只写看见的不写猜测的、对象最好是陌生人、不借旁观嘲笑他人。
- **不强制装配件**：金句块/三件事/系列地图/下篇预告都是可选零件；系列地图只在首末/总导航篇。
- **篇幅**：普通稿 1600–2400（轻 1600–1900 / 深度 1900–2400），速览 900–1400。区间是报警器不是配额。**删改降幅≥30% 必须额外复核**叙事张力/情绪承接/方法细度/节奏。
- **动笔前先数素材**：真实/改编细节≥2、机制≥1、可照念台词≥1、边界≥1、场景起点；五项≈900–1100 字。**撑不到先补素材，不硬凑**。
- 工具：`模板感诊断_template_scan.py --dir "<系列>/公众号文章"`（`--count` 字数 / `--diag-structure` 结构 / `--baseline` 降幅）。

**4. 标题去同质化**：系列内轮换情绪共鸣型（≤1/3）/问题解决型/认知反差型。**禁用无依据夸张**。1 主 2 备都要正文兑现、事实站得住。**标题用白描不用标签词**（"不去上学了"而非"厌学躺平"）。

**5. 系列规模与去重**：普通系列 3–5 篇（长课程可用 1 篇总导航承接）。跨系列用**"处理原则"而非"禁令"**——主题主线区分、核心原则重复强化、表达与场景变化；去重只约束核心问题/主要论证/整篇结构；**账号锚点（先理解再纠正 / 减少羞耻 / 把目标拆小 / 区分孩子和行为）允许跨篇复现**，但须贴合新机制新场景，不得原段复制。

**6. 事实核验与边界（发布前必过）**：故事标明真实或改编；书中模型写"书中提出"、课程观点写"课程认为"；**研究/数字/履历发布前核验来源，核不到不写**；经验归纳写"常见的几种情况"，不写"必然导致"。

**7. 真实素材池**：`_资产/真实素材池.md`（6 项记录法）。每篇接 ≥1 个确认细节强于全篇虚构。

**8. 数据复盘闭环**：`_资产/发布数据复盘.md`。**真 A/B = 两个备选标题分发到不同渠道/时段**。积累 20–30 篇再调参数。

**9. 账号级视觉识别**：固定 1 个账号主色 + 2–3 个副色；视觉语言"暖光/近景/留白/物件语言"；封面走无人物静物。

**10. ⛔ 正文禁例三条（2026-09-14，外部爆款反面样例，在传播上有效但一律不写）**：①**绝对化归因+制造羞耻**（"全看父母的嘴"）→ 违反"减少羞耻"；②**密集引用不标出处**（转述冒充原话）→ 违反"核不到来源不写"；③**结尾居高临下的指导**（"亲爱的爸爸妈妈们，嘘，别说话"）→ 与人设"同路人非导师"冲突。三条均附替代写法（见 SOP）。

**11. 收尾两条（叙事文）**：①**承认不确定，不给完满结局**（不能变成"丧"，须留微小正向锚点；方法文不适用）；②**"他人提问—自己回答"**（直接说结论=说教，被追问后回答=坦白；回答要低不要高）。

**流程弹性**：关卡是为了不让 Agent 替用户决定，**不是每步都必须停**；关卡前多给选项、信息不足优先问、主动暴露不确定性。
- **⚠️ 但"弹性"不作用于"跳过 Gate 1/2/3 的确认"**。用户说"你定就行/继续做"时，**授权仅限当次点名的那一步**，不得推及未提及的关卡。**减少 present_files ≠ 减少确认。**

## 三、排版与 HTML 规范

**结构铁律**：布局一律 `<section>` 流式，**禁 `<table>` 做布局**（微信安卓 X5 会把 table 宽度固化、窄屏右裁）。
- **⭐ 改架构级规则时，清扫范围必须含「顺带提及的描述句」**（2026-09-14 踩坑）：9-05 改 section 流式时只改了规范条文主体，**agent 骨架第 101 行、README、3 个细则里的 table 描述句全部漏改**，长期自相矛盾。同批还发现 `工具脚本/微信公众号排版HTML规范.md` **顶部声明禁用 table、下面四节却仍按 table 写**（白名单甚至写着"允许 table/tr/td"）。→ **架构级改动要全库 grep 旧关键词，覆盖 README / 配套工具文档 / "顺带提及"句，不能只改主规则。**
- **⚠️ 纯词替换有陷阱**：`05-publish-kit.md` 生图提示词里的 `hands/table` 是英文**"桌子"**（提示模型别裁掉手/桌），**不是 HTML 标签**，全局替换会毁掉提示词。改前必须逐条看上下文。
- 标签白名单：`section/p/span/b/strong/br`；**禁 div/h1-4/ul/li/img/data-*/class/`<style>` 块**。文字颜色写在 `p/span/b/strong` 自身，`section` 只放 background/padding/width/border。
- **白字大标题**：一行一个独立 `<p style="color:#fff;text-align:center;display:block;">`，**禁 `<br>` 拆行**。
- 标准骨架：标题色块 → 改编声明（第一屏）→ 开场叙事 → 台词卡 → 竖条小标题×N → 正文 → 方法卡 → 金句居中块 → 边界 → 陪伴卡（无动作指令）→ 来源声明（米白 `#faf9f6`+灰字 `#9a9890`）。
- **微信丢样式三根因（修序 A→C→B）**：A `data-*` 残留 → 删；C div/h 骨架+白字 br 拆行 → 改 p；B 颜色挂 section → 下沉。一键工具 `微信HTML规范校验修复_wx_html_fix.py`（`--check` / 无参修复，幂等）。**交付铁律：全部正文 `合格 N/N`。**

**色板**：学习认知类墨蓝绿 `#3f6f6a`/深 `#2f5753`/浅底 `#f0f5f4`；情感治愈类赤陶棕 `#b06a48`/深 `#8a4f33`/浅底 `#faf3ec`；长系列按季分色（暖陶橘 `#c0764f`/雾蓝绿 `#5f8a86`/暖金棕 `#c0924f`）。台词·方法卡暖琥珀 `#d9963f`/深字 `#b4730f`/底 `#fef6ec`；正文 `#3a322c`。忌高饱和原色铺屏。

## 七、交付与确认纪律（跨系列通用）

**两件必须分开的事：**
- **① `present_files` 不必每次都调用**。中间过程的验证/自检/脚本输出一律不必交付；打开 HTML 预览会渲染整页、是耗时主因。**是否交付、是否打开预览，以用户明确指令为准**。
