## 视频文件移出版本库 + 提交推送（用户要求）

**用户原话**：「家庭教育下做了很多更改，需要 push 到 git，但是要**忽略视频文件**，因为太大了，
**视频文件包括原始视频和合成后的视频**」。

### 做法
1. **`.gitignore` 追加视频规则节**（放在"管理目录"之后）：**用「扩展名」不用「目录名」**——
   `*.MOV`／`*.MP4`／`*.mov`／`*.mp4`／`*.m4v`／`*.MTS`／`*.avi`／`*.mkv`／`*.flv`／`*.wmv`。
   ⚠️ **大小写都要写**：手机导出是 `.MOV`、管道产出是 `.mp4`（同一坑见 `_备份*` 那条教训）。
2. **`git check-ignore -v` 实测**（项目纪律，改完必做）：
   - **50 个视频全部命中**——原始素材走 `*.mov`（Windows 下 core.ignorecase 也认 `.MOV`）、
     成片与旧版走 `*.mp4`、过程拼接走**既有的 `_过程文件*`** 规则；
   - **反向验证**：封面 `png`、文案 `md` **未被忽略** ✓。
3. `git add -A` → **55 项、0 个视频**；新增 31 个文件共 **14.51 MB**（12 张封面 png ＋ md/txt/py）。
4. 提交 `46f92af`「内容更新：视频号文案 01–06 定稿 + 技能/工坊规则同步；视频文件不入库」→ push `origin/main`。
