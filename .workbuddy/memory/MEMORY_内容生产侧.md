### ⭐ 两载体分工（2026-10-03 用户定；**后续每个系列都按此走**）

> **用户原话**：「一个文章可能对应多个视频……**公众号文章是视频号的素材来源**，视频号可以**根据自己的节奏安排**，
> 因为**两个载体传播属性不一致**……公众号用于承接愿意阅读长文的人，一篇文章讲解内容深和透；
> 视频号满足的是快节奏的人群，短快，但也要求单视频有营养。两个载体虽然受众不一样，但都是为了讲清楚一个系列。」

| | **公众号** | **视频号** |
|---|---|---|
| **承接谁** | 愿意读长文的人 | 快节奏人群 |
| **形态** | 一篇**讲深、讲透**（完整判据／工具全文／逐字台词） | **短快**：一条一个点，单条**要有营养** |
| **角色** | **素材来源**（内容库） | **产出**（按自己的节奏重组） |
| **"完整"** | 一篇之内讲透（可以长） | 单条自成一体 ＋ **整个系列不重叠、不遗漏** |

**⇒ 三条硬约束**：① ⛔ **不是"一篇 = 一条"，是"多对多"**（一条可跨几篇取材；一篇可拆成几条）；
② ⛔ **《系列视频地图》的组织轴 ＝"视频号自己的节奏"**——⛔ **不许出现"第 X 篇拆成几条"这种分节**（主表一律"按发布序的条清单"，「素材来源」只作标注列）；
③ **两载体覆盖分开算**（公众号＝**每篇自身**讲透；视频号＝**视频群合起来** ≈80%）。
**细则落点**：专家包 `video-script-studio` SOP 的「⭐ 两个载体的分工」（在「两条最高原则」之后）。

### ⭐⭐ 口播标点（2026-10-05 用户点名立；**改口播稿前先看这条**）

> 用户原话：「为什么在标点符号上**只使用逗号和句号**？可以多一些标点符号，**比如明显是问句，就应该用问号**；
> 而且**明显两句话上下承接的关系，你直接用了句号**。」

**能用哪些标点**（管道只认这几个，⛔ 别自己发明）：句末 `。？！`｜句内 `，、；：`。
- ⚠️ **断句只看行末的 `。？！`**（字幕按这个切）；**`，、；：` 只在句内起停顿作用**。
- ⛔ **口语里不写破折号**（`——` 会被强制断行，SOP 也禁）；⛔ **不要用 `……`**（管道不认）。

**三条强制**：
1. ⭐ **问句就要用 `？`**——汇报式问句（"什么时候算做到？""要不要当着大家更正过来？"）也算问句。
2. ⭐ **承接的两句要连成一句**（`，`；各自还带小停顿就用 `；`），目标 **15~35 字、2~4 分句**。
   ⛔ **不许"每行一个短句、行末都落句号"**（电报腔）。
3. ⭐ **锚点句必须独占一行、以 `。？！` 收尾**——所以**锚点与下一句之间那个句号是"必须的"**；
   读起来要衔接，就在**下一句开头加连接词**（"所以…""它…""毕竟…"），⛔ **不是把锚点句并进长句**。
