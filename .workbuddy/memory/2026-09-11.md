## 封面清晰度问题：找到两个原因（2026-09-11 上午）

用户对比 Codex 生成封面（摆烂第1篇）与我生成封面（青春期30讲第3篇），问"清晰、细腻度差异很大，有什么办法"。

### 量化结论（两张均 1200x511，非尺寸问题）
| 指标 | Codex | 我 |
|---|---|---|
| 独立色阶数 | 72,488 | 33,832（Codex 2.1×） |
| 高频细节能量 | 3.93% | 2.81%（Codex 高 40%） |
| 边缘锐度 | 88.5 | 461.2（**假象**：扁平插画硬边缘虚高） |

**关键认知**：拉普拉斯锐度对扁平插画**虚高**，不能当清晰度依据；要 **独立色阶数 + 高频细节能量**。

### 原因1：我的处理链路缺陷（已修）
- 旧做法：生成 **1024x1536 竖图** → 裁 2.35:1 横带 → **放大**到 1400
- 竖图裁横带浪费 ~60% 像素，剩余再放大，**两步都丢细节**
- 实测：竖图裁带放大1400 → 细节保留 **86.1%**；横图裁带缩小1200 → **97.6%**；放大 1.37× 锐度损失 ~45%
- **修正（已写 SOP 05-publish-kit.md B2/B3/B4）**：生成一律 **横图 1536x1024**；后处理**只缩不放**；推荐终稿 **1200x511**

### 原因2：风格差异（**待用户决定**）
- SOP 原文指定"**扁平治愈插画风**"，此风格像素级细节天然少
- 写实摄影（真实材质纹理/浅景深/细颗粒）色阶数约 2.1 倍
- 已写入 vision.md，但**明确要求切换前须 Gate 3 与用户确认**——这是账号视觉识别变化，不单方面替换
- 全库现状：写实类 28 张 / 插画类 18 张 / 中间 16 张（已混）

### 实测验证
- 用 1536x1024 横图生成测试图，走新链路（裁带→缩到1200）出片，细节保留率 97.6%，肉眼可见细腻度提升
- 测试产物在 `_档案/封面测试_20260911/`

### SOP 同步
- cache → marketplace → zip 三处**完全一致**；validate_expert.py ✅
- 变更日志已写入 `_资产/SOP变更日志.md`
