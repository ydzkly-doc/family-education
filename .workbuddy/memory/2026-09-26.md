## ⑨ 复盘文档 ＋ 下一条拍摄规范（用户要求"把经验总结下来"）

### ⭐ 查代码得到的三条硬事实（决定"怎么拍"）
1. **多文件模式**：`preserve = None`（`video_make.py:865`）→ **所有 >0.8s 的静音都被压到 0.35s，包括第一段开头与最后一段结尾** → **片头留白不会自动变成钩子的位置**。
2. **单文件模式**：`preserve = 1.2`，但 `find_segments` 从 `cur=0` 开始、**片头/片尾静音不算"段"**（`s-cur=0` 不满足 `>0.3`）→ **边缘静音会在"段间叠化"那步被裁掉**。
   - 顺带确认：**单文件的段边界靠 `-35dB` 猜**，有底噪会静默退化成 1 段（无叠化/无色温对齐）。
3. ⛔ **管道只剪"静音"，不剪"说错的话"** → **一次成片里口误留在片子里**（这是"分段拍"真正的价值：说错只重拍那一段）。
   → 拍摄纪律：**说错＝整段重录**，**不要在同一段里重说那一句**（会两句都留下，锚点还可能挂到前一次）。
