# 第 7 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第7篇_手机游戏.html`**。全篇 table+内联样式，**零 `<img>`**。本篇含一张**可打印、双方签字的《家庭手机使用约定》**，是全系列工具性最强的一篇，建议读者截图/收藏。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第7篇_手机游戏.html` → `Ctrl+A` → `Ctrl+C`。
2. **新建图文**：后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要，标题与正文大标题逐字一致。
4. **传封面**：上传本文件夹 **`封面_第7篇_手机游戏.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：重点看《手机约定》签字栏、堵/疏对照卡、7 天打卡表不溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：手机约定卡（五条+签字栏）完整、不横向溢出
- [ ] 无"点在看/转发/求关注"等动作指令；无绝对化承诺
- [ ] 坐标小字为"第二季 · 做功课"

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 深夜十一点，我和十五岁的儿子为抢一部手机，在床上拽得谁也不松手。
> 没收、摔机、断网，都试过，越禁他越馋，看我像看敌人。
> 后来我才明白：游戏不是病因，是他现实里找不到成就感时抓住的替代品。
> 别去堵洪水，去种庄稼。我把"我命令你"换成了一张双方签字的约定，
> 那场打了三年的仗，第一次有了停火的意思。约定模板在文末，可直接打印。
