# 第 18 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第18篇_收官合集.html`**。全篇 table+内联样式，**零 `<img>`**。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第18篇_收官合集.html` → `Ctrl+A` → `Ctrl+C`。
2. **新建图文**：后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要。
4. **传封面**：上传本文件夹 **`封面_第18篇_收官合集.jpg`**（2.35:1、约1200×511、无文字无水印、≤200KB；封面批次生成后放入，放入前先确认文件在位）。
5. **手机预览**：重点看7张救命小抄长卡、知道到做到三步卡、18站完整地图不溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：7张救命小抄长卡、知道到做到三步卡、18站完整地图不挤、不横向溢出
- [ ] 无“点在看/转发/求关注”等动作指令；无绝对化承诺

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 半年前我收藏了上百篇“如何教育青春期孩子”的文章，篇篇看得热泪盈眶。
> 可第二天一开门，儿子一顶嘴，道理全忘，照样吼、照样后悔。
> 后来我懂了：光听懂没用，做到一件，胜过收藏一百篇。
> 收官这一篇，我把30讲压成7张能贴冰箱、能照念的救命小抄，
> 也说说那段从“知道”到“做到”最远的路。
> 18站，我们一起走完了。门一直开着，光就一直都在。
