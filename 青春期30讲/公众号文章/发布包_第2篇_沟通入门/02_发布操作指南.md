# 第 2 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第2篇_沟通入门.html`**（一份，不另存副本）。全篇用 table+内联样式绘制，**零 `<img>`**，粘贴即图文完整，无需上传任何正文图。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：用浏览器打开本文件夹 `正文_第2篇_沟通入门.html` → 页面里 `Ctrl+A` 全选 → `Ctrl+C`。
2. **新建图文**：登录公众号后台 mp.weixin.qq.com → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V` 粘贴。
3. **填字段**：照 `01_标题作者摘要.txt` 填【标题】【作者】【摘要】；标题与正文顶部大标题逐字一致。
4. **传封面**：上传本文件夹 **`封面_第2篇_沟通入门.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：扫码在手机上看一遍 → 重点看"禁语/替换对照卡"和"7 天打卡表"是否溢出 → 存草稿 / 定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字，且与正文大标题**逐字一致**
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位（扶鹰教育·王金海《青春期三十讲》）
- [ ] 手机端：左右对照卡（✕/✓）不挤、7 天打卡 7 格完整显示
- [ ] 全篇无"点在看 / 转发 / 求关注 / 分享给"等动作指令
- [ ] 无绝对化承诺；"我家孩子"片段为 15 岁男孩、共情口吻

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 儿子放学进门，我端着水果问了句"考得怎么样"，他戴上了耳机。
> 那一刻我才反应过来：我所谓的"关心"，开口全是我的焦虑。
> 后来我把进门第一句换了——先不问学习，先接"人"。
> 第七天，他主动跟我说了十分钟篮球。
> 把我家踩过的坑和一句能直接照念的开场白，写在这篇里了。
