# 第 4 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第4篇_叛逆情绪.html`**。全篇 table+内联样式，**零 `<img>`**。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第4篇_叛逆情绪.html` → `Ctrl+A` → `Ctrl+C`。
2. **新建图文**：后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要，标题与正文大标题逐字一致。
4. **传封面**：上传本文件夹 **`封面_第4篇_叛逆情绪.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：重点看"火上头三句话"对照卡、3 天打卡表不溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：左右对照卡（✕/✓）不挤、3 天打卡完整
- [ ] 无"点在看/转发/求关注"等动作指令；无绝对化承诺
