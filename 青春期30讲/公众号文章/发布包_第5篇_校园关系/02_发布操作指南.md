# 第 5 篇 · 发布操作指南（第一季 · 搞关系 收官）

> 正文就是本文件夹的 **`正文_第5篇_校园关系.html`**。全篇 table+内联样式，**零 `<img>`**。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第5篇_校园关系.html` → `Ctrl+A` → `Ctrl+C`。
2. **新建图文**：后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要，标题与正文大标题逐字一致。
4. **传封面**：上传本文件夹 **`封面_第5篇_校园关系.jpg`**（2.35:1、1200×511、无文字无水印、≤200KB，已就绪，直接选用即可）。
5. **手机预览**：重点看三角色卡、三可卡、三步复盘表不溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：三栏"挡枪/媒婆/拜菩萨"卡不挤、复盘表完整
- [ ] 无"点在看/转发/求关注"等动作指令；无绝对化承诺
- [ ] 篇尾"上一站/下一站"标题与第 4、6 篇主标题一致

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 儿子被老师当众罚站，憋着一肚子气回家。
> 我张口就来："一个巴掌拍不响，你也有错。"
> 他抬头看我那一眼，不是愤怒，是"连你也不站我这边"的凉。
> 后来我才懂：孩子在外面是弱势，回家要的是靠山，不是第二个裁判。
> 先站队、再讲理——顺序反了，道理再对也推不近他。
