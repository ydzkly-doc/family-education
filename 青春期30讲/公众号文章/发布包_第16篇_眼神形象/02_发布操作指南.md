# 第 16 篇 · 发布操作指南

> 正文就是本文件夹的 **`正文_第16篇_眼神形象.html`**。全篇 table+内联样式，**零 `<img>`**。

## 一、5 步发布（约 2 分钟）

1. **复制正文**：浏览器打开 `正文_第16篇_眼神形象.html` → `Ctrl+A` → `Ctrl+C`。
2. **新建图文**：后台 → 草稿箱 → 新的创作 → 图文消息 → 正文区 `Ctrl+V`。
3. **填字段**：照 `01_标题作者摘要.txt` 填标题/作者/摘要。
4. **传封面**：上传本文件夹 **`封面_第16篇_眼神形象.jpg`**（2.35:1、约1200×511、无文字无水印、≤200KB；封面批次生成后放入，放入前先确认文件在位）。
5. **手机预览**：重点看耐心两件事卡（帮坚持/陪不挑剔）不溢出 → 存草稿/定时发布。

## 二、发布前自查清单

- [ ] 标题 ≤64 字、钩子在前 20 字、与正文大标题逐字一致
- [ ] 课程笔记类，**不声明原创**
- [ ] 文末【来源声明】在位
- [ ] 手机端：耐心两件事卡（帮坚持/陪不挑剔）不挤、不横向溢出
- [ ] 无“点在看/转发/求关注”等动作指令；无绝对化承诺

## 三、本篇朋友圈 / 家长群转发文案（一屏内）

> 我随口问儿子：“你小时候最怕爸爸什么时候？”
> 他说：“不是你打我骂我，是你那种眼神——不说话，就看着我，一脸‘你怎么又这样’。比挨打还难受。”
> 我心里咯噔一下。原来真正刻进他心里的，不是我说了什么，
> 是我脸上那个自己都没察觉的表情。
> 父母的样子，会一点点内化成孩子心里的声音：
> 挑剔的脸，是他一生的枷锁；信任的笑，是他一生的底气。
