# 本地文生图（local-imagegen）

## 一句话

一条命令本地出图，形态和 ffmpeg 一样：独立程序 + 模型文件，离线可跑。

```bash
python 工具脚本/本地生图_生成.py --prompt "英文提示词" --preset cover --out "输出路径.jpg"
```

程序与模型在仓库外：`D:\local-imagegen\`（`bin-vulkan\sd-cli.exe` + `models\DreamShaper8_LCM.safetensors`）。
**用带 Pillow 的 Python 运行**；DSH 自带的那个在
`C:\Users\ZhuanZ\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`（含 Pillow 12.3，已验证）。

## 预设（选 preset 即可，不用自己算尺寸）

| preset | 产出 | 体积上限 | 后处理 | 用途 |
|---|---|---|---|---|
| `cover` | 1200×511（2.35:1） | ≤200 KB | 中央方形安全区 + 两侧模糊背景 | 公众号长文封面 |
| `card` | 900×1200（3:4） | ≤100 KB | cover 裁切 + 柔化 + 压暗 | 卡片文章底图 |
| `raw` | 生成原图（512×512） | — | 无 | 需要自己再加工时 |

`cover` 与 `card` 直接对应公众号 SOP 的封面规范（2.35:1 / 无文字 / 核心意象居中安全区）与卡片规范
（3:4 / 单张 <100KB / 底图一律柔化），出图即合规，不必再手工裁切压缩。

## 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--prompt` | 必填 | **英文提示词效果最好**（模型 CLIP 是英文的） |
| `--preset` | `cover` | 见上表 |
| `--out` | 必填 | 成品路径，**可以含中文** |
| `--batch` | 1 | 一次出几张（不同种子），文件名自动加 `_00` 后缀 |
| `--seed` | 随机 | 固定种子可复现；batch>1 时作为起始种子 |
| `--steps` | 6 | LCM 模型 4~8 步足够，加大收益很小、耗时线性增长 |
| `--size` | 512 | 生成分辨率；显存不足时调小 |
| `--json` | 关 | 结构化输出，便于程序解析结果 |

一次约 **50 秒/张**（Vulkan/核显）。`--batch 3` 就是约 2.5 分钟。

## ⛔ 三个坑（踩过，别再踩）

1. **中文路径不能直接给 sd-cli.exe。** 参数经 UTF-16→GBK 双重编码会坏，文件会写成乱码名或报
   "Access is denied"。封装脚本已把原图写到纯 ASCII 的 TEMP 再转存，**所以不要绕过封装直接调 sd-cli**。
2. **不要往 TEMP 的子目录写。** 沙箱只授权 TEMP 根目录本身，`mkdtemp()` 建的子目录反而被拒。
3. **sd-cli.exe 写不进工作区目录**（只认 TEMP），**也写不进仓库外目录**（沙箱限制）。成品落盘一律由
   Python 完成 —— Python 处理中文路径没问题，可以直接写进仓库。

**因此：整条链路在「工作区可写」的受限模式下即可完成，不需要提权。** 如果封装脚本报
`Permission denied`，先确认没有绕过它自己调 sd-cli。

## 能力边界（重要，别过度承诺）

| 题材 | 本地效果 |
|---|---|
| 静物、门、窗、光影、氛围、抽象意象 | ✅ **可用**，是主战场 |
| 插画感、简约图形 | 🟡 基本可用，可能要试几张 |
| 写实人物、人脸、手、复杂建筑 | ❌ **别用**，改用外部生图服务 |

分辨率上是 512×512 原生。`cover` 预设的中央方形正好用足 511 高、**无放大**，所以清晰；
`card` 预设会放大到 900×1200，**靠柔化掩盖**（SOP 本来就要求柔化，所以不违和）。

## 与公众号 SOP 的衔接

- SOP 里写「**AI 出无字底图 → 脚本叠中文**」：本地出图**天然无字、无水印**，比云端更省事 ——
  云端那张"去 AI 水印角标"的后处理步骤可以省掉。
- SOP 里「**生成前必须告知用户消耗积分**」：本地路线**不消耗积分**，这条自动失效。
- SOP 里「**底图一律柔化**」：`card` 预设已内置（blur=6 + 压暗 0.85），直接满足压进 100KB 的要求。

## 出图不理想时

1. **换英文写法**：具体场景 + 光线 + 情绪词，比抽象词有效；
   `still life, a ceramic cup on a wooden windowsill, soft morning sunlight, muted colors, no text`
2. **加 `--batch 3`** 一次出几张挑一张（约 2.5 分钟）。
3. **末尾固定加** `no text, no letters, no watermark` —— 虽然模型基本不写字，但能进一步降低风险。
4. **别加 `--steps`**：LCM 模型 6 步已够，加到 20 步只会慢 3 倍。
