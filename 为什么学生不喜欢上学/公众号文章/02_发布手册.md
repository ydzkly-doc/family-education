# 发布手册（归途有光和孩子一起重启）

> 每篇正文就是它「发布包_第X篇」文件夹里的 `正文_第X篇_短标题.html`（图文一体，卡片全用 section+内联样式绘制、无位图）：浏览器打开 → 全选(Ctrl+A) → 复制(Ctrl+C) → 公众号后台新建图文 → 粘贴(Ctrl+V)，标题、正文、内嵌卡片、来源声明一并带过来，无需手动插图。
> 每个发布包内含 `正文_第X篇_短标题.html` + `01_标题作者摘要.txt`（标题/作者/摘要/标签）+ `02_发布操作指南.md` + 封面图，照着约 2 分钟/篇。

## 二、发布操作步骤（每篇通用，用发布包最省事）

1. **打开正文**：进 `发布包_第X篇_短标题/`，双击 `正文_第X篇_短标题.html`，浏览器打开（正文只此一份，就在发布包里）。
2. **全选复制**：在页面按 Ctrl+A、Ctrl+C。
3. **后台新建图文**：内容与互动 → 草稿箱 → 新的创作 → 图文消息 → 编辑区 Ctrl+V 粘贴。标题、加粗、卡片色块、来源声明一起带过来。
4. **填字段**：照 `01_标题作者摘要.txt` 填标题、作者、摘要、话题标签。
5. **传封面**：上传发布包里的封面图（封面必填，正文内嵌卡片无需另传图）。
6. **手机预览**：点"预览"发到自己手机，检查换行、卡片、错别字。
7. **定时群发**：选固定晚 8–9 点。
> 详细 5 步图解与本篇自查清单见各发布包内 `02_发布操作指南.md`。

## 四、发布前自查清单

- [ ] 标题戳痛点、30 字内
- [ ] 开头 3 行内是具体场景、不是术语
- [ ] 手机端预览：卡片色块、行距、加粗正常，金句无孤字换行、卡片无横向溢出
- [ ] 金句小标题完整、无编辑备注残留
- [ ] 口误硬伤已规避（NBA=篮球、"疆"字、阿尔泰山、艾宾浩斯）
- [ ] 结尾是"3件事 + 下篇预告 + 祝愿式收口"，**无"点在看/转发/关注"等动作指令**
- [ ] 文末「来源声明（读书笔记）」在位；**读书笔记类不声明原创**
- [ ] 无绝对化表述
- [ ] 已加话题标签、归入同一合集
