## 〇、这个模块解决什么（先看这四问）

> **它不是教你"怎样把孩子教育得更好"**——那是 A／B 板块的事。
> 它是**刹车、护栏和责任边界**，回答的是另外四个问题：

| # | 问题 |
|---|---|
| 1 | **哪些事情我可以做？** |
| 2 | **哪些话我可以公开讲？** |
| 3 | **什么时候必须停止给建议？** |
| 4 | **什么情况需要转给更专业的人？** |

## 三、⛔ 不把教育问题当成态度问题

**面对厌学、长期无法到校、严重失眠这类情况，不能简单判断为**「**懒惰**」「**逃避困难**」「**手机成瘾**」。

> 这类标签的问题不是"说得难听"，而是**它会把一个需要评估的问题，变成一个需要管教的问题**——方向直接错了。

**正确姿势**：先描述**可观察的行为与持续时间**，再评估，**不先归因**。

## 四、未成年人隐私与案例使用

### 写进文章或课程前必须做的五步

1. **知情同意**——涉及孩子的具体信息，先取得同意；
2. **最小披露**——能模糊的就模糊（学校名、班级、可识别事件一律模糊化）；
3. **匿名化**——公开内容不出现可识别孩子的信息；
4. **可撤回**——孩子或家人要求撤下，**立即执行**，不做解释性拖延；
5. **留痕**——在 `05_学习成果台账.md` 的「来源与使用限制」列标明本篇属于哪一类（见 §六）。

⛔ **孩子不同意时不发布。**

## 五、不诊断、及时转介

### 5.1 说法对照表（⭐ 这条最容易越界）

| ✅ 可以说 | ⛔ 不能说 |
|---|---|
| "这些表现**值得进一步评估**" | "孩子**患了抑郁症**" |
| "这种情况建议找专业的人看一下" | "这是**游戏成瘾**" |
| "我看到的是一组持续的行为变化" | "这是**注意力缺陷**" |
| "我不能判断，这超出我的范围" | 任何基于家长单方讲述的**定性结论** |

> **分界线**：**描述＋建议评估**可以；**下诊断**不可以。哪怕家长自己已经这么说了，也不要顺着复述成结论。

### 5.2 什么时候必须停止给家庭教育方法

出现以下情况，**不应继续靠沟通话术、手机协议或家长沙龙解决**，而要建议寻求合格的心理或医疗支持：

| 信号 | 动作 |
|---|---|
| **自伤、轻生念头或行为** | ⛔ **立即**建议专业支持；**安全优先于一切方法讨论** |
| **持续功能受损**（长期无法上学／工作／社交） | 建议专业评估 |
| 严重**饮食或睡眠**问题、体重明显变化 | 建议医学评估 |
| 疑似注意力／执行功能或**学习障碍** | 建议专业评估，**不自行贴标签** |
| 家庭暴力、严重忽视 | 属专业干预范围，**不在本系统内处理** |
| 物质使用、离家出走等高风险行为 | 立即专业支持 |

## 六、保证文章和课程真实可信

### 6.1 叙事真实性三分法（P0）

| 素材性质 | 写法 | 标注要求 |
|---|---|---|
| **① 真实经历**（我自己的、孩子的） | 第一人称「我和儿子」 | 无需特别标注 |
| **② 课程案例／改编场景** | 可以写成场景，但 | **必须标注「场景改编」** |
| **③ 他人的经历** | 第三人称 | 标明来源 |

⛔ **绝不把讲师自述改写「我」**；⛔ **不替孩子补台词**（素材里没有的孩子的话，一句都不能补）。

### 6.2 五层标注方法（⭐ 成果 #5）

任何一条公开内容里的观点，都要能回答"**这是哪来的**"：

| 层 | 标注写法 | 例 |
|---|---|---|
| 1 **研究或专业指南** | 「某某指南指出／某研究发现」 | 须核到原文；**核不到就不写** |
| 2 **扶鹰课程** | 「课程认为」 | ⛔ 不写成"研究表明" |
| 3 **自己的家庭实践** | 「我家的做法是」 | 只说**我做了什么、孩子有什么反应**，不推断"这对所有家庭有效" |
| 4 **推测** | 「我猜测／可能」 | **必须显式标"推测"** |
| 5 **（课程案例）场景化改编** | 「场景改编」 | 见 6.1 |

⛔ 五层**不许混写**——最典型的违规是**把第 2 层写成第 1 层**（"课程认为"→"研究表明"）。

### 6.3 其他口径纪律

- 书中模型写「书中提出」；**不写"必然导致""一定会"**。
- **阅读量不公开**；⛔ **绝不编造「10万+」**；**传播量 ≠ 方法有效**。

## 七、不越界到内容生产 / 不评价孩子

- **本系统只管学习与评估**。写稿、排版、卡片、视频各有专门专家（见工作空间 MEMORY）。⛔ 不代劳、不擅自调度；⛔ **不改动 `_资产/技法库/`**。
- ⛔ **只评父母可控的行为**（清单见 `03_评判标准.md` 三）。孩子成绩、到校、手机时长、是否服从，**不得计入成绩**。
- 家庭实践记录的写法：**记"我做了什么、孩子的反应是什么"，不记"孩子做得好不好"**。

## 八、为进入学校和机构做准备

> 合作方在意的**从来不是"你讲得好不好"**，而是下面五件事。**没有 C3，即使课讲得再好，也很难成为可靠的合作方。**

| 合作方会问 | 需要拿得出的东西 |
|---|---|
| 未成年人隐私怎么保护？ | 同意与匿名化规则（成果 #2） |
| 家长是否知情？ | 知情说明模板 ＋ 留痕 |
| 课程是否制造焦虑？ | 公开内容伦理检查表（成果 #1）＋ 不做绝对化承诺 |
| 遇到高风险家庭如何转介？ | 边界图（#3）＋ 转介清单（#4，**含依据**） |
| 讲师会不会超出自己的能力范围？ | 一份**写出来的**个人边界声明 |

## 九、为什么 C3 必须先于 C2

> **你自己在家尝试一个不合适的方法，影响范围相对有限；
> 一旦开始讲课、带领家长小组，一个错误判断可能被几十个家庭复制。**

同理，C3 也是**转介机制的前置条件**——不知道何时停手，讲得越好越危险。

## ⛔ 速查：遇到情况先问三句

1. **我有证据吗？** 没有 → 写「无法判断」，**不下结论**。
2. **这是谁的经历？** 不是我的 → 按 §6.1／§6.2 **标注来源或改编**。
3. **有没有人处在风险中？** 有 → **停止给方法，先转介**。
