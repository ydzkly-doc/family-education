# 资料库

> **本目录装两件事**：① 顶层的**待获取清单**（找什么、为什么）② 子目录里的**外来资料原文**（拿到之后存哪）。
> 索引与获取规则见 `../02_学习资料总索引.md`。

## 一、⭐ 顶层清单 = 资料获取三步（2026-09-30 用户定）

| 文件 | 回答什么 | 步序 |
|---|---|---|
| `01_扶鹰课程清单.md` | 扶鹰有哪些课、**名称**、为什么值得学 | **第 1 步** |
| `02_数据源清单.md` | 有哪些**权威数据源与指标名称** | **第 2 步** |
| `03_专家与著作库.md` | 领域内的**专家 ＋ 代表著作** | **第 3 步** |
| `04_讲授与课程设计书单.md` | **C2 专项**：讲授／课程设计／演讲书目 ＋ 微信读书推荐值 | **专项**（不对应步骤） |

⭐ **按 1 → 2 → 3 的顺序检索**，结果汇总成**每月的学习资料推荐**。
⚠️ 三份清单**只给名称与推荐依据**，**具体资料由用户自行获取**；规划师负责检索、核验与登记。

## 二、子目录 = 外来资料原文

按**来源层级**分：

- `法律政策/` —— 现行法律、主管部门正式文件
- `专业指南/` —— 权威机构指南、专业共识
- `教材研究/` —— 大学教材、系统综述、研究论文、评估报告

### 与 `课程材料/` 的区别

| | 放什么 | 生命周期 |
|---|---|---|
| **本目录子目录** | 外来**长期**资料原文（法律、指南、教材电子版、报告 PDF） | 长期，**跨月复用** |
| `月度学习/YYYY-MM/课程材料/` | 当月**学习过程材料**（课堂笔记、纪要、当月临时收集件） | **跟月份走** |

## 三、命名规范

```text
<层级>_<标题>_<版本或年份>_<获取日期>.<ext>

例：法律政策_家庭教育促进法_2021_20261001.html
    专业指南_UNICEF积极养育指南_2022_20261105.pdf
```

## 四、⛔ 三条纪律

1. **入库必登记** —— 存的同时补进 `../02_学习资料总索引.md`（含**受众／抓取日期／版本**）；
2. ⛔ **只存合法来源** —— 官方公开入口、已合法拥有的资料；**绝不找盗版或未授权讲义**；
3. ⚠️ **必记版本与抓取日期** —— 官方文件会修订，**URL 不变、内容会换**；没有版本号的文件等于没有出处。
