# 第 2 篇发布操作指南

## 5 步发布（约 2 分钟）
1. 用浏览器打开本文件夹 `正文_第2篇_你就不能说句好听的.html`，**Ctrl+A 全选 → Ctrl+C**。
2. 登录公众号后台 mp.weixin.qq.com → 新建图文 → 在正文区 **Ctrl+V 粘贴**（排版、卡片、色块一并带入，无需上传任何正文图）。
3. 打开 `01_标题作者摘要.txt`，照填【标题】【作者】【摘要】，加合集/话题标签。
4. 上传封面（Gate3 确认风格后统一补：`封面_第2篇_xxx.jpg`，2.35:1）。
5. 点【预览】用手机扫码自查 → 无误后存草稿 / 定时群发。
