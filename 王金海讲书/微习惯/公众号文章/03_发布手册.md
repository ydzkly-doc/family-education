# 《微习惯》系列发布手册

## 发布顺序

1. 计划总在第三天熄火？先把目标缩到只剩一步
2. 总等“有动力再开始”，难怪计划撑不过三天
3. 目标小到“说出来都脸红”，为什么反而更容易坚持
4. 总是忘记行动？给微习惯装上这4个小机关
5. 孩子一看到任务就拖延，先别催，帮他切成小台阶

建议每 2—3 天发布一篇。前四篇依次完成启动、动力、设计和系统搭建，第五篇再进入亲子应用，避免读者一开始就把工具用于控制孩子。

## 单篇发布步骤

1. 打开对应发布包中的 `正文_第N篇_*.html`，复制正文内容到微信公众号编辑器。
2. 按同目录 `01_标题作者摘要.txt` 填写标题、作者和摘要；后台作者统一填写“归途有光·和孩子一起重启”。
3. 上传同目录的 `封面_第N篇_*.jpg`。本系列已按确认的人物主题风格重新生成，五张均为 1200×511、无字、低于 200KB。
4. 保存草稿，分别在安卓和 iOS 微信中预览，重点检查段距、底色、引号、窄屏显示和来源声明。
5. 由用户最终确认并保存或发布；本地预览与自动检查不能代替微信客户端预览。

## 发布前内容检查

- 改编场景已在开篇明示，不冒充作者或用户家庭亲历。
- 不把意志力描述为容量固定的电池，不用单一的葡萄糖解释行动成败。
- 不使用“一定成功”“不可能失败”“一天进步1%，一年强37倍”等过度承诺。
- 最小动作只是启动线，不是假装完成最终目标；额外完成不自动抬高次日最低线。
- 对孩子使用时先询问困难、征得同意、共同拆分，不把工具变成新的控制。
- 若困难伴随明显焦虑、睡眠紊乱、持续缺课、身体不适或功能下降，保留专业求助边界。
- 核心原则允许跨篇重复，但每篇应有不同机制、场景和行动。

系列来源口径：内容依据斯蒂芬·盖斯《微习惯》及扶鹰教育·王金海读书栏目《微习惯》整理；正文为观点转译和家庭教育场景改编，非原文摘录。
