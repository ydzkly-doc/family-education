# 《我们到底在吵什么》系列 · 发布手册

> 系列共 5 篇；账号：归途有光·和孩子一起重启  
> 本手册是发布操作说明的唯一归口，不再逐篇生成操作指南，也不生成 PDF 审阅版。

## 一、发布顺序

| 篇号 | 标题 | 主要作用 |
| --- | --- | --- |
| 1 | 一碗炒面，为什么吵成了“你心里根本没我” | 看见导火索、解释与关系需要的错位 |
| 2 | 她只是想被听见，我却急着给出解决方案 | 区分倾听、安慰与共同解决 |
| 3 | 袜子没放好，为什么最后吵成“这日子不过了” | 中断冲突升级，并约定回来修复 |
| 4 | 一个生日蛋糕，背后藏着多少没说出的渴望 | 理解旧经验，同时守住今天的边界 |
| 5 | 认识伴侣，不是给他贴上五种气质标签 | 把类型判断改成核对与协商 |

建议每周发布 2 篇，按篇号顺序推进；第5篇作为收官回看前四篇。

## 二、正式发布包

每个 `发布包_第X篇_短标题/` 只含三件成品：

| 文件 | 用途 |
| --- | --- |
| `正文_第X篇_短标题.html` | 微信正文，以浏览器呈现和微信后台粘贴效果为准 |
| `01_标题作者摘要.txt` | 标题、作者、摘要、备选标题和来源字段 |
| `封面_第X篇_短标题.jpg` | 1200×511 横封面，无文字，低于 200KB |

五个正式目录依次为：

- `发布包_第1篇_炒面争吵`
- `发布包_第2篇_先听后解`
- `发布包_第3篇_袜子争吵`
- `发布包_第4篇_生日蛋糕`
- `发布包_第5篇_气质标签`

## 三、微信公众号后台操作

1. 登录微信公众号后台，进入草稿箱并新建图文。
2. 从该篇 `01_标题作者摘要.txt` 复制【标题】与【摘要】。
3. 【作者／署名】统一填写“归途有光·和孩子一起重启”。
4. 用浏览器打开该篇 HTML，复制页面中呈现的正文，粘贴到微信编辑器；不要复制源码。
5. 上传同一发布包里的 JPG 封面，裁剪时保持 2.35:1，并确认中央主体没有被二次裁掉。
6. 在手机端分别检查标题块、卡片颜色、段距、左右裁切和文末来源。
7. 由用户自行保存、预览或群发；本地发布包不会自动上传或发布。

## 四、发布前自查

- [ ] 标题与正文顶部标题逐字一致。
- [ ] 作者填写账号名，不填写正文叙事者。
- [ ] 课程案例保持第三人称；改编场景的声明仍在。
- [ ] 来源声明包含王金海讲书、林文采及必要的研究补充。
- [ ] 封面无文字、商标和水印，核心物件在中央安全区。
- [ ] 微信编辑器中没有横向裁切、丢色、空白卡片或多余空段。
- [ ] 安卓和 iOS 微信至少各预览一次后再发布。

## 五、系列边界

- 关系理解不等于必须答应对方所有要求。
- 原生家庭只能作为理解线索，不能替伤害行为免责。
- 五种气质只作为课程观察框架，不当作人格诊断。
- 控制、羞辱、威胁、暴力或持续恐惧不属于普通沟通差异，应优先处理安全与专业支持。
