# 第1篇 · 一键发布操作指南（个人订阅号 · 手动粘贴版）

> 公众号：**归途有光·和孩子一起重启**
> 本篇正文**不含任何 `<img>` 图片**——"厌学四阶段卡片"等全部是 table+内联样式画的，
> 粘贴进公众号后台会**自动保留色块和排版**，无需上传任何正文图。

---

## 🚀 5 步发布（约 2 分钟/篇）

### 第 1 步：打开正文 HTML
- 本文件夹里的 **`正文_第1篇_接错话.html`**（双击用 Chrome/Edge 打开）。
- 在页面任意处点一下 → **Ctrl+A 全选** → **Ctrl+C 复制**。

### 第 2 步：进后台新建图文
- 登录 https://mp.weixin.qq.com → 左侧「草稿箱」→「新的创作」→「图文消息」。
- 在正文编辑区点一下 → **Ctrl+V 粘贴**。
- ✅ 粘贴后检查：橙色标题色条、金句框、四阶段卡片、"今晚3件事"色块都应完整保留。

### 第 3 步：填标题/作者/摘要
- 打开 **`01_标题作者摘要.txt`**，逐项复制：
  - 标题 → 粘贴到标题栏
  - 作者 → `归途有光`
  - 摘要 → 粘贴到「摘要」栏（不填则系统抓正文前54字，建议填）

### 第 4 步：设置封面（唯一需要"图"的地方）
- 公众号封面**必须上传一张图**（正文可以没图，封面不能空）。
- 建议尺寸 **900×500**（公众号封面比例 2.35:1），≤2MB，暖橙/米色系，与正文风格统一。
- 封面图来源二选一：
  - **A. 我帮你生成**：告诉我一声，我用 AI 出 1~3 张暖色家庭教育主题封面图给你选；
  - **B. 你自己截/找**：可把正文里的"厌学四阶段卡片"截图，或用 unsplash/pexels 免费图（关键词：parent child、温暖、陪伴）。
- 上传后可选择「正文是否显示封面」——建议**关闭**（正文开头已有标题色块，重复显示封面会突兀）。

### 第 5 步：预览 → 存草稿 / 发布
- 点右上角「预览」→ 扫码发到自己微信，**手机上通读一遍**（重点看卡片有无横向溢出、金句换行自不自然）。
- 确认无误 → 「保存」即进草稿箱；要发就「群发」（可定时，建议工作日晚 20:30–21:30）。

## ✅ 发布前自查清单

- [ ] 标题无错别字、痛点清晰但不夸大失实
- [ ] 手机端预览：四阶段卡片、金句框完整，无横向溢出、无白底断裂
- [ ] 作者、摘要已填
- [ ] 封面已上传（暖色、风格统一）
- [ ] 文末**来源声明在位**（读书笔记整理自扶鹰教育·王金海课程，版权归原作者）
- [ ] **不声明原创**（本文为读书笔记/学习心得，避免与原课程版权冲突）
- [ ] 无口语残留（对吧/啊/那么）、无绝对化承诺（"一定""必"）
- [ ] 事实表述稳健（"比例更高/往往"而非"全部/绝对"）
- [ ] 留言/在看/转发引导按需开启
