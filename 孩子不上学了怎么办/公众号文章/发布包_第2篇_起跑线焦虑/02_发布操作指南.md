# 第第2篇篇 · 一键发布操作指南（个人订阅号 · 手动粘贴版）

> 公众号：**归途有光·和孩子一起重启**
> 本篇正文**不含 `<img>` 外链图**——卡片、示意图形全部是 table+内联样式画的，
> 粘贴进公众号后台会**自动保留色块和排版**，无需上传任何正文图。

---

## 🚀 5 步发布（约 2 分钟）

### 第 1 步：打开正文 HTML
- 双击本文件夹里的 **`正文_第2篇_起跑线焦虑.html`**（用 Chrome/Edge 打开）。
- 页面任意处点一下 → **Ctrl+A 全选** → **Ctrl+C 复制**。

### 第 2 步：进后台新建图文
- 登录 https://mp.weixin.qq.com →「草稿箱」→「新的创作」→「图文消息」。
- 正文编辑区点一下 → **Ctrl+V 粘贴**。
- ✅ 检查：暖橙主题色条、金句框、内嵌卡片、“今晚3件事”色块都应完整保留。

### 第 3 步：填标题/作者/摘要
- 打开 **`01_标题作者摘要.txt`** 逐项复制：标题、作者（归途有光）、摘要。

### 第 4 步：设置封面（唯一需要“图”的地方）
- 封面**必填**（正文全用 table 画、无位图，封面是唯一要图的）。比例 2.35:1（约 900×500），暖橙色系、与正文风格统一、画面不带文字。
- 把准备好的封面（`封面_第2篇_起跑线焦虑.jpg`，≤200KB）上传；建议关闭“正文显示封面”。


### 第 5 步：预览 → 存草稿 / 发布
- 「预览」扫码发自己微信，**手机通读一遍**：卡片无横向溢出、金句换行自然。
- 无误 →「保存」进草稿箱；「群发」可定时（建议工作日晚 20:30–21:30）。
