# 《孩子不上学了怎么办》视频号制作方案（总规划）

> 系列：6 篇公众号长文 → 视频号口播短视频
> 素材来源：`孩子不上学了怎么办/公众号文章/发布包_第1–6篇/正文_*.html`
> 状态：**规划阶段，尚未生成口播文案。** 出镜身份已定（走真亲历），另有**两道闸**待用户拍板。

## 一、总体判断：这个系列适合做视频号，而且终于有了根

**适合的四个理由**

1. **题材有天然需求**：家长遇到这件事的时候，是深夜一个人翻手机的时候。视频号"刷到一条有人认真讲这件事"的场景完全成立。
2. **干货密度高**：第 5 篇（四步对话）有完整可照念台词，第 1 篇有完整可照念开场句——**有台词就能拍，也能被转发**（"这句话我存下来了"）。
3. **原文已经排过雷**：规划表已删掉未核验数字、已把"四阶段"降级为课程观察框架、已写明专业求助边界。视频改写不用重新做合规体检，只需守住原有边界。
4. **⭐ 出镜者是真亲历者**（见第二节）。这是本系列最稀缺的资产。

## 二、✅ 已定：走真亲历（用户确认 2026-09-22）

**用户提供的事实**：孩子**上个学期（很长一段时间）基本没去学校**，家里经历过一段"鸡飞狗跳"；现在孩子**高一**。

> ⛔ **用词红线（全系列统一）**：**不用"休学"这个词。**改用「**有很长一段时间，基本上是上个学期**，他基本没去学校」。不提具体月份、不提校名。

→ 与账号人设**逐字吻合**：孩子 15 岁 / 高一 / 儿子，账号名"归途有光·**和孩子一起重启**"——**"重启"是实指，不是修辞**。
→ 换句话说：**这个系列的根，本来就是这段真实经历。** 前面几轮之所以要把改编场景标注清楚，恰恰是因为真事没被说出来。

### ⭐ 结构要求：六条放同一个合集（用户确认 2026-09-22）

六条视频**放进同一个视频号合集**，观众会连着看。
→ 因此每条都要：**结尾给下一条留一个自然的开口** + 开头可承接上一条。
→ 专项文件：**`_系列过渡文案_合集版.md`**（含逐条承上启下文案、速查表、与引流的顺序规则）。

**⚠️ 合集≠连续剧（不可让步）**：每条**仍必须自成一体**。过渡只能是"软连接"——
- ✅ 允许："下一条我说说当时家里是怎么乱起来的"
- ❌ 禁止：把核心留给下一条（"这个下一条再讲"）
- ❌ 禁止：开头"上一集我们说到……"（观众可能是第一条刷到的）
- **判断标准：把过渡句删掉，这一条还完整吗？**

### 出镜身份：**亲历者 + 学习者**（双重身份，两边都不撒谎）

| | 位置 | 怎么说 |
|---|---|---|
| **"我"是真的** | 开场、场景、情绪、犯错 → 用他真实的记忆 | 第一人称，可以很具体 |
| **"方法"是学来的** | 中段的知识部分（四阶段框架、四步对话、三问等） | "我后来学到……"「课程里讲……」 |

**这个结构有三个好处**：
1. **完全真实**——真事说真事，学问说学问；
2. **与账号人设一致**——"重启"包含"我在学"；
3. **天然解决引流**——方法来自课程，而学习心得写在了公众号。**顺理成章，不是广告位。**

> ⚠️ 特别注意：**第 5 篇那四轮对话如果来自课程示范，不能说成"我们家当时就是这么谈的"。** 处理方式是把课程方法放在"我后来学到"的位置。**但如果你真记得当时某段对话，那段比课程示范值钱十倍**（真实的语气、真实的卡壳、真实的反应，是任何示范都替代不了的）。

## 三、⚠️ 闸 1（最高优先级）：孩子的隐私

> **这一条不解决，后面所有稿子都不成立。** 不是流程问题，是内容能不能长久做的地基。

**为什么必须先说这个**：
- 孩子现在**高一**——同学、老师的手机里都可能刷到这条视频；
- "我儿子去年休学半年"**一旦发出去就收不回来**；
- 更根本的是：**这是他自己的经历**，不一定是**他愿意被公开**的那一段。

**要你定的四件事**：

| 要定的 | 选项 |
|---|---|
| 1. 用不用"休学"这个词 | ① 直接用 ② 换成"有半年基本没去学校" ③ 不提时长，只说"那段时间" |
| 2. 时间与学校 | 不提具体月份、不提校名（推荐） |
| 3. 孩子的形象 | 不出正脸、不出可识别的房间/物品（推荐） |
| 4. **孩子本人知道吗** | **建议告知并征得同意**——不是形式，是这件事能长久做的前提 |

**我的建议分寸：讲"我"的部分可以很具体，讲"孩子"的部分要模糊。**

理由：这段故事里真正对别人有用的，**是家长那一侧的真实**（我当时怎么慌、怎么把话说死、怎么睡不着），不是孩子那一侧的隐私。**"我"可以敞开，"他"要留门。**

### 三档敞口，你挑一个（也可逐条微调）

| 档 | 讲什么 | 适合 |
|---|---|---|
| **A 最敞开** | 具体场景 + 具体对话 + 情绪细节 + 后来怎么变的 | 完全不在意公开、孩子也同意 |
| **B 推荐** | **家长这一侧的真实**（我的慌、我的错、我说错的话）＋ 孩子那侧模糊（"他后来不再说了""他开始锁门"这类不带细节的状态） | 既真又有保护 |
| **C 最保守** | 只承认"我们家经历过那段时间"，细节全部抽象化 | 只想给个态度、不想暴露任何具体 |

## 四、⚠️ 闸 2：课程示范 ≠ 家里的真实对话

六篇原文是**课程学习心得**，其中的框架、四阶段、四步法、示范台词都来自课程。

| 内容 | 归属 | 怎么说 |
|---|---|---|
| 孩子的状态、家里的混乱、我的反应 | **真实** | "那半年……" 第一人称 |
| 四阶段框架、四步对话法、报班三问 | **课程** | "我后来学到一套说法……" |
| 课程里的示范对白 | **课程** | ⛔ 不能说成"我们家当时就是这么谈的" |

→ 所以不是"整条都能说成亲历"，而是**两个来源要各归各位**。这恰恰是账号最诚实也最有说服力的地方：**一个走过这段路的爸爸，后来去学了一套方法。**

## 五、这个变化带来的最大机会（原方案没有的）

**原文最大的短板：太正确、太冷静。**
因为它是课程学习心得（第三人称 + 边界声明），通篇"可以先这样说""不必立刻升级""要留出可信度"——**道理都对，但缺一个在那种处境里活人的真实状态。**

**真实经历补上的正是这一块**，而且这些是原文里完全没有的：

- 我当时是怎么一步步把话说死的
- 夜里睡不着的时候我在搜什么、想什么
- 家里谁跟谁吵、分工怎么乱的（"鸡飞狗跳"具体长什么样）
- 什么时候第一次觉得"可能是我错了"
- 孩子哪个瞬间松动了一点——哪怕只有一点点

**这才是让人转发的东西**：不是"这条有道理"，而是"**这条说的是我当时的样子**"。

举两个对比：

| 原文（正确但冷） | 加上真实底色之后 |
|---|---|
| "不在高度情绪中逼孩子承诺'明天一定去'。" | "**我当时就是那么做的——逼他点了头，第二天早上，人没起来。**" |
| "也可以先离开几分钟，和另一位成年人商量。" | "**那天我在楼道里站了十分钟，不知道回去该说什么。**" |

→ **同一句方法，配上"我做错了"，说服力不在一个量级。** 而且这正好是账号最擅长的位置：不是导师，是走错过路的同路人。

## 六、待拍板：专业求助边界怎么落

六篇原文都写了这段边界（持续拒学、功能明显下降、自伤或轻生表达、暴力 → 尽快寻求专业帮助）。视频里怎么处理：

| 选项 | 做法 | 评价 |
|---|---|---|
| **① 口播结尾平静带一句（推荐）** | 方法型结尾，出镜者平稳说一句，≤15 字，如"如果这事已经持续很久，别自己一个人扛，找专业的人帮忙。" | 守边界、不掉链子、不破坏节奏 |
| ② 只放视频号正文 + 评论区置顶 | 视频里不提，完整求助信息写在文案里 | 更轻，但看完就走的人接不到 |
| ③ 不处理 | — | ❌ 不接受，违反系列既定的内容取舍 |

> **建议**：**①+②**。口播一句极简的，正文和评论区置顶写完整（含"存在即时安全风险时不要让孩子独处"）。
> ℹ️ **有了真实经历之后这条更该保留**：正因为他家真的走过，一句"别自己扛"才不是套话。

## 七、六条视频逐条方案

时长标准（本系列**不用**常规的更短档）：讲的是重话题，**语速必须比常规慢半拍**，讲太快显得轻率。
→ 观点型 **55–70 秒 / 220–280 字**；方法型 **80–110 秒 / 320–440 字**。

> 「真实素材锚点」一行是我推测**最可能对得上**的接口，**请你确认哪些真、哪些不是**——不对的划掉，我不硬套。

### ▍第 1 篇《第一句话先别追问原因》

| 项 | 内容 |
|---|---|
| **形态** | 观点输出型（强反常识）+ 一句可照念台词 |
| **建议时长** | 60–70 秒 / 240–280 字 |
| **讲透的核心** | 孩子说"不想上学"，**第一句话的目标不是问出真相，是把压力降下来**。因为他不是不想说，是紧张、羞耻、疲惫包住的时候，本来就组织不成完整的语言。 |
| **真实素材** | ⭐⭐⭐ **已对上（素材5）：那段追问**——"你到底还想不想上学？""想呀。""那明天能去么？""能去。"→ **第二天不起床，一叫就发脾气**。<br>**这几乎就是本条的活教材**：三个动作全在里面（追问 → 逼承诺 → 第二天崩）。原文那句"不在高度情绪中逼孩子承诺'明天一定去'"，被这段真实对话完整印证。 |
| **⭐ 核心洞察** | **孩子说"能去"的时候，他没骗你——他当时是真的想去，只是第二天做不到。**他答的不是承诺，是他当时的希望。<br>→ 这一句直接把"孩子说话不算话＝不守信"的旧理解推翻，是本条最值钱的地方。 |
| **视频内闭环** | 学会：那句追问为什么无效（真实对话演示）＋ 第一句话该说什么（完整台词）。 |
| **金句方向** | 候选①**「第一句话不是用来问出真相的，是用来让孩子敢接着说下去的。」**<br>候选②**「他说'能去'的时候没骗你，他只是第二天做不到。」**（← 更贴真实素材，**倾向用②**） |
| **次级金句** | 「他听见的不是担心，是：你必须马上给我一个满意的解释。」 |
| **公众号承接 20 分** | 三条观察线（事情线/状态线/关系线）、先把三件事收回去、孩子只说"我不知道"时怎么接 |
| **优先级** | **P2（有强素材，具备首条资格）** |
| **⚠️ 排布** | 与第5篇共用素材5，**发布时不要相邻**；本篇讲"那句话不该问"，第5篇讲"后来学到该怎么说"。 |

### ▍第 2 篇《报班前先问：是在帮孩子，还是安抚我的焦虑》

| 项 | 内容 |
|---|---|
| **形态** | 方法讲清型（三问）+ 强自我指向 |
| **建议时长** | 80–95 秒 / 320–380 字 |
| **讲透的核心** | 加一项安排之前，先分清**它在解决谁的问题**。家长的焦虑有个特点——它要求你立刻做点什么；报名、加题、换老师都能带来"我没有耽误孩子"的感觉。但一个安排值不值得，不看它能不能安抚你的不安，看它有没有回应孩子真实、具体、可观察的需要。 |
| **真实素材** | ⚠️ **咬合弱**。真实素材是"报了课程也偶尔不想去、到时间点才提不去"——那是**报了之后**的事；本条讲的是**报之前**先问三问。两者相关但不是同一件事。**且用户明确"报过班吗"这条没给**，故本条**无本土素材可用**。 |
| **视频内闭环** | 三问讲完整（①解决什么具体问题 ②占用了什么 ③孩子多少参与权）＋ 一句能照念的对话台词 |
| **金句方向** | **「报名能治好你的焦虑，但治不好孩子的累。」** |
| **次级金句** | 「目标越模糊，越容易无限追加。」 |
| **公众号承接 20 分** | 试行四周、每周回看三件事、什么变化该认真记录评估、"减压不等于撤掉所有要求" |
| **优先级** | **P3（由 P0 下调：无本土素材，失去首条资格。降为"通用干货条"，排在亲历条之后）** |

### ▍第 3 篇《先别给家庭定罪》

| 项 | 内容 |
|---|---|
| **形态** | 观点输出型（双反问开场，把两个极端同时否掉） |
| **建议时长** | 55–65 秒 / 220–260 字 |
| **讲透的核心** | **"责任"不等于"定罪"。** 定罪是追问谁把事情弄坏了，责任是问"不论原因有多少，我现在能为安全、沟通和求助多做哪一步"。前者让人防御，后者才带得动行动。 |
| **真实素材** | ⭐⭐⭐ **已对上（素材7，全系列最强金句）**——妈妈那句：**"如果他真就不上学了，你能开除孩子么？如果不能，那就先转变自己吧。"**<br>⭐ **且"妻子不只说了一次"**（用户补充）——见下方说明。<br>+ 素材3 我的疲惫："那段时间我情绪很低落，为什么就不去上学呢，想着不上学不就完了么。" |
| **视频内闭环** | 观众带走一个转念：不用再在两个极端之间摇摆，改问一句"今天我能先改哪一处"。 |
| **金句方向** | ⭐ **建议就用真实那句**：**「你能开除孩子么？不能的话，那就先转变自己吧。」**（比原拟的"自查"句强得多——**它一句话把整个系列讲完了**：堵死惩罚性思路 + 把改变落点移回家长） |
| **⭐ "不只说了一次"的用法（三层价值）** | ① **证明这句话当时没被听进去**——她说过不止一次，说明我一开始根本没听。比"妻子点醒了我"真实得多，也更痛。<br>② **让"转变"变成过程而非顿悟**——不是一句话就改变了，是被说了好几次才慢慢听进去（与账号"重启"的定位一致：**重启是过程，不是开关**）。<br>③ **对观众更宽容**——等于告诉屏幕前的人：**你听不进去也正常，我当时也是。** 这句话把观众的羞耻感卸掉了。<br>→ **强烈建议把这层写进稿子**，它是这条的第二层骨架。 |
| **次级金句** | 「孩子后来不再说，不一定是问题消失了，也可能是他发现——只要开口，家里的压力就更大。」 |
| **公众号承接 20 分** | 四个可调整维度、每次只改一个可观察动作、七天小实验、复盘时也要看大人的状态 |
| **优先级** | **P1（由 P4 大幅提前：素材7 是全系列最强金句，素材3 补上了原文最缺的"大人也在垮"）** |
| **风险提示** | ① 开场**先给父母松绑**再讲可改处。② **"不上学不就完了么"必须交代清楚是"累到极点的念头，不是真的不要他"**——写法要念头 + 它把你吓到了 + 你没那么做，三者在一起，否则会被读成"这个爸爸想放弃孩子"。③ **素材7 需要"错误很具体的铺垫"才有力**，故不宜做首条。 |
| **✅ 授权** | 素材6／7 **已确认可公开**；素材7 是妈妈原话，**保留归属**（"孩子妈妈跟我说过一句话"）——归属是这句话力量的一部分。 |

### ▍第 4 篇《不同状态，处理方式不同》

| 项 | 内容 |
|---|---|
| **形态** | 方法讲清型（三条判断线） |
| **建议时长** | 85–100 秒 / 340–400 字 |
| **讲透的核心** | 只听"我不想上学"这一句，判断不了严重程度。**支持的强度要跟着状态变**：①持续时间 ②功能影响 ③安全信号。 |
| **真实素材** | ⭐⭐⭐ **已确认（素材4）**——带他去检查过，**没有结果**；而**我当时确实以为他是装的**。<br>⭐ **素材1**："我不舒服／想睡觉／不想去学校／给我请假"（逐级说出来的）。 |
| **视频内闭环** | 三条判断线＋一条硬提醒：**头痛腹痛是真实感受，检查没问题也不等于孩子在装。** |
| **金句方向** | **「支持孩子的力度，要跟着他的状态变，不是跟着你的着急变。」** |
| **次级金句** | ⭐ **建议用真实自白替代**：**「检查没查出问题的那阵子，我心里想的是——他是不是装的。」**（由亲历者说这句话，才让别人听得进去） |
| **⭐ 最强结构** | **我当年就是这么想的 → 后来才知道那是真的 → 所以别那么说。** 这是本条的核心写法，**后半句必须带上**（否则等于替"装病论"背书）。 |
| **公众号承接 20 分** | 四阶段各自的调整方式、一页纸记录怎么记、"阶段框架不是给孩子贴标签" |
| **优先级** | **P0（首条）** |
| **拆条机会** | ⭐ 天然可拆 2 条：①三条判断线 ②「别再说孩子装病」 |

### ▍第 5 篇《四步对话，先把门打开》

| 项 | 内容 |
|---|---|
| **形态** | 方法讲清型（本系列**最硬的一条干货**） |
| **建议时长** | 95–110 秒 / 380–440 字（四步要讲完整） |
| **讲透的核心** | 四步：①说出你观察到的状态 ②核对感受，不抢着解释 ③共同定义当下的问题（把"上不上学"变小）④只商量一个可尝试的动作。 |

### ▍第 6 篇《家长先做这张行动清单》

| 项 | 内容 |
|---|---|
| **形态** | 观点输出型（讲一个顺序原则）——**不做六步全讲** |

| **真实素材** | ⭐⭐⭐ **已对上（素材6）**——**"当时家里更多是妈妈在动员，我是一个扯后腿的，总给妈妈负面压力，给孩子甩脸子。"**<br>**这就是第6篇"全员动员、却没有一张共同的行动图"的完美真人版**，而且给出了一个很多人没意识到的真相：**家里乱的另一种形式，不是没人管，是各拉各的车。** |
| **视频内闭环** | ①顺序原则 ②一个能立刻做的动作：**家里只留一个主要沟通者** ③一个换尺子的提醒：不让"返没返校"当唯一标尺。 |
| **金句方向** | **「返校可以是目标，但不能是唯一的那把尺子。」** |
| **次级金句** | ⭐ **建议用真实自嘲**：**「她一个人在往前推，我在后面踩刹车。」**（比原文"全家都在忙却没有行动图"更具体） |
| **公众号承接 20 分** | 六步清单完整版、最初 24 小时、第一周三条协作线、一页纸记录四类信息 |

## 十、本系列特有的四个提醒

1. **标题不碰焦虑。** 不用"90% 的家长第一步就错了""别等孩子彻底不去上学才看到"。题材本身够重，标题靠说人话取胜。**最好的标题往往就是一件真事。**
2. **六条收尾句必须各不相同。** 原文已要求不重复同一种祝愿收尾。**且"收尾金句"与"合集过渡句"是两句、不要合并**（顺序：先落地，再往下一集引）。
3. **⭐ 真事也要过一遍"我愿不愿意让儿子看到"。** 每写一条先问：**如果孩子刷到这条，他会怎么想？** 这条自检比任何合规清单都重要。
4. **⛔ 用词统一**：不用"休学"（→「有很长一段时间，基本上是上个学期」）；不用"确实是装的"（→「我当时以为是装的」）。
5. **合集里六个标题句式要错开**（不要都是"孩子××怎么办"），避免重复同一个词。合集名建议：**《孩子一段时间去不了学校，我们走过的路》**。
