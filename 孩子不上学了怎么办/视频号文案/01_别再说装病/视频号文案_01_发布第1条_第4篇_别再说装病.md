# 【开拍前看】

## 一、怎么拍

- **时长：约 103 秒，口播 413 字。** 这条是"**先自曝 → 再给方法 → 再落金句**"，三段缺一不可。**压到 60 秒会把"我以为是装的"这个铺垫挤掉——这条全部的力量都来自那个自曝。**
- **⭐ 状态：像跟一个熟人聊天，不是在念稿。** 不要用力、不要沉、不要"播音腔"。**可以有小停顿、可以有一点点想不起来的样子**——那些反而是最像聊天的地方。
  > ⚠️ **最忌"痛心疾首"**——一旦沉痛，就变成表演了。分寸是：**有点难为情地承认，而不是懊悔地控诉。**
- **哪句要"重"**：说"**我儿子，会不会是装的**"那一句，是**低声、停一下、带点不好意思**——不是咬牙切齿。**这句最容易念成"抱怨孩子"，一旦念成抱怨，整条就废了。它是在交代你自己的错。**
- **⭐ 全片的情感引擎，是这一段对比**（最重要的一条）：
  > **她一直在做**（带孩子去医院、一直有耐心、还常带他去图书馆、去公园、带他出去玩），**我在旁边怀疑、还跟孩子冷战。**
  说到"她一直有耐心。还老带他出去。"——**要平、不要感慨、不要加重**，像顺口提一句。**越是平铺直叙，观众自己越能听出那个落差**；一感慨就变成"我在夸我老婆"，反而轻了。
- **⚠️ 危险信号那两句要平着念**（"比如他跟你讲过，他不想活。或者说，他要伤害自己。"）——**语气平、不加重、不拉长停顿**。它是必须说的，但别念成吓人的话。
- **分段拍**：①自曝（肚子疼＋我的念头）②妈妈那一段＋三条判断 ③金句＋收尾。**管道自动拼接**（见「五、怎么合成」）。

## 五、怎么合成（ffmpeg 管道）

> 用技能 **`ffmpeg-vertical-video-pipeline`** 合成，**不用剪映**。
> 「四、上屏方案」里已经把字幕、大字卡、序号条、封面全写清了——**这里只写这条特有的**。

1. **素材**：按「一、怎么拍」分 3 段拍，存到**本条目录下的 `_素材/`**，命名 `01.mp4 02.mp4 03.mp4`（**按文件名排序 = 段序**）：
   - `01.mp4` = 自曝（肚子疼＋我的念头）
   - `02.mp4` = 妈妈那一段＋三条判断
   - `03.mp4` = 金句＋收尾
   ⚠️ **拍的时候直接用 1080×1920 竖屏原画**——尺寸低了后期放大，字幕和画面都会变软。
2. **逐字稿**：**不用手工抽**——`--md` 会自动从「二、口播文案」生成 `…_文案.txt`（一行一句、剥掉方括号提示）。
3. **一条命令**：
   ```
   cd C:\Users\ZhuanZ\.workbuddy\skills\ffmpeg-vertical-video-pipeline
   python scripts/video_make.py ^
     --md "D:\个人资料\家庭教育\孩子不上学了怎么办\视频号文案\01_别再说装病\视频号文案_01_发布第1条_第4篇_别再说装病.md" ^
     --videos-dir "D:\个人资料\家庭教育\孩子不上学了怎么办\视频号文案\01_别再说装病\_素材" ^
     --out "D:\个人资料\家庭教育\孩子不上学了怎么办\视频号文案\01_别再说装病\_成片_01.mp4"
   ```
   💡 **先加 `--dump-params`** 看一眼解析结果再真跑（省一次编码时间）。金句版应显示：**字幕 = 2 句（不是 all）**、大字卡 2 张、序号条 3 条。
4. **⚠️ 本条要特别交代的三处**：
   - **"我没去"前后的停顿不能被剪**——那两句之间的停顿才是它的重量（剪成连读就废了）。
   - **妈妈那三句**（"她一直有耐心。还老带他出去。去图书馆，去公园。有时候就是带他出去玩。"）是**慢的、平的，不是卡壳**——要让观众听清她当时都在做什么。
   - **危险信号那两句**（"比如他跟你讲过，他不想活…"）——**金句版下它本来就不上字幕**（不在「录制提示」的挂句里），画面干净，正好符合"必说但不突出"的要求。
5. **产出**：`_成片_01.mp4` ＋ 封面 PNG（中间产物落在 `_过程文件/`）。
6. **出片后自查**：① **只有那 2 句有底部字幕、其余画面干净**吗（金句版最关键的一点）② 三条序号条对上"第一个／第二个／第三个"了吗 ③ 大字卡**结尾回放的那一帧**在吗 ④ 响度与噪声正常吗。

> ℹ️ **合成能力与硬坑**（响度 −14 LUFS、真峰值 −1.5 dBTP、CJK 折行、锚点定位等）以技能文档为准，此处不重复。
